## K-1002 · HPU · T3 — 수냉식 오일 쿨러 출구 유온 확인 순서 — Algo J.2

- **부품**: 오일 쿨러
- **증상**: 냉각기 출구 포트의 오일 온도 측정값이 해당 설비의 승인된 정상 상한을 초과하거나, 냉각 성능 확인이 필요하다. 정상 상한 수치는 원문에 없으므로 현장 기준이 없으면 온도 이상 여부를 판정하지 않는다.
- **노하우**: 가상 MES 유온(hpu_oil_temp)은 mes-card-signals.md의 정상 범위 35–58℃(양끝 포함)와 비교한다. 범위 이탈을 안내하되 측정 위치가 냉각기 출구와 같다고 확인되지 않았으므로 출구 유온으로 대체하지 않는다. 58℃를 원문의 출구 임계값으로 사용하거나 MES high만으로 아래 분기를 선택하지 않는다. 출구 온도 분기에는 별도 출구 관측과 해당 설비의 출구 온도 기준이 필요하다. 1) 냉각기 출구 포트의 유온 측정값과 해당 설비의 승인된 정상 상한을 비교한다. 상한 초과이면 3)으로, 상한 이하이면 2)로 간다. 상한 수치는 원문에 없으므로 현장 기준을 확인하지 못하면 이 분기를 보류한다. 2) 오일 입·출구 온도차가 있는지 본다. 차이가 있으면 냉각기는 정상 작동 중이고, 없으면 오일이 작동 온도에 도달했을 때 다시 확인한다. 3) 냉각수 공급, 4) 써모스탯 조정, 5) 냉각수 출구 온도>입구 온도 여부, 6) 냉각수 입구 온도 측정값의 해당 설비 승인 상한 초과 여부, 7) 냉각기 통과 오일 유량 측정값의 승인 범위 충족 여부를 차례로 확인한다. 두 기준의 수치는 원문에 없으므로 현장 기준이 없으면 해당 판정을 보류한다.
- **근거 설명**: Vickers 흐름도 Algo J.2(냉각기 계통 시험)는 출구 유온 확인에서 시작해 냉각수 공급→써모스탯→수온 상승→입구 수온→오일 유량 순으로 YES/NO 분기와 조치를 명시한다. '너무 높다'의 온도 기준값은 원문에 없다. 제조사 권고 진단 절차이며 실제 수행 기록이 아니다.
  1. 냉각기 출구 포트의 오일 온도 측정값을 기록하고 해당 설비의 승인된 정상 상한과 비교한다. 상한 수치는 원문에 없으므로 현장 기준을 먼저 확인한다. MES 유온은 35–58℃ 기준으로 정상 범위 이탈을 별도 안내하며 냉각기 출구 측정값이나 출구 임계값으로 대체하지 않는다. → 측정값이 승인된 정상 상한을 초과하면(YES) ST-03으로 진행한다. 상한 이하이면(NO) ST-02로 진행한다. 기준을 확인하지 못하면 판정과 분기를 보류한다. MES high만으로 이 분기를 선택하지 않는다.
  2. 전제: ST-01에서 별도 냉각기 출구 관측과 해당 기준으로 출구 유온이 정상 상한 이하임을 확인한 경우에만 진행한다. 오일 입구·출구 온도 사이에 차이가 있는지 확인한다. → 차이가 있으면(YES) 냉각기는 작동 중이다. 목록의 다음 장치를 점검한다. / 중지: 차이가 없으면(NO) 오일이 작동 온도에 도달한 뒤 다시 확인한다.
  3. 냉각수 공급이 켜져 있는지 확인한다. → 켜져 있으면(YES) ST-04로 진행한다. / 중지: 꺼져 있으면(NO) 냉각수 밸브를 연다(Open water valve).
  4. 써모스탯이 조정되어 있는지 확인한다. → 조정되어 있으면(YES) ST-05로 진행한다. / 중지: 아니면(NO) 써모스탯을 재조정한다.
  5. 냉각수 입구·출구 온도를 측정하고 출구 온도 − 입구 온도를 계산한다. → 출구 온도 − 입구 온도 > 0이면(YES) ST-06으로 진행한다. / 중지: 출구 온도 − 입구 온도 ≤ 0이면(NO) 냉각기를 점검한다.
  6. 냉각수 입구 온도 측정값을 프로젝트 설정 상한 30 degC와 비교한다. 프로젝트 적용 기준이며 해당 위치의 측정값·단위·품질을 확인한다. → 측정값이 프로젝트 설정 상한 30 degC 이하이면(NO) ST-07로 진행한다. 측정값이 없거나 측정 위치·단위·품질이 확인되지 않으면 판정과 분기를 보류한다. / 중지: 측정값이 프로젝트 설정 상한 30 degC를 초과하면(YES) 냉각수 공급을 점검한다.
  7. 냉각기를 통과하는 오일 유량 측정값을 프로젝트 설정 유량 범위 38–46 L_min과 비교한다. 38–46 L_min은 hpu_flow 정상 범위에 맞춘 프로젝트 적용 기준이다. → 유량 측정값이 38–46 L_min 안(양끝 포함)이면(YES) 냉각기를 점검한다. 38 L_min 미만 또는 46 L_min 초과이면(NO) 계통의 손실을 확인한다. 통과 유량 측정값·단위·품질이 확인되지 않으면 판정과 분기를 보류한다.
- **출처**: 100980172-Logical-Troubleshooting-in-Hydraulic-Systems.pdf PDF p.29 / 인쇄 p.29 / Algo J.2 System test for coolers
- **작성 노트**: 냉각기 출구 유온·냉각수 입구 온도의 승인 상한, 냉각기 통과 유량의 승인 범위 확인. 입출구 온도차의 관측 위치와 분기 적절성 확인. 단일 MES 유온을 출구 온도로 대체하지 않았는지 확인. [현재 카드 원본](20260929-A/cards.json).

## K-1203 · HPU · T2 — 압력 이상 여부에 따라 릴리프 설정과 유량 확인 경로를 나눈다
