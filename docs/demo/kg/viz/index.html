데이터 확인 중

카드에서 설비 분류와 인용 문서 판본까지, 연결과 원문을 함께 살펴봅니다.

합성 장비는 기본 구성 스냅샷입니다. 실제 현장 자산은 확인되지 않았으며, AssetPart는 설계만 되어 있습니다. 증상 연결은 사람 검수 전 후보입니다. 분류·인용 탐색 시연이며 GraphRAG·검색 성능 향상·정식 온톨로지 달성을 뜻하지 않습니다.

그래프를 불러오고 있습니다.

그래프를 불러오지 못했습니다

저장소 루트에서 아래 명령을 실행하고 HTTP 주소로 접속하세요.

python -m http.server 8765 --bind 127.0.0.1 --directory docs/demo/kg

http://127.0.0.1:8765/viz/ — 기본 경로는 ../build/graph.json입니다. 파일이 없으면 변환 담당자의 산출물 통합을 확인하세요.

가짜 데이터 시연은 주소에 ?mock=1을 명시해서 엽니다. 실제 파일 로드 실패를 가짜 데이터로 자동 대체하지 않습니다.

노드 목록

목록에서 위·아래 방향키로 선택합니다. Tab으로 필터·이웃 관계·원문 속성으로 이동합니다.

설비 필터는 분류·자산·카드와 그 카드에 직접 연결된 증상·문서 판본에 적용됩니다.

선택 노드와 이웃

화살표는 저장된 관계 방향입니다. 관계 이름과 속성은 오른쪽 목록에서 확인할 수 있습니다. 이웃은 필터 밖의 노드도 보여줍니다. 좁은 화면에서는 그래프 안을 가로로 스크롤하세요.
