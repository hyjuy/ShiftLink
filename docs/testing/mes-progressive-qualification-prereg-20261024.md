# 새 점진 랜덤 모드의 운영 AI 검증 — 평가 전 기준

현재 설치된 Pi r6의 모델·profile·임계값을 고정한다. 모드는 df1565f8 기반이며 생성기·정상 동역학·기존 MES engine/contracts/configuration 해시는 Jetson 운영 파일과 일치한다. 평가 후 기준이나 후보를 바꾸지 않는다.

- 신선한 seed·nonce로 네 고장 종류별 6건, 총 24건. 자연 랜덤 생성 결과에서 종류별 첫 6건만 채택한다. 채택은 AI 결과를 보지 않고 끝낸다.
- 별도 정상 8실행 × 900프레임. 고장 시작 뒤 300프레임 유지, 명시적 pause/repair/resume 후 160프레임 회복 확인.
- 정답은 별도 장부에만 저장. AI에는 센서 69채널·가동·시각·실행 정보만 입력한다.
- 첫 통지: 같은 설비, 고장 시작부터 수리 직전까지 처음 공개 reader에 나타난 사건. 같은 고장 창 안 추가 사건은 중복, 그 밖 통지는 비매칭/정상 오통지다. 매번 표시되는 같은 event_id는 새 통지로 세지 않는다.
- 고장 시작 지연과 관측 가능 지연을 별도로 산출한다. 관측 가능 시점은 해당 설비 타깃 센서가 유효 품질로 정상 범위를 3프레임 연속 벗어난 첫 프레임이다.
- 오프라인 통과: 탐지율 ≥95%, 종류별 미탐 0, 정상 오통지 0, 비매칭 0, 중복 0, 시작 지연 p95≤120초, 관측 가능 지연 p95≤15초, feed/report/reader 계산 p95≤1초.
- 3프레임 PDA 조회 간격에 따른 가상 표시 지연을 따로 기록한다. 이 수치를 실제 통신·대기·화면 포함 끝단 간 지연으로 설명하지 않는다.
- 오프라인을 통과할 때만 별도 실제 1Hz·전달·표시 확인을 진행한다. 그 확인과 기존 운영 경보 보존 조건까지 충족해야 Jetson에 적용한다.

최초 검증 도구는 분석 시작 전에 수리 pause 처리를 운영 poll과 같게 보완했다. 초기 부분 생성 자료를 별도 경로에 보존하고 v2 경로에서 고정 기준으로 새 자료를 생성한다. 모델·임계값·평가 기준은 바꾸지 않았다.

현재 Jetson은 기존 경보 1건·고장 정지 상태다. 이 경보를 임의로 해제하거나 새 실행을 시작해 지우지 않는다. PR #354는 이미 병합되어 후속 변경은 별도 PR로 연결한다.
