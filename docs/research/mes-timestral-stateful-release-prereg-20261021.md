# 第2단계 증거 기반 해제 조건 고정

2026-10-21. 첫108개 개발후보는 네조건 통과0개다. 진단선정 gate0/on_scale1/on_z2.5/off_z1.5/release2는 개발35건에서30탐지·오경보297·중복14·p959, 개발45건에서34탐지·오경보274·중복16·p959다. 원래 rawZ 하한만으로 유지하면 고장 원인이 끝난 뒤에도 경보가 길어져 채택할 수 없다. 이 결과를 보존하고 새 확인자료 생성 전 추가 해제 조건을 고정한다.

두 번째 단계는 현재 rawZ>=off_z이고 (EWMA ON 또는 현재 TSratio>hold_ts)일 때만 ON을 유지한다. 그 밖에는 현재 프레임부터 즉시 OFF다. OFF 진입 규칙은 첫단계와 같으며 gate0·release1을 고정한다. off_z{2.5,3}×on_z{3,3.5}×on_scale{.75,1,1.5,2}×hold_ts{.1,.5}, 총32개다. 새 추가 모델·새 센서·추가 추론은 없고 설비별 상태만 유지한다.

기존35+45 개발자료에서만 탐색하며 첫단계와 같은 엄격한 두자료 네조건을 사용한다. 선정/tie 순서의 parameter끝에 hold_ts를 추가한다. 통과후보가 없으면 첫단계와 같은 진단선정 순서를 쓴다. 첫108개와합쳐140개를 탐색한 선택편향을 명시한다. 새 확인에는 이32개중 하나를 고정해서 넘기며 첫단계 진단후보와 바꿔가며 고르지 않는다.
