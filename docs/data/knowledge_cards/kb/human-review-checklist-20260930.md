## K-1002 · HPU · T3 — 수냉식 오일 쿨러 출구 유온 확인 순서 — Algo J.2

- **부품**: 오일 쿨러
- **증상**: 냉각기 출구 포트의 오일 온도 측정값이 해당 설비의 승인된 정상 상한을 초과하거나, 냉각 성능 확인이 필요하다. 정상 상한 수치는 원문에 없으므로 현장 기준이 없으면 온도 이상 여부를 판정하지 않는다.
- **노하우**: 1) 냉각기 출구 포트의 유온 측정값과 해당 설비의 승인된 정상 상한을 비교한다. 상한 초과이면 3)으로, 상한 이하이면 2)로 간다. 상한 수치는 원문에 없으므로 현장 기준을 확인하지 못하면 이 분기를 보류한다. 2) 오일 입·출구 온도차가 있는지 본다. 차이가 있으면 냉각기는 정상 작동 중이고, 없으면 오일이 작동 온도에 도달했을 때 다시 확인한다. 3) 냉각수 공급, 4) 써모스탯 조정, 5) 냉각수 출구 온도>입구 온도 여부, 6) 냉각수 입구 온도 측정값의 해당 설비 승인 상한 초과 여부, 7) 냉각기 통과 오일 유량 측정값의 승인 범위 충족 여부를 차례로 확인한다. 두 기준의 수치는 원문에 없으므로 현장 기준이 없으면 해당 판정을 보류한다.
- **근거 설명**: Vickers 흐름도 Algo J.2(냉각기 계통 시험)는 출구 유온 확인에서 시작해 냉각수 공급→써모스탯→수온 상승→입구 수온→오일 유량 순으로 YES/NO 분기와 조치를 명시한다. '너무 높다'의 온도 기준값은 원문에 없다. 제조사 권고 진단 절차이며 실제 수행 기록이 아니다.
  1. 냉각기 출구 포트의 오일 온도 측정값을 기록하고 해당 설비의 승인된 정상 상한과 비교한다. 상한 수치는 원문에 없으므로 현장 기준을 먼저 확인한다. → 측정값이 승인된 정상 상한을 초과하면(YES) ST-03으로 진행한다. 상한 이하이면(NO) ST-02로 진행한다. 기준을 확인하지 못하면 판정과 분기를 보류한다.
  2. 오일 입구·출구 온도 사이에 차이가 있는지 확인한다. → 차이가 있으면(YES) 냉각기는 작동 중이다. 목록의 다음 장치를 점검한다. / 중지: 차이가 없으면(NO) 오일이 작동 온도에 도달한 뒤 다시 확인한다.
  3. 냉각수 공급이 켜져 있는지 확인한다. → 켜져 있으면(YES) ST-04로 진행한다. / 중지: 꺼져 있으면(NO) 냉각수 밸브를 연다(Open water valve).
  4. 써모스탯이 조정되어 있는지 확인한다. → 조정되어 있으면(YES) ST-05로 진행한다. / 중지: 아니면(NO) 써모스탯을 재조정한다.
  5. 냉각수 입구·출구 온도를 측정하고 출구 온도 − 입구 온도를 계산한다. → 출구 온도 − 입구 온도 > 0이면(YES) ST-06으로 진행한다. / 중지: 출구 온도 − 입구 온도 ≤ 0이면(NO) 냉각기를 점검한다.
  6. 냉각수 입구 온도 측정값을 해당 설비의 승인된 정상 상한과 비교한다. 상한 수치는 원문에 없으므로 현장 기준을 먼저 확인한다. → 측정값이 승인된 정상 상한 이하이면(NO) ST-07로 진행한다. 기준을 확인하지 못하면 판정과 분기를 보류한다. / 중지: 측정값이 승인된 정상 상한을 초과하면(YES) 냉각수 공급을 점검한다.
  7. 냉각기를 통과하는 오일 유량 측정값을 해당 설비의 승인된 유량 범위와 비교한다. 범위 수치는 원문에 없으므로 현장 기준을 먼저 확인한다. → 유량 측정값이 승인 범위 안이면(YES) 냉각기를 점검한다. 범위 밖이면(NO) 계통의 손실을 확인한다. 범위를 확인하지 못하면 판정과 분기를 보류한다.

## K-1004 · HPU · T1 — 베인펌프 소음 증가와 유면 우유빛 거품 — 에어레이션 징후

- **부품**: 주 베인펌프
- **증상**: 펌프 운전 중 동일 운전 조건의 정상 소음 기록과 비교해 소음 증가가 관측되고, 유량 또는 압력 측정값이 해당 설비의 요구값에 미달하며, 탱크 유면이 거품으로 우유빛(milky)을 띤다. 소음 증가의 정량 경계와 요구값 수치는 원문에 없으므로 현장 기준이 없으면 수치 이상 여부는 미판정으로 기록한다.
- **노하우**: 이 세 가지가 함께 보이면 작동유에 공기가 섞였을(에어레이션) 가능성을 먼저 의심한다. 추가로 흡입 배관 밀봉 상태, 축 씰 상태, 리턴 라인 끝이 유면 아래에 있는지, 흡입구가 리턴 라인 정면에 있지 않은지, 탱크 유면과 흡입 위치의 높이차를 측정해 해당 설비의 승인된 최소 높이차와 비교하고 기록한다. 최소 높이차는 원문에 없으므로 현장 기준이 없으면 적정 여부를 판정하지 않는다. 우유빛 외관은 수분 오염으로 생긴 거품에서도 나타나므로 이것만으로 원인을 단정하지 않는다.
- **근거 설명**: Denison 베인펌프 고장 가이드 §2.4 2)는 공기 혼입 시 베인이 불균형해져 가장 두드러진 것이 비정상 소음이며, 심한 마모 전에 유량·압력 미달과 유면의 우유빛 거품이 나타난다고 설명하고, 흡입관 누설·축 씰 열화·리턴 라인 위치·낮은 유면 등을 원인으로 든다. 같은 가이드 §6은 수분 오염 거품도 우유빛이라고 적는다. 정상/이상 외관의 정량 경계는 원문에 없다.

## K-1005 · HPU · T3 — 축압기 프리차지·충전 압력 확인 순서 — Algo J.1

- **부품**: 축압기
- **증상**: 축압기가 계통에서 제 역할을 하는지 의심되어 가스 프리차지와 충전 압력 확인이 필요하다.
- **노하우**: 1) 제조사 지침대로 가스측에 시험 게이지를 단다. 2) 축압기의 유체를 배출하고 가스압(프리차지)을 확인한다. 측정값이 제조사 지정 프리차지 범위 밖이면 질소로 지정 범위까지 충전한다. 범위 수치는 원문에 없으므로 해당 모델 지침을 확인하지 못하면 판정과 충전을 보류한다. 3) 펌프를 정지하고 축압기를 배출한다. 4) 유체 라인에 압력계를 단다. 5) 축압기를 유체 계통 압력까지 충전한다. 6) 유체측 압력 측정값이 해당 설비의 지정 압력 범위 안인지 본다. 범위 수치는 원문에 없으므로 현장 기준이 없으면 판정을 보류한다. 범위 밖이면 7) 압력 스위치 설정, 8) 릴리프 밸브·보상기 조정을 차례로 확인한다.
- **근거 설명**: Vickers 흐름도 Algo J.1(축압기 계통 시험)은 가스측 게이지 설치→프리차지 확인→펌프 정지·배출→유체측 게이지→충전→압력 확인→압력 스위치→릴리프/보상기 순으로 분기와 조치를 명시한다. 프리차지·계통 압력의 정상값은 원문에 없고 제조사 지침을 따르게 되어 있다. 제조사 권고 진단 절차이며 실제 수행 기록이 아니다.
  1. 제조사 지침에 따라 축압기 가스측에 시험 게이지를 설치한다. → 가스측 압력을 읽을 수 있게 된다.
  2. 축압기에서 유체를 배출하고 가스 압력 측정값을 제조사 지정 프리차지 범위와 비교한다. 범위 수치는 원문에 없으므로 해당 모델 지침을 먼저 확인한다. → 가스 압력 측정값이 제조사 지정 프리차지 범위 안이면(YES) ST-03으로 진행한다. / 중지: 가스 압력 측정값이 제조사 지정 프리차지 범위 밖이면(NO) 질소로 지정 범위까지 충전한다(Charge with nitrogen to correct pressure). 범위를 확인하지 못하면 판정과 충전을 보류한다.
  3. 펌프를 정지하고 축압기를 배출한다. → 축압기가 배출된 상태가 된다.
  4. 유체 라인에 압력계를 설치한다. → 유체측 압력을 읽을 수 있게 된다.
  5. 축압기를 유체 계통 압력까지 충전한다. → 축압기가 계통 압력으로 충전된다.
  6. 유체측 압력 측정값을 해당 설비의 지정 압력 범위와 비교한다. 범위 수치는 원문에 없으므로 현장 기준을 먼저 확인한다. → 유체측 압력 측정값이 지정 압력 범위 밖이면(NO) ST-07로 진행한다. 범위를 확인하지 못하면 판정과 분기를 보류한다. / 중지: 유체측 압력 측정값이 지정 압력 범위 안이면(YES) 목록의 다음 장치를 점검한다.
  7. 압력 스위치 설정이 맞는지 확인한다. → 맞으면(YES) ST-08로 진행한다. / 중지: 틀리면(NO) 압력 스위치를 재조정한다.
  8. 릴리프 밸브 또는 보상기가 올바르게 조정되어 있는지 확인한다. → 맞으면(YES) 제조사 지침에 따라 축압기를 점검한다. 틀리면(NO) 릴리프 밸브 또는 보상기를 재조정한다.

## K-1025 · GR · T3 · ⚠ 안전 — 감속기 베어링부 온도 측정값이 승인된 정상 상한을 초과하면 오일 상태와 베어링을 확인한다

- **부품**: 감속기 베어링부
- **증상**: 감속기 베어링부 온도 측정값이 동일 운전 조건의 승인된 정상 상한을 초과한다. 상한 수치는 원문에 없으므로 현장 기준이 없으면 온도 이상 여부를 미판정으로 기록한다.
- **노하우**: 1) 모터 전원을 차단하고 재기동을 방지한 뒤 감속기 표면 온도를 측정해 해당 설비의 승인된 점검 가능 온도 이하로 냉각된 것을 확인한다. 점검 가능 온도 수치는 원문에 없으므로 현장 안전 기준을 확인하지 못하면 점검을 시작하지 않는다. 2) 사이트글라스가 있으면 유면이 중간에 있는지 확인한다. 딥스틱 장착형이면 표시된 적정 범위를 확인한다. 사이트글라스 중간 기준 또는 딥스틱 표시 범위를 벗어나면 유면을 맞춘다. 3) 마지막 오일 교환 시점을 확인하고, 드레인 플러그에서 오일을 조금 받아 점도와 오염 상태를 본다. 필요하면 오일을 교환한다. 오염이 심하면 제조사는 교환 주기와 관계없이 교환을 권고한다. 4) 베어링 손상이 의심되면 베어링을 점검하고 필요시 교체하며 SEW‑EURODRIVE 고객 서비스에 문의한다.
- **근거 설명**: 제조사 고장표는 베어링부 온도 과다의 가능한 원인으로 오일 부족·과다, 오일 노후, 베어링 손상을 각각 제시한다. 유면과 오일 상태를 확인하는 방법은 §8.3에 있다. 고장표의 원인들은 각각의 분기이며, 하나를 반드시 마친 뒤 다음 원인으로 넘어가는 제조사 지정 절차는 아니다.
  1. 모터 전원을 차단하고 재기동을 방지한다. 감속기 표면 온도를 측정해 해당 설비의 승인된 점검 가능 온도 이하로 냉각된 것을 확인한다. 점검 가능 온도 수치는 원문에 없으므로 현장 안전 기준을 확인하지 못하면 점검을 시작하지 않는다. → 전원 차단·재기동 방지와 냉각을 확인했다. / 중지: 표면 온도 측정값이 승인된 점검 가능 온도를 초과하거나 해당 기준을 확인하지 못하면 점검을 시작하지 않는다.
  2. 사이트글라스가 있으면 유면이 중간인지 확인한다. 딥스틱 장착형이면 표시된 적정 범위를 확인한다. 사이트글라스 중간 기준 또는 딥스틱 표시 범위를 벗어나면 유면을 맞춘다. → 해당 유면 확인 장치의 기준에 맞는다.
  3. 마지막 오일 교환 시점을 확인하고, 드레인 플러그에서 오일을 조금 받아 점도와 오염 상태를 확인한다. → 교환 이력과 오일 상태가 확인되었다.
  4. 교환 이력과 오일 상태를 바탕으로 필요하면 오일을 교환한다. 오염이 심하면 교환 주기와 관계없이 교환하라는 제조사 권고를 따른다. → 필요한 오일 조치가 이루어졌다.
  5. 베어링 손상이 의심되면 베어링을 점검하고 필요시 교체하며 SEW‑EURODRIVE 고객 서비스에 문의한다. → 베어링 상태와 후속 조치가 확인되었다.

## K-1027 · GR · T3 — 감속기 누유 위치별 확인: 커버·오일실·드레인·브리더 원인에 따라 조치한다

- **부품**: 감속 기어박스
- **증상**: 감속기 커버판·하우징 커버·베어링 커버·장착 플랜지·오일실 또는 드레인 플러그·밸브·브리더 플러그에서 오일이 샌다.
- **노하우**: 1) 운전 초기 24시간의 오일실 소량 누유인지 먼저 구분한다. 2) 커버·플랜지 가스켓 누유가 의심되면 해당 볼트를 조이고 관찰한다. 계속 새면 SEW‑EURODRIVE 고객 서비스에 문의한다. 3) 별도 원인으로, 오일실 립 뒤집힘이 의심되면 감속기를 벤트하고 관찰한다. 계속 새면 고객 서비스에 문의한다. 오일실 손상·마모가 의심되면 바로 문의한다. 4) 드레인·브리더 누유는 오일 유면이 해당 설비의 표시 상한을 초과하는지와 브리더 장착 상태에 따라 유면과 장착 상태를 바로잡는다. 그래도 계속 새면 사용을 보류하고 SEW‑EURODRIVE에 후속 지시를 요청한다.
- **근거 설명**: 제조사 고장표는 누유 위치와 가능한 원인별 조치, 길들이기 중 정상 누유 예외를 제시한다. 커버 볼트 조임과 오일실 립 뒤집힘에 대한 벤트는 연속 절차가 아닌 별도 분기다.
  1. 감속기가 길들이기 단계인 운전 초기 24시간에 있고, 누유가 오일실에서 나오는 소량의 오일·그리스인지 확인한다. → 두 조건에 모두 해당하면 원문의 정상 누유 예외로 구분한다. 그 밖의 누유는 위치와 가능한 원인에 맞는 분기로 간다.
  2. 커버판·하우징 커버·베어링 커버·장착 플랜지의 가스켓 누유가 의심되면 해당 볼트를 조이고 감속기를 관찰한다. → 누유 여부를 다시 확인한다. / 중지: 조인 뒤에도 계속 새면 SEW‑EURODRIVE 고객 서비스에 문의한다. 3단계의 벤트로 이어서 진행하지 않는다.
  3. 오일실 립 뒤집힘이 의심되면 감속기를 벤트하고 관찰한다. 오일실 손상·마모가 의심되면 고객 서비스에 문의한다. → 벤트 후 누유 여부를 다시 확인한다. / 중지: 계속 새면 고객 서비스에 문의한다.
  4. 드레인 플러그·밸브 또는 브리더 플러그에서 새면, 오일 유면이 해당 설비의 표시 상한을 초과하면 유면을 교정한다. 브리더 장착이 잘못된 경우 브리더 플러그를 올바르게 장착하고 유면을 교정한다. → 교정 후 누유 여부를 다시 확인한다. / 중지: 계속 새면 사용을 보류하고 SEW‑EURODRIVE에 후속 지시를 요청한다.

## K-1107 · COMMON · T4 — 공급원 설비 상태를 함께 읽어 원인 범위를 좁힌 결과를 넘긴다

- **증상**: 공급받는 설비의 유지압·장력이 떨어졌는데, 공급원 설비도 이상인지 함께 봐서 다음 조에 넘겨야 한다.
