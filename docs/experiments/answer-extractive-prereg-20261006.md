# 추출형 답변(E1·E2) 사전 등록 (2026-10-06, 재생 전에 확정 — 결과를 본 뒤 바꾸지 않는다)

## 동기
10/6 Cursor 채점(`grade1006/compose.md`)에서 L1~L3는 모두 채택 문턱에 못 미쳤다(final1002 57건 기준 L2 최고: 충족 30·수정 5·미충족 22·sanity 충족 18, L1+L2+L3C: 28/5/24/17).
미충족의 뿌리는 모델이 자유롭게 쓴 본문이라, 본문을 카드에서 직접 뽑아 쓴다. 후처리뿐이라 모델 호출·재시도는 늘지 않는다.

## 구성 (컴포즈 층 `E1`, `E2`, 기본 꺼짐)
공통: 인용 카드 = 모델이 인용한 카드(`cited_card_ids`) 중 tool_results에 있는 것. 첫 번째 카드가 "1위 카드"다. 인용 카드를 하나도 찾지 못하면 답은 바꾸지 않는다.
측정 사실 줄(L1) = 기존 `l1_lines()` 결과(참고 카드면 REFERENCE_NOTE, 측정값이 없으면 NO_READING_NOTE, 있으면 최대 3줄).

### E1 — 순수 추출 (모델 본문을 쓰지 않는다)
답 = 아래를 줄바꿈으로 잇는다.
1. L1 줄
2. 1위 카드 `know_how`의 처음 2문장(문장 분리는 기존 `_sentences`). 두 문장을 공백으로 합쳐 220자를 넘으면 첫 문장만
3. 인용 카드에 정지 조건이 있으면 `정지 조건: ` + 카드 문구 그대로 최대 2개를 공백으로 잇는다. 정지 조건 = 카드 최상위 `stop_conditions` + `type_payload.steps[*].stop_conditions` (중복 제거, 등장 순서). 없고 `safety_flag`이면 기존 `_card_prohibitions(card)`의 첫 문장. 그래도 없으면 이 줄은 없다
4. `(K-xxxx 참조)` — 인용 카드 ID를 `, `로 잇는다

### E2 — 필터 (모델 문장을 살린다)
모델 답을 `_sentences`로 나눠, 아래 셋을 모두 통과한 문장만 남긴다.
1. 카드 근거 겹침: 문장(카드 ID 제거)에서 `[가-힣A-Za-z0-9]{2,}` 토큰을 뽑고, 토큰이 하나도 없으면 탈락. 토큰 t가 인용 카드 근거 텍스트(title·symptom·know_how·rationale을 공백으로 이은 것)에 부분 문자열로 있거나, len(t) ≥ 3이고 t[:-1](조사 한 글자 허용)이 있으면 "겹침". 겹침 비율 ≥ 50%여야 한다
2. 기존 가드 통과: `_answer_guard_errors(문장, 인용 ID, tool_results)`가 비어 있다(전부 정상 범위인데 벗어남, 방향 뒤집기, 카드·질문·측정값에 없는 수치)
3. 기존 L2 규칙 통과: `l2_filter(문장, …) == 문장`
남은 문장이 0개면 E1 답으로 대체한다. 있으면 답 = L1 줄 + 남은 문장을 공백으로 이은 것. 남은 문장에 카드 ID가 없으면 끝에 `(K-xxxx 참조)`를 붙인다.
