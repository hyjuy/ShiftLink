# T4 정답 검토 — 2026-10-01

질문 6개의 원문을 모두 보존했다. H-012·H-017의 주 정답을 K-1108로 변경하고, H-016은 K-1104와 K-1108의 공동 요구로 명시했다. H-008은 K-1104를 유지했다. 최초 검토에서는 H-018·H-019를 보류했다. 이후 H-019는 외부 원문을 대조한 별도 절차 K-1401을 추가하여 평가에 복귀했다. H-018만 보류하며 지식 없음 응답의 성공으로 채점하지 않는다. 검색 로직과 기존 사건 기반 T4 카드는 변경하지 않았다.

## 독립 검토와 재판정

주 에이전트가 변경 전 diff와 라벨·검색 스냅샷을 확인했다. 읽기 전용 검토를 세 갈래로 수행했다: A는 정답·순위를 보기 전 질문의 요구와 누락 조건을 추출, B는 카드 적용 범위·제외 조건·근거 사건 검토, C는 실제 점수 계약 검토. 주 에이전트만 수정했다. 독립 의견 → 원문/카드 대조 → 충돌 재판정 → 구조 검사/회귀 테스트 → 동일 결과 재채점의 하니스로 검증했다.

H-012와 H-017에서 최초의 엄격한 의견은 질문에 없는 알람 처리 절차나 운전 승인을 요구했다. 재검토에서 두 검토자가 K-1108의 직접 적용을 인정했다. H-017의 카드에는 운전 상태를 함께 쓰라는 적극적 처방이 명시되지 않은 한계가 남는다. 관측 사실을 기록하는 원칙으로 적용하되 계속운전 적정성·승인 여부를 카드가 판단한다고 해석하지 않는다.

수정 후 평가 계약 에이전트가 코드를 다시 읽고 AND/OR·안전·보류 계약의 구현 일치를 확인했다. dev/sanity에서도 제외 문항이 생기면 분모가 일치하도록 출력 계산을 통일했다. 현재 두 데이터에는 제외 유형이 없어 기존 점수는 유지된다.

## 공통 라벨 계약

- `primary_card_ids`: 질문에 직접 답하는 우선 정답. 기존 배열은 어느 하나면 충분한 OR를 유지한다.
- `acceptable_card_ids`: 독립적으로 질문에 답할 수 있는 허용 대안으로만 인정한다. 단어 관련성·일부 사실 지원을 넣지 않는다. **현행 코드의 이름 `partial`은 acceptable 인용만 있을 때의 점수 등급**이며 답변이 실제로 일부만 완성됐다는 의미가 아니다. 이번 대상에는 충분한 대안이 없다. 다른 문항의 기존 acceptable은 이번 범위에서 재판정하지 않았다.
- `safety_card_ids`: 명시적 적용 조건 아래 요구되는 안전 참고. 별도 safety 출력의 모든 ID가 있어야 `safety_ok`가 된다. 정답 인용 점수에 자동 포함되지 않으며 안전 전용 카드를 답 인용으로만 내면 wrong cite다.
- 일부 사실만 지원하는 카드는 단독 정답에서 제외한다. H-016처럼 함께 충분한 카드들은 `primary_card_sets: [["K-1104", "K-1108"]]`로 표현한다. 내부는 AND, 외부는 대체 가능한 완전 세트의 OR다. `primary_card_ids`는 세트 합집합과 일치해야 한다.
- `evaluation_status: "deferred"`와 `defer_reason`은 평가 보류다. 모델 실행과 점수 분모에서 제외한다. `answerable:false`만 보고 지식 없음의 성공으로 계산하지 않는다. 실제 KB 밖 질문은 기존 방식대로 평가한다.
- 공동 세트가 필요한 H-016은 rank-1만으로 성공할 수 없으므로 rank-1 점수에서 제외하고 top-k 전체 세트 포함 여부로 평가한다. 전체 20문항 중 평가 대상 18, rank-1 대상 17이다. 활성 answerable 14개 중 rank-1 answerable 분모는 13이다.

[score.py](../score.py)는 인용/검색의 완전 세트 포함을 검사하고, [route_score.py](../route_score.py)는 rank-1 제외 분모를 출력한다. [label_contract.py](../label_contract.py)는 구조와 카드 ID를 검사한다. 검색 함수·설정은 유지했다. [report.py](../report.py)는 공동 세트, 보류 사유, key_facts와 label_note를 표시한다. key_facts의 의미 충족 여부는 계속 사람 검토 대상이며 자동 ID hit를 답변 완성도로 부르지 않는다.

## 조사와 적용

[Stanford IR 교재](https://nlp.stanford.edu/IR-book/html/htmledition/evaluation-of-ranked-retrieval-results-1.html)의 집합/순위 평가와 graded relevance 구분을 적용해 관련 설비 카드와 직접 답변 카드를 구별했다. 현재 hit@k는 이진 완전 세트 포함 지표이며 Recall@k·MRR은 아니다. [AmbigQA](https://aclanthology.org/2020.emnlp-main.466/)의 복수 해석 구분은 H-017의 기록 요구와 운전 승인 요구를 분리하고, 부족한 조건을 임의로 채우지 않는 판정에 연결했다. [Ragas 공식 지표 문서](https://docs.ragas.io/en/latest/concepts/metrics/available_metrics/)가 구분하는 검색 문맥 평가와 답변 정확성을 따라 검색 ID hit와 생성 답변 완성도를 별도로 보고한다.

## H-019 후속 근거 보강

[S-04](../../../docs/sources/safety/S-04_HSE_work_completion_handover.md)는 HSE Shift handover의 인수자 교차 확인과 HSG250 PDF p.13 §23–24, p.14 §25, p.24 Figure 1을 직접 대조한 기록이다. 작업 오더·체크리스트의 구체적 확인 항목은 프로젝트 적용 해석으로 구분했다. HSG250의 역할별 확인은 작업허가제가 적용될 때만 안내한다.

별도 문헌 기반 T4 [K-1401](../../../docs/data/knowledge_cards/kb/20261001-handover-completion/cards.json)을 추가했다. 기존 T4 카드의 적용 조건이나 사건 기록은 넓히지 않았다. H-019 질문에 완료 사실이 없다는 점은 그대로이며, 새 정답은 완료 여부를 확인하는 방법이다. 판정 JSON의 `previous_deferred_label`에 이전 보류를 보존했고 `final_label`은 현재 실행용 정답과 일치시켰다.

위의 검색 검증 표와 `search_review_20261001.json`은 최초 라벨 검토 시점의 기록이다. 후속 KB 추가 전후와 다른 분모의 점수를 검색 성능 개선으로 해석하지 않는다. 현재 rank-1 제외는 H-016·H-018이며 H-019는 검색·인용 테스트 대상으로 복귀했다.

후속 검증: H-019 보류 복귀와 새 근거 카드 로딩을 요구하는 테스트를 먼저 추가하여 2 failed / 19 passed를 확인했다(RED 커밋 `3532a71`). 원문 근거·카드·정답을 반영한 뒤 관련 평가 테스트 21개, KB 통합·로더 테스트 12개가 통과했다. 통합 KB는 86장이고 원본 배치 재생성과 일치한다. 원문 내용과 작업허가제 조건부 적용은 별도 읽기 전용 검토에서 확인했다.

최초 후속 검증은 dev 21/30, sanity 29/30, T4 9/18이었다. H-019 검색 1위는 K-1401이지만 H-004는 K-1103으로 바뀌었다. 이후 실제 검색기와 변경 이력을 대조하여 H-004 회귀의 원인이 K-1401이 아니라 동시에 병합된 K-1101 증상 문구 변경임을 확인했다. 새 카드의 직접 영향으로 설명한 이전 판단은 정정한다. 생성 답변의 의미 충족률은 미검증이다.

## H-004 회귀 수정 및 별도 후속 과제

main의 `695c626`에서 K-1101의 symptom을 현장 말투로 바꾸면서 ‘인계’ 어간이 빠졌다. 이전 `5daffe9` KB를 실제 provider로 읽었을 때 H-004의 K-1101 점수는 7.0, 현재 문구에서는 4.5였다. K-1103은 양쪽에서 6.5이며 K-1401은 이 질문에서 0점이다. ‘인계’ 어간 가중치 2점과 ‘조’의 본문·근거 토큰 기여 차이 0.5점이 직접 차이를 만든다.

K-1101 symptom 한 필드를 이전 명사형 ‘원인 미해결·여러 단계 확인 진행, 확인 완료 범위·정상 결과의 다음 조 인계’로 복원하고 통합 KB를 재생성했다. 정답·질문·검색 로직·K-1401은 변경하지 않았다. H-004 적중 유지 회귀 테스트는 수정 전 1 failed / 21 passed(RED 커밋 `3898f67`), 수정 후 평가 테스트 22개와 KB·로더 테스트 12개가 통과했다. 최종 `route_score`는 dev 21/30, sanity 29/30, T4 10/18이며 H-004·H-019가 모두 적중한다.

H-012·H-017 검색 개선은 별도 작업으로 추적한다. 질문 원문과 정답 K-1108을 유지하고 최신 KB에서 top-5 및 점수 구성을 먼저 재현한다. 인계 의도와 관측·추정·미확인 구분을 반영하는 최소 검색 변경 또는 근거 범위 안의 카드 표현 보강을 검토한다. 완료 기준은 두 문항의 K-1108 rank-1 적중, H-004·H-019 적중 유지, dev ≥21/30·sanity ≥29/30 및 T4 전체 회귀 없음이다. 이 후속 검색 변경은 이번 PR 범위에 포함하지 않는다.
