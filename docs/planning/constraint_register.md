# ShiftLink MES 기능 제약 대장 (constraint register)

- 원본: `/home/claude/shiftlink_mes/개발계획_v2_260911.md` (개발계획 v2, 2026-09-11)
- 대상: "MES 기능" = 가상 라인 L1의 작업지시·설비 상태·알람·교대/인계 등을 담는 모의 MES 데이터와, 에이전트가 이를 읽기 전용으로 조회하는 계층(`list_handover` 등). 담당 허재원(Embedded).
- 이 대장은 문서 검토 결과이며 도메인 숙련자 검증·장비 시험·L2 전문가 승인이 아니다.
- 상태 기준: **확정** = 계획서에 승인·확정으로 기록 / **조건부** = 조건부 승인 또는 절차 승인 / **미결** = 별도 결정·승인 대기·실측 대기 / **추정** = 계획서에 "추정" 표기.
- 원문 인용은 계획서 문장을 그대로 옮겼고 필요 시 "…"로 줄였다. 해석이 들어간 영향 칸에는 "(해석)"을 표시했다.
