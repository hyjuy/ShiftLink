# PR 메모: T4 합성 카드 연구 자료와 후속 비교 설계

## 제목 제안

`docs: add T4 synthetic research and follow-up design`

## 요약

공통 T4 카드 25개, 장비별 카드 20개와 관련 합성 근거·검토·실험 기록을 문서화하고, 공통 M07/M08/M13/M16/M18의 수신 확인 및 미해결 상태 표현을 후속 버전으로 정합화했습니다. PDP와 CAU를 포함한 6개 장비군 비교 실험은 실행 전에 검토·동결했습니다.

현재 논리 카드 수는 45개입니다. 후속 COMMON 5개는 기존 카드의 버전 변경이므로 별도 카드로 더하지 않았습니다. 모든 카드는 개발 초안이며 KB 채택 상태가 아닙니다.

## 변경 범위

- 이전 T4 카드 후보·명세·검토와 공통 25개 카드, 장비별 20개 카드 및 파일럿 기록을 추가했습니다.
- 카드 45개의 핵심 내용을 카드별로 정리한 [인벤토리 표](t4-card-inventory-20260928.md)를 덧붙였습니다.
- M07/M08/M13에서 정확한 상태 수신과 내용 해결 대기를 분리했습니다. M16은 새 증빙의 도착과 대조 결과를 구분하고, M18은 명시적 무응답과 회신 기록 미첨부를 다른 대기 상태로 다룹니다.
- 6개 장비군 × 3조건 × 3반복, 총 54개 송수신 쌍을 사전 설계했습니다. 선택 T4 조건은 카드 전문 대신 `know_how` 필드만 사용합니다.
- 검토 수정 이력, 입력 해시, 경계 사례, 접근 편차와 다음 단계 인계 문서를 보존했습니다.

## 검증

- 후속 카드 스키마 5/5, 필수 필드 누락·공백 거부 50/50, 개발 카드 적재 차단 5/5를 확인했습니다.
- 원본 자료 67개 파일의 해시, 연결 대본 5개와 사실 참조를 확인했습니다.
- 비작성자 카드 검토와 비작성자 실험 설계 검토가 각각 통과했습니다. 설계 검토는 55개 입력 해시를 확인했고, 초기 검토와 7개 수정 전 스냅샷도 보존했습니다.
- 비교 설계는 사실 원자 69개, 미확인 원자 27개, 카탈로그 참조 21개, 실행 순서 54개를 검증했습니다.

## 해석 범위와 남은 일

기존 파일럿은 카드의 추가 효과를 입증하지 못했습니다. HPU 측정 대상 명칭의 경계 사례는 엄격 판정 1건, 대안 판정 0건으로 보존했습니다. 후속 역할 실험은 아직 실행하지 않았으므로 카드 효과, 현장 효과 또는 일반화 결과를 주장하지 않습니다. 사전 계획의 세 조건 비교는 새 역할 실행과 독립 판정이 다음 단계입니다.

기존 파일럿의 HPU/GR/RT/CV 결과에서 카드 수정 근거가 충분하지 않아 장비별 카드 20개는 수정하지 않았습니다. 이 PR은 운영 DB·출처 등록부·분할 정책·검색 구현·KB 채택을 포함하지 않습니다.

## 자료 접근 편차

최초 설계 컨텍스트에서 sealed로 지정된 프로토타입의 요약 메타데이터 1건이 우발적으로 노출되어 해당 작성자를 중단하고 새 컨텍스트의 작성자로 교체했습니다. 해당 컨텍스트 산출물은 사용하지 않았고 sealed 사건 원문이나 holdout 파일을 읽지 않았습니다. 편차와 조치는 [기록](../data/knowledge_cards/drafts/20260926-t4-followup/access-deviation.md)에 남겼습니다. 이 연구 작업 전체가 sealed 메타데이터 비열람을 완벽히 충족했다고 주장하지 않습니다.
