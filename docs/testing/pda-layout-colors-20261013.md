# PDA 색상·배치 변경 요약 (2026-10-13)

## 변경

- PDF의 밝은 배경·어두운 텍스트·파란 강조색을 적용했다.
- 승인된 홈 레이아웃에 인계 목록과 설비 현황을 배치하고, 스캔·설비 목록·챗봇 바로가기를 하단에 두었다.
- 짧은 답변·빈 상태·업로드 대기 내용을 중앙 정렬하고, 취소·인계 작성 등 하단 버튼을 가운데 배치했다.
- 업로드 안내를 “기기에 저장된 인계입니다. 클라우드 업로드를 기다리고 있습니다.”로 바꿨다.
- 최신 main(0424088)의 로그인·촬영·확인 체크·챗봇·해결 기록을 유지했다. 홈 대수는 API 데이터를 사용하며, 읽지 못한 상태는 `—`로 표시한다.
- 검토용 44개 화면 원본은 `docs/design/pda_ui/approved-20261013/index.html`에 모았다. 정적 시안 데이터와 실제 운영 데이터는 구분한다.

## 검증

- PDA 관련 Node 회귀 스크립트와 새 홈 집계 테스트 통과.
- 실제 PDA HTML/JS를 로컬 API 응답에 연결해 1280×800, 1024×768, 390×844에서 가로 넘침·취소 버튼 중앙 정렬·업로드 대기 중앙 정렬을 확인했다.
- 인계 체크, 긴 업로드 대기 목록 스크롤, 이상 설비 확인 이동, 해결 기록 진입, 필수 인계 입력 동작을 확인했다. 브라우저 JavaScript 오류 없음.
- 화면 제공·API 프록시 서버 테스트 2건 통과. 전체 서버 테스트 실행에서는 8건 통과, 얼굴 프레임 서버 테스트 1건 실패했다(`test_face_frame_is_local_and_rejects_unknown_id`: 얼굴 미등록 처리 중 응답 타임아웃). 해당 얼굴 서버 코드는 이번 변경에 포함하지 않았다.
- `git diff --check`, `graphify update .` 실행.
