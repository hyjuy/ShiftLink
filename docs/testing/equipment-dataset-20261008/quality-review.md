# CNN 장비 사진 독립 품질 검토

검토일: 2026-10-08. 사용자 요청으로 위임된 사진 품질 검토 서브에이전트의 보고서다. 한글이 물음표로 손상된 기록을 UTF-8로 복구했다. 검토자는 사진과 촬영 코드를 수정하지 않았다.

## 확인 범위

원본 captures 10대 × 600장 = 6000장의 JSON을 전수 분석해 타깃 bbox 면적과 이웃 장비 bbox 면적 비율을 계산했다. bbox 면적은 실제 실루엣 픽셀 면적이나 가림 비율과 다르다.

원본은 장비별 최소 타깃 면적, 최대 이웃/타깃 비율, 인덱스 0·180·300·480·570을 골랐다. 70개 표본 칸 중 중복을 뺀 67개 실제 이미지를 육안 확인했다. 추가 HPU/PDP/CAU 각 24장, CAU 시험 24장, 이후 GR-01/02·RT-01/02/03·CV-01/02 각 36장씩 확인했다. 추가 촬영 10대 모두 대표 사진 검토에 포함했다.

반복 문제 그룹은 별도로 확인했다: PDP CabinetSidePanel 73장, CAU SideServicePanel 53장, CAU Fan guard rim 132장, RT-03 BearingCover.012 7장, CV-01 방향6 30장, CV-02 방향3 30장. 합계 325장이며 앞선 표본과 중복되므로 전체 고유 검토 건수로 단순 합산하지 않는다.

주로 396~420픽셀 폭 축소판을 확인했다. CV-02 EQ-0010_0128, PDP EQ-0002_extra_0138, CAU EQ-0003_extra_0009/_0185, CV-01 EQ-0009_extra_0190/_0200, RT-03 EQ-0008_extra_0310/_0320은 1280×720 원본도 확인했다.

전체 이미지 육안 전수검사, CNN 학습, 실제 카메라 정확도 검증은 수행하지 않았다. 정확도 저하·개선 수치를 주장하지 않는다.

## 실제 발견한 문제

원본에서 이웃 장비/타깃 bbox 면적 비율이 1을 넘는 건수는 CAU 0, CV-01 37, CV-02 90, GR-01 0, GR-02 133, HPU 0, PDP 0, RT-01 16, RT-02 118, RT-03 94였다. 같은 종류 이웃도 포함한 통계이며 확정 제외 장수가 아니다.

대표 불량 사례는 다음과 같다.

- EQ-0009_0337: CV-01 타깃 약 4.3%, 이웃 장비 약 9.36배. 정답이 가려진 원경이다.
- EQ-0010_0128: CV-02 타깃 약 3.6%, 이웃 장비 약 27.93배. 앞쪽 RT 롤러·기둥 뒤에 정답이 작게 나온다.
- EQ-0005_0559/_0560: GR-02 타깃 약 6.7%/6.5%, 이웃 장비 약 2.85배/2.55배. 컨베이어·이송 프레임이 중심이고 구동부는 원경이다.
- EQ-0007_0288 / EQ-0008_0280: 타깃 약 5.6%/6.6%, 이웃 장비 약 7.88배/6.17배. 가까운 RT·코일이 정답을 가린다.
- PDP EQ-0002_extra_0138/_0159: 평평한 측판·바닥·캐비닛 모서리만 보여 분전 패널 맥락이 부족하다.
- CAU EQ-0003_extra_0009: 팬 뒷면 직사각판과 얇은 옆모서리만 보인다. 원형 팬 정면이 없다.
- CAU EQ-0003_extra_0185: 볼트 정비판이 대부분이고 팬·조작부·탱크 맥락이 부족하다.

## 반복 유형 검토와 초기 제외 권고

초기 독립 검토 제외 권고는 108건으로 확장한 뒤 마지막 장비 검토를 반영해 146건으로 갱신했다. 이 목록은 검토 당시 권고이며 최종 판정이 조정될 수 있다.

- PDP CabinetSidePanel 방향4/5 48장: 분전 전면이 없는 평판·캐비닛 모서리 중심으로 제외 권고했다. 방향6은 대부분 전면도 보여 유지하고 0188/0193/0198/0202/0203만 추가 제외 권고했다. 0195/0200/0205는 전면 형태가 보여 유지했다.
- CAU Fan guard rim 방향0 25장과 방향11 14장: 팬 정면 없는 뒷면 하우징·모서리·파이프 중심으로 제외 권고했다. 방향1의 비스듬한 그릴과 방향2~4 팬 정면은 식별되어 유지했다.
- CAU SideServicePanel: 루버와 측면 전체가 함께 보이는 것은 유지했다. 평판이 대부분인 0160/0175/0178/0184/0185/0186/0190/0193/0196/0198은 제외 권고했다.
- GR-01/02·RT-01 각 36장 표본에서는 새 확정 제외가 없었다. MotorMountBolt라는 이름이어도 실제 사진에 모터 몸통·플랜지·감속기 하우징이 보여 유효하다.
- RT-03 BearingCover.012 중 0310/0312/0314/0320/0323은 넓고 무늬 없는 커버판이 롤러·베어링 맥락을 가려 제외 권고했다. 0316/0318은 베어링과 롤러가 보여 유지했다.
- CV-01 방향6 0180~0206은 코일·RT 롤러·넓은 이송판이 지배하고 정답 벨트 컨베이어가 작거나 가려져 27장을 제외 권고했다. 0207~0209는 헤드·측면 맥락이 더 잘 보여 유지했다.
- CV-02 0060 및 0090~0094는 앞쪽 롤러·넓은 판 뒤에 정답이 작게 보여 6장을 제외 권고했다. HingedSlat 0095~0113은 하부 판이 넓어도 슬랫·가드 형태가 함께 보여 유지했다.

146건은 이전 108 + CV-01 27 + RT-03 5 + CV-02 6이다. 자동 기준과 중복되므로 실제 감소량을 단순 합산하면 안 된다.

## 어둡지만 식별되는 사진 유지

dim 프로필과 낮은 평균 밝기만으로 일괄 제외하지 않는다. GR-02 EQ-0005_extra_0030/_0180, RT-01 EQ-0006_extra_0160/_0320, RT-03 EQ-0008_extra_0100/_0110/_0250/_0260, CV-02 EQ-0010_extra_0190/_0200은 어두워도 모터·롤러·베어링·슈트 형태가 보여 유지 권고했다. 밝기 자체와 의미 있는 특징 가시성을 구분했다.

타깃 bbox 8% 미만과 다른 종류 bbox가 타깃의 1.2배를 넘는 조건은 검토 후보 선별에 유용하다. 최소 가로/세로 15% 조건은 길고 낮은 컨베이어 전경을 과도하게 제외할 수 있어 강제 기준으로 권하지 않았다.

일부 가림 물체는 objects에 별도 장비로 나타나지 않았다. CV-01 0190처럼 다른 클래스 우세 자동검사만으로 놓칠 수 있으므로 실제 RGB 영상 검토가 필요하다. 선별 후 장비·split·방향·조도·전경/근접별 잔여 수를 확인한다. 동일 합성 공장과 모델에서 얻은 사진의 실제 촬영 일반화 성능은 별도 실제 사진 평가가 있어야 알 수 있다.

## 최종 판정과 삭제 정책

상위 작업자의 최종 검토 전달에 따르면 CAU EQ-0003_extra_0207/_0042/_0105/_0124/_0250/_0255 및 RT EQ-0006_0544, 총 7장은 식별 가능한 사진으로 보존 권고가 반영될 예정이다. 초기 권고와 최종 패키징 판정이 다르면 최종 판정을 따른다.

최종 전달 집계는 원본 6000장과 추가 3600장, 총 9600장 중 **8951장 유지 / 649장 제외**다. 이 수치는 상위 작업자의 최종 집계이며 본 검토자가 8951장 전부를 육안 확인했다는 뜻이 아니다.

사용자의 최신 지시에 따라 제외 원본과 복사본은 삭제하고 사유 기록을 남기는 정책으로 변경했다. 이전의 원본 보존 제안은 현재 정책이 아니다. 실제 삭제·패키징은 상위 작업자가 수행하며 이 보고서 수정 자체가 삭제 완료를 증명하지 않는다.

독립 사진 품질 검토는 완료했다. 대표 표본과 발견된 반복 불량 그룹의 판단이며 전체 이미지 육안 전수 통과나 CNN 성능 보장을 주장하지 않는다.
