# 페르소나 합성 데이터에서 T4 카드 품질을 높이는 연구

검토일: 2026-09-26. 논문의 원문·저자 제공 페이지를 확인했다. 아래 연구는 제조업 인수인계 T4 카드 자체를 검증한 연구가 아니다. 페르소나 생성, 대화 시뮬레이션, 경험의 지식화, 평가 방법을 ShiftLink에 적용하는 제안이다. 이번 검색 범위에서 이 네 가지를 제조업 T4 카드 생성에 직접 결합·검증한 논문은 확인하지 못했다.

## 이 프로젝트의 생성·평가 설계 제안

다음은 위 연구에서 가져온 아이디어를 조합한 프로젝트 제안이며 논문에 그대로 있는 제조업 검증 절차가 아니다.

1. **가상 세계의 사실을 먼저 고정한다.** 설비, 관측, 문서 상태, 담당 역할, 채널, 시간 관계를 합성 원장에 적는다. 현실 자료가 없는 사실도 가상 가정으로 명시하면 설계할 수 있다. 원장을 바꾸어 실패를 사후 성공으로 만들지는 않는다.
2. **페르소나별 정보 접근을 다르게 한다.** V-11의 구술·시각/수치 누락, V-12의 항목 대조·정성 세부 누락, V-13의 기록 맥락·수신 여부 누락을 활용한다. 페르소나가 모르는 상대 정보는 대화를 거치기 전 입력하지 않는다.
3. **실패와 보완을 비교한다.** 예: '압력은 정상'이라는 가상 인계에서 관측시각이 전달되지 않았다. 수신자는 이를 현재값으로 오해한다. 개선 방법은 관측시각 또는 시각 미확인을 함께 전달하고, 상대가 그 구분을 되짚게 하는 것이다. 원장에도 시각이 없으면 시각을 만들어 보완하지 않는다.
4. **일반화한 방법을 카드로 만든다.** 사건의 설비명·문장만 복사하지 않고 적용 상황, 필수정보, 대상, 시점, 채널, 확인, 미완료 처리를 추출한다. 좋은 결과만 골라 근거로 삼지 않고 실패·비적용 조건도 보존한다.
5. **다른 가상 상황에서 비교한다.** 동일 상황에 카드 없음 / 일반 5항목 체크리스트 / 해당 카드의 세 조건을 비교한다. 모델·입력·예산을 맞추고 반복 실행한다. 이름을 바꾼 파생본은 같은 그룹에 두고 생성·개선용과 평가용을 나눈다. 현재 이 비교 실험은 미실행이다.

| 우선 측정 항목 | 제안 정의 |
|---|---|
| 필수 정보 보존 | 원장이 요구한 정보 중 수신자가 정확히 회신한 항목 비율 |
| 미확인 상태 보존 | 알 수 없는 값을 그대로 미확인으로 유지한 비율 |
| 잘못된 승인 추론 | 수신·정비 결과·문서 부재를 운전/정비/재가동 허가로 바꾼 경우 수 |
| 미완료 식별 | 무응답·부분 회신·충돌을 완료로 잘못 처리한 경우 수 |
| 정보 누출 | 송신하지 않았고 수신자에게도 주지 않은 사실을 수신자가 아는 경우 수 |
| 재사용성 | 설비·역할·채널·정보공백 조합이 다른 평가 상황에서의 성능 변화 |

평가용 시나리오의 기준 답은 인계문 작성자에게 주지 않는다. 별도 평가자는 원장과 송수신 결과를 대조한다. 문장 의미 판정이 필요한 부분은 규칙 검사만으로 해결됐다고 표시하지 않는다. 작은 표본의 비율을 정밀한 신뢰도 점수로 해석하지 않는다.

## 이번 산출물의 위치

이번 25건은 **기존 방법 → 가상 원장 → 인계·되물음·보완·응답 대본** 순으로 구체화한 개발 예시다. 독립 실험에서 발견한 25개 방법이라는 뜻은 아니다. 원장 참조와 문서상 visible_to 정합성을 정적으로 검사하고 별도 에이전트가 내용을 검토한다. 실제 역할별 에이전트 대화 실행, 카드 유무 비교, 별도 평가 상황의 효과 측정은 아직 수행하지 않았다.

현장 원문이 없다는 이유로 이 합성 개발 작업을 실패로 계산하지 않는다. **합성 시나리오의 내부 일관성**, **독립 시뮬레이션의 성능**, **실제 현장 타당성**을 서로 다른 평가 결과로 기록한다.
