## 반영 기준

- 기존 `ShiftLink-PDA-LLM-1280x800.pdf`의 밝은 배경, 텍스트 색상, 강조색을 유지합니다.
- 홈은 승인된 인계 상황·설비 현황 카드와 하단 바로가기 레이아웃을 사용합니다.
- 짧은 빈 상태와 업로드 대기 내용은 본문 영역 중앙에 배치합니다.
- 하단 취소·다시 질의·저장·이동 버튼과 안내는 가운데에 배치합니다.
- 업로드 안내는 “기기에 저장된 인계입니다. 클라우드 업로드를 기다리고 있습니다.”로 바꿉니다.

## 실제 PDA와 시안의 구분

실제 앱은 `shiftlink/mes/web/pda.html`, `pda.js`입니다. 홈 수치·인계 목록·설비 이상은 현재 API 데이터를 표시합니다. API를 읽지 못하면 정상·이상 대수에 `—`를 표시합니다. 저장·검색 API 계약은 유지합니다. 인계 작성의 저장 버튼은 화면 하단 중앙에 고정하며, 좁은 화면에서는 입력 영역을 스크롤합니다.

이 폴더의 화면은 예시 데이터로 만든 정적 검토안입니다. 수치·답변·저장 결과가 실제 운영 결과를 뜻하지 않습니다. 챗봇 37~44번은 기존 PDF의 UI 제안이며, 실제 홈의 챗봇 버튼은 기존 설비 지식 질의로 연결됩니다. 최신 main의 로그인·촬영·인계 확인 체크·대화형 질의·해결 기록 기능을 유지합니다. 이번 변경은 새 대화 저장 기능을 추가하지 않습니다.

이미지와 PDF를 Git에 중복 저장하지 않고 HTML/CSS/JavaScript 원본을 보관합니다. 기기 배포와 현장 터치 검증은 별도입니다.
