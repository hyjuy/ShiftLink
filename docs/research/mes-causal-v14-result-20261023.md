## 성능 해석의 한계

p95는 탐지 성공 사건의 개입 시작 기준 합성 시간이다. 실제 추론·대기·통신·PDA 표시 시간은 포함하지 않는다. 미탐은 따로 공개했으며 고착 품질 스트레스2건의41초 지연도 남는다.10초 내 비율35.7%가 보여주는 빠른 탐지의 한계도 유지한다.

정상 노출13440초는 약3.73합성시간이다. 관측0건은 현장 오통지율0의 증거가 아니다. 반복된 개발·후보 선택과 동일 A/B 동역학·고장 종류·작성 가정 안의 평가이며 새 공장/실제 장비 일반화를 입증하지 않는다. 첫55건·이전36건·서로 다른42건의 수치를 직접 전후 성능으로 비교하지 않는다. 온도 상승은 부하·마찰 등 다른 이유도 가능하며 원인 확정·정비 지시는 아니다. 실제 센서와 기기 검증을 거쳐야 한다.
