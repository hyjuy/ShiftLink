# 네이밍 레지스트리

4명이 동시에 스키마·파이프라인·데이터를 건드리다 보니 클래스명·함수명·환경변수명이 겹치거나 미묘하게 다른 이름으로 중복 정의될 위험이 있다. 이 폴더는 그걸 막는 **단일 진실 원천**이다.

## 규칙

1. **새 공유 이름(다른 모듈에서도 쓸 클래스/함수/환경변수/ID 접두어)을 추가하기 전에 `registry.md`에 먼저 검색**한다.
2. 새로 추가하거나 이름이 바뀌면 **같은 PR 안에서** `registry.md`도 같이 수정한다 (코드 PR에 딸린 부수 변경 — 별도 PR 필요 없음).
3. 이름이 겹치거나 애매하면 여기서 먼저 상의하고 코드를 쓴다. 발견 즉시 `docs/branching.md` 규칙대로 PR 리뷰에서 지적한다.
4. **함수 하나·클래스 하나당 한 줄.** 모듈 전체를 옮겨적지 않는다 — 공개 API(다른 모듈이 import해서 쓰는 것)만 올린다. 모듈 내부에서만 쓰는 private 헬퍼는 등록 안 해도 된다.
5. 담당자 칸은 "이 이름을 최초로 도입한 사람" — 이름을 바꾸고 싶으면 그 사람에게 먼저 물어본다.
