# 지식카드 생성을 위한 원문 탐색

정리일: 2026-09-22 (Asia/Seoul)

## 목적과 탐색 기준

현재 원문 탐색의 목적은 지식카드 생성이다. 실제 고장 사건 수집 기준을 모든 원문에 적용하지 않는다. 실제 수행 조치·복구 결과가 없어도 원리, 증상, 원인 후보, 점검 방법, 적용 조건을 설명하는 자료는 카드 근거 후보가 될 수 있다.

판단 기준은 **지식카드로 만들 내용이 있고 그 내용을 원문에서 뒷받침할 수 있는가**이다. 냉연 공정에 직접 해당하는 자료를 우선하고, 공통 베어링·감속기·유압 지식은 적용 범위를 표시해 함께 검토한다. 실제 사건을 작성할 때에는 별도로 [사건 채택 기준](../events/README.md)을 적용한다.

## 원문과 매뉴얼의 구분

원문과 매뉴얼은 서로 배타적인 개념이 아니다. 원문은 카드의 근거가 되는 원래 자료를 뜻하고, 매뉴얼은 문서의 종류다. 제조사 매뉴얼도 원문이 될 수 있다.

| 구분 | 의미 | 생성할 수 있는 지식카드 |
|---|---|---|
| 원문 | 매뉴얼·기술자료·논문·사례보고서 등을 포함하는 원래 자료 | 모든 유형 |
| 매뉴얼 | 운전·점검·정비 방법을 설명하는 문서 | 점검 절차, 고장 원인 후보, 작업 조건 |
| 기술자료 | 설비 원리와 손상 메커니즘 등을 설명하는 문서 | 개념, 원인–증상 관계, 진단 시 주의점 |
| 사례보고서 | 특정 현장에서 발생한 문제와 대응을 설명하는 문서 | 조건이 명시된 진단·조치 사례 |

## 냉연 관련 원문 후보

아래 자료는 제조사가 공개한 사례·기술자료이며, 현장 작업 매뉴얼 자체는 아니다. 카드 주제는 검토 후보이며 생성·채택 완료를 뜻하지 않는다.

| 대상 | 원문 | 카드 주제 후보 | 확인 상태 |
|---|---|---|---|
| 냉간압연 베어링 | [NSK — Cold Rolling Mill: Steel Strip, PDF](https://nskmetals.com/documents/case-studies/NSK-Case-Study-Cold-Rolling-Mill_SteelStrip.pdf) | 철강 절삭편 유입에 따른 베어링 손상, 손상 베어링·윤활제 분석, 오염 환경에서의 베어링 선정 | 웹 도구로 2쪽 PDF 본문 확인 |
| 냉간압연 작업롤·초크 윤활 | [FUCHS — RENOLIT CXS AM 1 사례 원문](https://www.fuchs.com/us/en/products/download-center-1/case-studies/case-study-renolit-cxs-am-1/) | 수분에 의한 손상 흔적, 그리스 선정, 급지 간격과 그리스 상태 점검 | 공식 웹 본문 확인. PDF 검색 색인 확인, PDF 직접 열람 실패 |
| 강대 산세라인 공급부 감속기 | [SKF — Drivelines, Metals Industry, PDF](https://cdn.skfmediahub.skf.com/api/public/0901d196800a4e07/pdf_preview_medium/10404_EN_Driveline_for_Metals_pdf_preview_medium.pdf) | 충격하중과 감속기·커플링 반복 고장, 베어링 배치의 적합성, 설계 개선 사례 | 공식 PDF 검색 색인에서 관련 사례 확인. 전문·페이지 대조 필요 |

이 목록은 SPM 자료 탐색 이후 다른 제조사로 검색을 확대한 결과다. SPM에서 냉연 자료가 전혀 없다는 결론을 뜻하지 않는다.

### 로컬 원문 파일

2026-09-22에 위 링크의 원문 3건을 다운로드했다. NSK·SKF는 PDF, FUCHS는 지정된 웹페이지의 HTML 원본이다. PDF 헤더·종료 표식과 HTML의 제목·본문 키워드를 확인했으며, 로컬 PDF 전체 렌더링 검증은 수행하지 않았다. HTML의 외부 이미지·스타일 파일은 포함하지 않는다.

## 카드 작성 시 적용할 구분

- 카드에는 원문이 다루는 설비와 운전·측정 조건, 적용 범위를 붙인다.
- 특정 제품으로 개선된 사례를 모든 설비에 적용되는 정비 지침으로 바꾸지 않는다.
- 제조사의 권고, 실제 수행한 조치, 관측 결과, 추정 원인을 구분한다.
- 실제 사건 기록이 없어도 일반 지식카드의 근거 후보가 될 수 있지만, 원문에 없는 수치·절차·복구 결과를 추가하지 않는다.

생성 전에는 사용할 절·페이지 또는 웹 heading과 뒷받침되는 주장을 검토하고, [원문·출처·평가 분할 계약](../policies/source-and-split-contract.md)에 따라 출처 상태와 계보를 관리한다. 카드 형식은 [현재 작성 가이드](../../../seeds/카드_작성_가이드_초안.md)를 따른다. 이 탐색 메모 자체는 원문을 대체하지 않으며 출처 등록부의 승인 상태를 변경하지 않는다.
