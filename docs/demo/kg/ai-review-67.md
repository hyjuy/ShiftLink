2026-10-22 — **원문 충실성 AI 교차 검토 완료, 후보 상태 유지**.

후속 상태: 사용자의 수정 지시에 따라 R1–R6 반영과 재검증을 완료했다([최신 검증](revision-validation.json)). 아래 순위와 종합 판단은 수정 전 검토 이력이다. 새 /67 심사를 실행한 것으로 해석하지 않는다.

사용자가 요청한 사람 검수 대상의 원문·정의·매핑 판단을 6개 전략으로 검토하고 7번째 심판이 비교했다. 동일 저장소에서 동시 실행 제한에 맞춰 나누어 수행했다. 안전·제조사 승인이나 현장 검증을 취득한 것으로 기록하지 않는다.

## 종합 결정

Adversarial의 실제 오류/해석 위험 구분을 기준으로 삼는다. 개념 18개·후보 관계 20개를 유지한다. 이번 검토에서 연결을 삭제하거나 계약을 바꿀 근거는 확인하지 못했다. 모든 후보는 `needs_review`로 남기며, AI 검토 완료를 그래프의 검수 승인으로 바꾸지 않았다.

실제 수정 요청은 K-1004의 동일 조건 및 MES 기준 누락, K-1105의 잘못된 보류 요약, K-1301의 출력 저하 관측 처리 사유다. K-1107 보류 사유와 K-1307/K-1323의 배타 조건처럼 읽힐 수 있는 정의·요약은 보완 요청이다. 정확한 대상과 제안은 [수정 요청](revision-requests.md)에 있다. 담당자 소유 파일은 보존했다.

- K-1001 압력 없음과 K-1203 압력은 읽히나 부족은 분리한다.
- K-1004는 소음 AND (유량 저하 OR 압력 저하) AND 거품, K-1011은 운전·부착물 없음·동일 조건 정상 회전수 비교를 보존한다. 정상 기준이 0 또는 미상일 때 비율을 실행 기준으로 쓰지 않는다.
- K-1201/K-1202는 같은 1.2 bar 초과 관측을 공유한다. 정확히 1.2 bar는 정상 범위에 포함한다. K-1301/K-1303은 압력 저하 관측만 공유하며 두 카드 전체의 의미가 같다는 뜻은 아니다.
- K-1323은 3개 독립 관측으로 나눈 현재 후보를 유지한다.
- 비안전·문자열 증상 28장 중 연결 18장, 보류 10장이다. 안전 56장과 null 13장(중복 11장)은 연결 0개를 유지한다. 안전 문자열 45장의 서술 후보를 그래프에 승격하지 않는다.
- 원문 인용 222건 중 판본 미상 42건(EV 41건, 마스터 참조 1건)은 11장에 걸쳐 보류한다. K-1101:4, K-1102:4, K-1103:5, K-1104:4, K-1105:5, K-1106:4, K-1107:3, K-1108:3, K-1109:6, K-1110:2, K-1111:2. 판본을 추정하지 않는다.

[86장 검토 대장](ai-review-cards.json)은 원문 증상·기존 사유·현재 연결·AI 처리 판단·수정 요청 ID를 카드별로 기록한다. 기계적으로 생성한 대장이며 각 행에 6명의 개별 승인표를 의미하지 않는다. 입력 해시는 README 및 재검증 보고서와 연결한다.

## 남은 확인

원문 충실성 검토는 이번 AI 검토로 수행했다. R1–R6 수정 반영·재검증은 완료했다. 누락 문서 판본 확보, 실제 장비·안전·제조사 임계값 확인은 미완료다. 합성 자산 10개는 실물 자산 확인의 증거가 아니고 AssetPart는 미구현이다. S30h·MES·PDA 답변 연결, GraphRAG, 성능 개선 및 정식 온톨로지 달성은 이번 결과에 포함하지 않는다.
