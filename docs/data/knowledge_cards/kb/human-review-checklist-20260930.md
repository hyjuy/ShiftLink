## 공통 확인 사항

- 수치의 출처가 가상 MES 정상 범위인지, 합성 사건의 관측값인지, 제조사 또는 승인된 현장 기준인지 구분한다.
- 측정 위치·설비 모델·운전/정지 상태·관측 시점·단위가 맞는지 확인한다. 가상 MES는 해당 run의 config_id·실제 구성·quality=good을 확인한다.
- 가상 정상 범위의 양끝은 정상에 포함한다. 범위 이탈을 고장 원인 확정이나 정비·재가동 허가로 사용하지 않는다.
- 수치 미기록 또는 현장 기준 미확인은 보완 대상으로 남긴다. 소음·기포·방호 복구·승인 기록처럼 별도 관찰이 필요한 항목도 확인한다.
