# PDA UI v2 작업 자료

- `figma-v2-comments-20261015.md`: 원본 코멘트 정리
- `figma-v2-screen-flow-20261015.md`: 화면 경로·회의 결정·기기 배포 검증 기록
- `v2-comment-patch.js`: 적용 전 화면 점검
- `v2-comment-apply.js`: 2차 시안 코멘트 적용 소스
- `v2-finalize-design.js`: 기존 적용본의 연결·체크박스 보완 소스
- `shiftlink-v2-plugin/`: 최종 보완용 개발 플러그인. 코멘트 적용본이 있는 기존 2차 페이지를 전제로 한다.
- `account-entry-plugin/`: 계정 로그인 화면을 프로토타입 시작점으로 설정한다.

Figma 저장 연결 오류로 최종 보완·계정 첫 화면의 실행과 클라우드 저장은 검증되지 않았다. PDA/MES 코드는 실제 기기에 적용했으며, Figma 전체 완료를 의미하지 않는다. 플러그인은 해당 파일의 노드 ID에 종속된다.
