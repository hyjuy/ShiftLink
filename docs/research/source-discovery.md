# 첫 지식카드용 원문 탐색·접근 상태 보고서

확인일: **2026-09-22 (Asia/Seoul)**

범위: HPU·GR·RT·CV 및 공통 안전·인계. **원문 탐색 결과이며 생성용 승인이나 전문가 검토 결과가 아니다.**

## 1. 현재 근거 공백

### 대조 기준과 확인 한계

- **최종 대조 기준**: [출처 등록부](../../seeds/source_registry.json), [출처·분할 계약](../data/policies/source-and-split-contract.md), [생성 가이드](../guides/card-generation.md). 등록부는 `registry_version=1`, `recorded_at=2026-09-22`, **16개 출처 모두 `pending_review`, `approved_scope=[]`**다. 원문 후보의 본문 확인과 생성용 승인은 별개다. 등록부는 수정하지 않았다.
- 조사 시작 때 일부 지정 파일이 없었으나 최종 검증 중 작업 트리 구성이 변경된 것을 발견했다. 이 에이전트는 브랜치를 전환하지 않았다. 최종 확인한 브랜치는 `docs/answer-key-format`, HEAD는 `b1972f9`다. 경로 이동과 새로 확인 가능한 자료를 다시 대조하여 **최종 상태를 본문에 반영**했다. 초기 부재·실패는 §5에서 시점별로 구분한다.
- 요청된 계약은 현재 `docs/data/policies/source-and-split-contract.md`, 매뉴얼·안전 자료는 `docs/sources/manual/`·`docs/sources/safety/`, 기준정보는 `docs/data/reference/00_plant_and_relations.json`에 있다. [매뉴얼 목록](../sources/manual/README.md), [다운로드 기록](../sources/manual/download-status.md), [안전 근거 목록](../sources/safety/README.md)과 등록부를 함께 대조했다.
- [설비 사전](../design/설비_사전_항목_목록_v0.1.md)과 [공통 기준정보](../data/reference/00_plant_and_relations.json)의 설비군 모델은 `가상-HPU-45L`, `가상-GR-315`, `가상-RT-1200`, `가상-CV-800`이다. 실제 설치 제품·판본은 확인되지 않았다. RT의 구조 원문은 여전히 부족하다.
- 최종 [작성 가이드](../../seeds/카드_작성_가이드_초안.md)와 [스키마](../../shiftlink/agent/schemas.py)는 **v1.1 / T1~T6**다. T3는 단계별 `action`·`expected_result`, T4는 `required_context`·`recipient_role`·`timing`·`channel`·`acknowledgement`, T6는 `restart_type`의 근거가 필요하다. 단계 수만으로 T3를 판정하지 않으며, 순서·조건·관측 결과를 창작하지 않는다. 실패 기록의 `action`·`observed_result`도 실제 자료가 필요하다.
- 카드별 생성 요청서는 제공되지 않았다. 우선순위는 현재 설비 사전과 가이드의 최소 근거를 기준으로 정했다. 사건 파일·sealed 사건·holdout 정답은 열람하지 않았으며 검색 질의에도 사용하지 않았다. 배정표나 정답 파일을 열지 않고 계약 문서의 사용 제한만 확인했다.
