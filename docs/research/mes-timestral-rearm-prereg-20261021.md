# 재무장 결합 실험 사전 고정

2026-10-21. 현재 보존형 결합의 탐지·오경보를 유지하면서 중복을 현재 EWMA 이하로 줄이고 최근 확인 자료의 p95를 줄이는 추가 실험이다. 모델27,821,184 parameters/FP32/68채널/64과거프레임/다음1프레임, CPU1thread/interop1/worker1/batch1, checkpoint·정상 통계·임계값을 유지한다. 새 학습·압축·운영 변경·Pi 배포는 하지 않는다.

이전35·45·51·47사건을 모두 개발 자료로 전환한다. 합계178사건이며 후보 수를 곱해 독립 표본으로 세지 않는다. 기존 보존형 설정gap3/hold_z3.5/hold_ratio.025/early_scale1/early_z2.5를 대조로 재현한다. 채점·데이터 loader·모델은 frozen helper를 재사용한다. 새 train은 적합하지 않고 test 본문은 읽거나 해시하지 않는다.

후보는 현재 보존형 경보 OR (TSratio>early_scale AND rawZ>=early_z)를 원하는 진입 신호로 사용한다. 초기에는 armed다. ON은 원하는 신호가 유지되는 동안만 유지하며 추가 ON 연장 분기는 없다. 신호가 OFF되면 실제 경보를 OFF하고 disarmed로 바꾼다. OFF전환 프레임은 정상 복귀 횟수에 포함하지 않는다. 이후 EWMA OFF AND rawZ<rearm_z AND TSratio<=.1인 유효 프레임이quiet회 연속이면 재무장한다. 재무장 완료 프레임에는 진입하지 않고 다음 프레임부터 허용한다. 이상 신호가 다시 높아져도 정상 복귀 없이 강제 재진입하거나 시간만으로 재무장하지 않는다.

누락/nonfinite는 경보OFF·quiet0·disarmed이며 정상 복귀 증거가 아니다. run/time/sequence/mode/예측준비 상태 단절은 기존 reset 계약에 따라 새 구간으로 초기화한다. 관측·시각만 사용하고 라벨을 상태 결정에 사용하지 않는다. UI알림 숨김 없이 실제 경보 상태를 기존 scorer로 평가한다. 재진입 차단으로 고장 중 경보 커버리지가 줄 수 있으므로 활성 원인 경보 시간과 억제 프레임도 보고한다.
