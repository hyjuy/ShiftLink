# KB-20260929-A 지식카드 ↔ 가상 MES 신호 대응표

갱신: 2026-10-01. 상태: 초안. [기계 판독용 JSON](mes_signal_map.json)과 같은 현재 카드·신호 정보를 기록한다. 연결 강도는 의미 대응이며 자동 검색 조건·원인 확정·작업 허가를 뜻하지 않는다.

현재 기본 구성: 고유 신호 48종, 설비별 측정 위치 69개, 시나리오 104개. 과거 run의 구성은 변경하지 않는다.
config_id: `e40c60646da26e421c5ff9e52a421adee232f4a34cc64e407c7f60c0bd6f0375`.

기존 공정 시나리오는 capability의 첫 설비를 대상으로 하고, 센서·증상 시나리오는 cause_equipment_id로 설비를 지정한다. GR-02도 지정 시나리오의 원인이 될 수 있다. 알람과 계측은 별도이며 모든 active 설비의 구성 신호를 계측한다.

high/low는 normal_min/normal_max 기준이며 양끝은 normal에 포함된다. 단위·quality=good·관측 시각·운전 상태를 확인한다. 자세한 범위는 [MES 신호 사전](../../../../guides/mes-card-signals.md)을 따른다.
