## 자료 분리와 평가의 범위

[사전 계획](../research/mes-context-v1-prereg-20261023.md)의 통과 기준을 유지한다. 최종 정상 학습은 코일 부하 3군 × MesEngine/SignalDynamics 정상 경로 × 12실행 × 224프레임 = 16,128프레임이다. 초기 자료에 있던 slow/nominal/fast는 실행 구분용 배속 표식이며 물리 부하 축으로 해석하지 않는다. 모델은 모든 실행을 부하 3군으로 합쳐 적합하고 재생 배속을 입력에 사용하지 않는다.

고장은 별도 additive/hold/독립 코일 개입으로 만들며 탐지기의 PATTERNS/FaultSchedule을 사용하지 않는다. 오일/냉각수 냉각 이상, 누설, 마찰, 진동 고착, 보정 대상 출구 온도 고착, 대기율 불일치, 실제 코일 정체를 비교한다. 라벨·active_alarms를 정상 부하 선택에 사용하지 않는다. 정상 생성 일부와 구성은 공유하므로 현장 일반화의 증거로 설명하지 않는다.

개발 자료는 기존 fixture 24고장+6정상, replay fixture 24고장+6정상, 정상 전환 6실행이다. 후보와 평가 코드를 SHA256으로 고정한 뒤 코일 부하 3군 × 8개입 × 4개 독립 실행의 새 96고장, 3부하 × 2정상 경로 × 4실행의 24정상, 6정상 전환, 총 126실행·28,224프레임을 생성한다. train/개발/전환/replay개발/test의 run_id·seed·nonce 비중복을 검사한다.

정상 오통지는 별도 정상 실행의 통지 수다. 비매칭은 고장 실행에서 목표 설비·고장 시작~종료 구간에 매칭되지 않은 통지이며, 고장 전 정상 구간과 다른 설비의 통지도 포함한다. 이번 단독 개입 자료의 비매칭을 실제 파급 반응으로 단정하지 않는다. 두 수치를 합치지 않고 모두 보고한다. 지연은 합성 개입 시작 기준이며 통신·대기·PDA 렌더를 포함하지 않는다. 동일 검출 사건의 지연 차이와 전체 검출 사건의 p95는 구분한다.

## 배포와 운영 경계

운영 기준은 r3-c6c8872다. PR #343이 병합된 것을 확인한 뒤 최신 main의 POSIX fsync 및 기존 동작을 통합했다. 새 후속 PR의 변경은 정상 기준 후보·profile·검증과 worker 연결이다. 기존 PDA 디자인·버튼·용어·active_alarms·확인·배지·진동은 변경하지 않는다. 같은 알람창의 무음 AI 참고 정보 계약과 정지 전 감지 이력 계약을 유지한다.

새 worker는 기존 출력 `/run/shiftlink-analytics/latest.json`과 별도 `/var/lib/shiftlink-analytics-normal-v1`을 사용한다. 기존 `/var/lib/shiftlink-analytics`와 STOP 스위치를 보존한다. 새 profile 해시가 맞아야 시작한다. 릴리스 manifest의 파일과 기존 worker unit 해시를 검사해 동시 수정 덮어쓰기를 차단한다. PDA 파일이 같으면 교체·재시작하지 않는다. 이전 unit과 state로 되돌릴 수 있도록 영구 백업을 남긴다.

실측 센서 정확도와 실제 물리 고장의 미탐 여부는 이 검증으로 확정할 수 없다. 정상 조절 상태와 같은 값으로 고착된 센서는 추가 기준 센서나 운전 변화 없이 구분하기 어렵다. 전체 경로 1초 완료와 고장→PDA 표시 p95도 별도 미검증이다.

## 자료 계약 추가 감사

학습 16,128프레임은 모두 운전 중·fault_level normal·active_alarms 0이었다. 측정 품질은 good 1,096,704건, unavailable 16,128건이며 unavailable은 `EQ-0007:rt_lift_delay`다. 이 신호를 정상값으로 채워 학습하거나 모든 69채널의 고장 검출을 검증했다고 설명하지 않는다.

## 새 실행 sequence 0의 제어 상태

검증 중 운영 MES가 외부에서 새 run `cc2477d1dbb042f6b9963d25b0046c2a`·sequence 0·stopped로 바뀌었다. 최초 독립 replay 요청은 서버가 연결을 끊어 실패했으며 로그를 보존했다. 이후 실제 조회에서 snapshots 0개·config_preserved true·is_synthetic true와 승인 config를 확인했다. sequence 0은 저장된 센서 tick이 없는 초기 제어 상태다.

## RMS 정상 양자화 정체의 추가 보완
