# T2 RT 생성 근거와 한계

- K-1207 / slot:S07 / RT-03 롤러 반송 확인 후보이며 Interroll RollerDrive/PolyVee/MultiControl 구조 일치가 확인된 경우에만 부품 조치를 적용한다. 클램프와 RT-02 승강 절차는 제외한다.
- K-1208 / slot:S08 / RT-03 검색 후보. 실제 과전류 차단 증상 및 대상 차단기/구동 구조 확인이 전제다. RT-02 lift_delay와 연계한 진단은 하지 않는다.

## 예시 슬롯 대체

- S07은 클램프압 대신 반송 속도 low에서 실제 RollerDrive 미기동/물품 미이송 분기로 대체했다. 로컬 RT 매뉴얼은 롤러 컨베이어/코일카이며 유압 클램프압 low와 반송 차단을 직접 연결하지 않는다.
- S08은 RT-03 motor_current 단독으로 제한한다. RT-02 lift_delay와 조합할 수 없으며 실제 과전류 차단 상태가 추가로 확인되어야 한다.

MES 상태는 검색 트리거이고 제조사 판정값이 아니다. 모두 draft/L0/0.0. 생성자 승인 없음. 원문 구조 적용성과 사람 검수 미완료.
