# MES 전체도·연결선 개선 검증

2026-09-20, 기본 구성의 설비 10대 / 설비 간 관계 19개 대상.

## 사용자 동작과 변경

- 기본 화면에서 소재 4개 연결을 유지하고, 명시적으로 선택한 설비의 직접 관계만 추가한다.
- 필터는 선을 숨기지 않고 관계를 강조한다. 같은 설비 재클릭, 해제 버튼, Escape로 기본 상태로 돌아간다.
- 도면을 1200×1080에서 1200×734로 압축하고, 본선 간 인터록·동시발생 경로를 본선 위쪽으로 분리했다.
- 기본 전체도는 화면에 맞추며, 글자·설비 그림을 크게 확인할 때 확대 보기를 선택한다. 그림과 노드 내부 여백을 줄이고 설명·검색·애니메이션 설정은 접었다.
- 동시발생 관계는 무방향이며, 설정된 관계 자체가 원인 확정을 의미하지 않는다.

## 브라우저 확인

Chrome 헤드리스에서 기본/선택, 강조 필터, Enter/Escape, 해제, 확대/전체도 전환 및 키보드 가로 스크롤을 확인했다. 4개 폭에서 브라우저 JS 오류와 문서 가로 넘침은 0이다.

| 화면 | 전체 도면의 페이지상 위치 | 확인 |
|---|---|---|
| 1440×1000 | y=380.28~960.28 | 첫 화면에 전체 설비 표시 |
| 1366×900 | y=380.28~860.28 | 첫 화면에 전체 설비 표시 |
| 768×1000 | y=453.47~875.52 | 첫 화면에 전체 설비 표시 |
| 390×844 | y=677.45~875.63 | 약간의 세로 스크롤 필요, 작은 글자는 확대 보기 사용 |

로컬 재현·캡처: `artifacts/mes-flow-review/compact-browser.cjs`, `compact-browser.json`, `compact-geometry.cjs`, `compact-geometry.json`, `compact-*-base.png`, `compact-*-selected.png`. 이 폴더는 `.gitignore` 대상이며 저장소에 포함되지 않는다.

UI 전문가가 모바일 필터 폭 문제를 지적했고 2열 배치로 수정 후 재평가했다. 최종 UI·설비 전문가 모두 추가 차단 항목과 남은 이견 없음. 설비 전문가는 데이터 방향·유형·표시 집합을 확인했으며 독립 브라우저 재실행은 하지 않았다.

## 한계

모바일 전체도는 배치 파악용이며 상세 글자는 확대가 필요하다. 최대 3개의 교차는 남아 있다. 미래의 임의 확장 구성, 다른 브라우저, 실제 터치 장치와 스크린리더는 미검증이다. 현재 구성에 대한 측정 결과를 전체 구성으로 일반화하지 않는다.
