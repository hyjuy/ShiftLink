## 2. 사람 검수 기준 (절당 공통 확인 항목)

1. **수치 일치** — 본문 수치가 같은 파일 `measurement_points`의 정상 범위·경보값과 일치하고 `[가상 값]` 표기가 있는가
2. **원문 미복제** — 시드 자료(SD-001~008)의 문장·표·수치를 복제하지 않고 구조·용어만 참고했는가
3. **조건 타당성** — `applies_conditions`/`excludes_conditions`의 field·op·value가 실제 신호명·허용값과 맞는가
4. **안전 근거** — 안전 절의 `safety_basis`가 해당 내용에 실제로 대응하는 규정인가 (안전 검토: 허재원 연계)
5. **정답 미누수** — sealed 사건의 원인·조치를 그대로 서술하지 않는가 (자동 검사 통과했어도 의미 수준 재확인)
6. **카드와 역할 구분** — 절이 재사용 절차 지식을 담고, 특정 사건의 이력·정답을 담지 않는가
