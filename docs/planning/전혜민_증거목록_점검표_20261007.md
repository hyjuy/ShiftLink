# 전혜민 오늘 업무와 2주차 점검표 초안

2026-10-07 M1·M3 작업용. 오늘 배정안은 전혜민이 계획·증거 목록, 시연 대본, 10/8 점검표를 맡는 것으로 되어 있다. 팀 배정 확인과 실물 화면 검토는 아래 빈칸에 기록한다.

공식 기준선은 10/6의 **71%, 완료 게이트 0/7**을 유지한다. 이 목록을 준비한 것으로 기능 완료나 점수 상승을 판정하지 않는다. 오늘의 장치 상태와 원자료 검수 결과는 미확인이다.

## 오늘 진행 순서

1. 아래 증거 목록에서 담당·선행 조건을 확인하고 팀 배정 합의 여부를 기록한다.
2. [시연 대본 초안](전혜민_시연대본_20261007.md)을 검토한다. 본 흐름과 오늘 수동 선택 점검을 구분한다.
3. 유현준의 G2·Unity→실물 PDA 화면, 업로더 준비 기록을 받아 화면 검토표를 채운다.
4. 최재영의 E1·hybrid dev 3건 결과를 받아 구성·분모를 검수한다.
5. 오늘 확보한 증거 경로와 미완료 사유를 기록하고 10/8 점검에서 점수를 판정한다.

## 10/8 점검 진행표

| 순서 | 점검 내용 | 결과 입력 |
|---|---|---|
| 1 | 허재원 복귀와 기존 모델·이미지·로그 확보 여부 확인 | 미확인 |
| 2 | W2-1~W2-5의 실행 증거 원자료와 main/기록 저장소 보관 여부 확인 | 대기 |
| 3 | G2, 실물 PDA, G3, 업로더 설정·서비스 상태 확인 | 대기 |
| 4 | 접속 준비 후 실제 랜선 끊김·복구 시험 결과 확인 | 대기 |
| 5 | E1·hybrid dev 기록 검수와 사전 등록 전원 합의 여부 확인 | 대기 |
| 6 | 점수와 미완료 사유를 기록하고 CNN 시험 일정을 재배치 | 대기 |

항목 판정은 **완료: 실행 증거 확인**, **미검증: 코드·자료가 있으나 끝 기준 미확인**, **보류: 선행 조건이나 담당 부재로 시험 대기**로 나눈다. 보류는 점수 상승 사유가 아니다. 기준 2점 항목도 원자료가 사라졌거나 재현되지 않으면 재판정한다.

| 점검일 | W1 합계/10 | W2 합계/10 | W3 합계/12 | 전체 | 게이트 | 변동 사유·증거 |
|---|---|---|---|---|---|---|
| 10/6 기준 | 9 | 8 | 5 | 71% | 0/7 | 기존 기록 |
| 10/8 | 미입력 | 미입력 | 미입력 | 미계산 | 미판정 | 점검 후 입력 |

계산식: `((W1 합계 / 10) + (W2 합계 / 10) + (W3 합계 / 12)) / 3 × 100`. 기준선은 70.6%를 반올림한 71%다. W2만 점검하고 다른 주의 점수를 바꾸지 않았다면 W1·W3 기준값을 유지한 사실을 기록한다. 게이트·파트 추정치는 합산하지 않는다.
