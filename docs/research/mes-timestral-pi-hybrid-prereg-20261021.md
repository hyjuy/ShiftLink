# 결합 방식 사전 고정 — 독립 확인 전

2026-10-21. 단독18후보 개발 실험에서 동시개선 후보0개였다. 결과를 숨기거나 단독모델 개선으로 바꾸지 않는다. 새 확인 corpus55371은 아직 생성/본문 접근하지 않았다. 기존35사건 개발자료에서만 두 번째18후보를 탐색한다. 최초 단독실험의 진단용선정0.75/1of1은 승격하지 않으며 새 확인에 넘길 후보는 아래 결합실험을 마친 뒤 고정한다. 이 변경은 독립확인 전에 선언한다.

결합 경보 = (현재 EWMA 경보 AND 현재 Timestral 점수 > 정상임계값*gate) OR (현재 Timestral 점수 > 정상임계값*scale이며 최근n시점 중k시점 초과). 추가 조건은 현재초과도 필요하며 시간/run 단절 reset은 단독실험과 같다. gate={.1,.25,.5}, scale={1,1.5,2}, (k,n)={(1,1),(2,3)} 총18개다. .1 gate는 원래 임계값 대비10%인 예측 잔차 조건이며 새로운 고장학습은 아니다.

후보 선택은 동시개선 통과 중 탐지 최대→오경보 최소→p95 최소→scale/k/n/gate 오름차순이다. 없으면 같은순서 진단용1개만 고르고 승격하지 않는다. 모델·입력·정밀도·정상보정은 그대로이며 EWMA 상태만 추가한다. 결합선정 JSON 및 코드를 Git에 고정한 뒤 frozen v7 seed55371의 validation55379..55386을 한 번 평가한다. 새 결과를 보고 임계값이나 결합 규칙을 다시 조정하지 않는다. 독립확인 대조군에는 현재 EWMA·정상재적합 EWMA·기본 FT와 단독18후보 진단선정도 포함한다.

이 방식이 통과해도 Timestral 단독개선이라고 부르지 않으며 EWMA+Timestral 결합 결과라고 쓴다. 개발36후보 탐색의 선택편향, 합성자료 한계, Pi 실측 미확인을 유지한다. 그 외 비용·해시·p95·사건별손익·그림·test0 조건은 최초 사전고정 문서를 따른다.
