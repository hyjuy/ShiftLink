# T2 HPU 생성 근거와 한계

- K-1201 / slot:S01 / 광학식/전기식 표시기 종류와 위치 확인에 한정한다. 가상 차압 high는 원문 막힘 표시와 동치가 아니다. 필터 모델과 표시기 적용성 미확인; 저온 일시 경보 해석은 하지 않는다.
- K-1202 / slot:S02 / 막힘 표시에 따른 교체 요구와 정기 교체 이력 확인에 한정한다. 유온 normal+차압 high로 막힘을 확정하는 원문 근거가 없어 온도 분기를 제거했다. 원문 연 1회는 가상 HPU의 승인 정비 주기가 아니다.
- K-1203 / slot:S03 / 출구 압력이 읽히는 기어·베인 펌프 계통에만 적용한다. 압력 없음 분기는 기존 K-1001 범위이다. hpu_pressure 및 hpu_flow의 측정 위치와 제조사 작업 기준 대조가 필요하다.

## 근거 부족으로 보류한 원래 예시

- S01 / K-1201: 필터 차압 high + 유온 low/normal을 냉간 일시 경보와 막힘으로 나누는 직접 근거가 로컬 원문에 없다. Danfoss p.29·37·39는 저온 점도/유량·흡입 진공, MAN-C-012 PDF p.6 §1.10은 막힘표시 확인 및 교체만 다룬다. 저온을 점도나 필터 차압의 대용값으로 쓰지 않는다. 필터 제조사 차압 표시·cold-start 억제 매뉴얼 필요.
- S02 / K-1202: 유온 정상 후 차압 high로 필터 교체 계획을 확정할 원문 판정값이 없다. 실제 막힘표시가 교체를 요구할 때 교체하는 일반 확인 카드는 가능하나 두 장의 온도 분기를 만들 근거가 부족하다. 필터 모델·막힘표시 사양 확보 필요.

MES 상태는 검색 트리거이고 제조사 판정값이 아니다. 모두 draft/L0/0.0. 생성자 승인 없음. 원문 구조 적용성과 사람 검수 미완료.

## 최종 대체 결과

S01/S02 원래 유온 결합 예시를 보류했다. 최종 K-1201은 표시기 종류별 확인 위치, K-1202는 실제 교체 표시와 정기 교체 이력으로 대체했다. 카드 수는 HPU 3장이다.
