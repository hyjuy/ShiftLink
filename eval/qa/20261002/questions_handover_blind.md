# 신입 작업자 인계 질문 10문항

작성일: 2026-10-02
요청·확정: 전혜민
상태: 카드 미열람 질문 초안, 정답 연결 전

## 작성·검토 이력

- 기존 대화·질문·카드 내용을 전달하지 않은 새 서브에이전트가 설비 이름과 일반적인 역할만 참고해 작성했다.
- 별도의 서브에이전트가 질문 초안과 작성 조건만 받아 인계 의도, 신입 말투, 문항 수, 설비 범위, 원인·정답 단정 여부를 검토했다. 수정 없이 원문을 유지했다.
- 작성·검토 에이전트 모두 저장소·파일·웹·정답 카드를 조회하지 않았다.
- 총 10문항이며 HPU·PDP·CAU·GR·RT·CV를 모두 포함한다.
- 배치 B 사건과의 일치 여부 및 정답 카드 연결은 아직 검토하지 않았다.
- 질문 원문은 유지하고, 정답 카드 연결·답변 가능 여부·검수 결과는 별도 파일에 기록한다. 이 질문은 KB나 검색 인덱스에 넣지 않는다.

## 질문

| 설비 | 질문 |
|---|---|
| HPU | 전 교대에서 계속 지켜보던 내용은 제가 인계 기록 어디에서 확인하면 돼요? |
| HPU | 제가 본 상태랑 앞 교대 기록이 조금 다른데, 인계할 때 둘 다 적어두면 돼요? |
| PDP | 교대 중에 알림이 떴다가 사라졌는데, 다음 교대에도 얘기해둬야 해요? |
| PDP | 전달받은 내용 중 아직 확인이 안 된 건 기록에 어떻게 구분해서 남겨요? |
| CAU | 전 교대에서 평소랑 달랐다고 했는데, 제가 이어서 확인한 내용은 어디에 덧붙여요? |
| CAU | 인계받은 뒤 별다른 변화가 없었어도, 교대 기록에 그 내용을 남겨야 해요? |
| GR | 가끔 들렸던 소리를 전달하려면, 언제 어떤 작업 중이었는지도 같이 적으면 돼요? |
| RT | 교대 시간에 자재가 남아 있으면, 어디까지 처리됐는지 어떻게 전달해요? |
| CV | 중간에 멈춘 적은 있는데 이유를 못 들었어요. 다음 교대에는 뭐라고 전달하면 돼요? |
| CV | 인계할 때 담당자가 잠깐 자리를 비웠으면, 전달한 내용은 어디에 남겨두면 돼요? |
