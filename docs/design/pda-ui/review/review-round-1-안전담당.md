## 감점 내역

### B1 / 안전 카드 최상단 고정 (-3 / 8)

- 근거: 프레임 10-b (라인 729-761), 프레임 11 (라인 778-810)
- 왜 문제인가: 조치 선택의 연속 흐름(10→10-b→11)에서 안전 카드가 2회 부재하면, 작업자가 안전이 모든 단계에서 필수임을 깨닫지 못할 수 있다. 특히 조치 기록과 다음 조치 선택 사이에 안전이 재확인되지 않으면 "건너뛸 수 있는 항목"으로 읽힐 위험.

### B2 / safety_basis 항상 펼침 (-3 / 5)

- 근거: 프레임 09 (라인 611-615)
- 왜 문제인가: 안전 카드가 2초 만에 선노출되는 시점에 조문 번호가 없으면, 작업자가 "이게 어디 규정인가?" 를 확인할 수 없다. 부분 결과라도 `bs` 필드는 필수여야 함.

### D1 / 실값 사용 (-3 / 6)

- 근거: 화면의 ID 값(K-0108, EQ-0009, CV-01 등)과 docs/data 파일 간 검증 불가능
- 왜 문제인가: 파일의 주석("docs/data 실제 값")은 변론이므로 근거로 인정할 수 없음. 실제 카탈로그와 일치하는지 확인 불가능하므로 보수적 채점 필요.
