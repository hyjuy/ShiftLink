# 생성 담당 판단 기록

작성자: Codex sub-agent card_author(GPT-6 계열). 생성 원문은 source_editor가 준비한 source-packet.json의 P-01~P-03 발췌다. 기존 카드·합성 사건·페르소나를 사실 원문으로 사용하지 않았다. 작성 가이드, 현재 스키마, 원문·분할 계약을 확인했다.

## 유형과 분리

| 카드 | 주된 목적 | 경합 유형과 판단 | 분리 |
|---|---|---|---|
| K-0301 | 정지스위치 주위 장애물 금지 | T5. 징후 해석이나 진단이 아닌 독립 금기 | 다른 두 카드와 독립 |
| K-0302 | 비상·사고 정지 후 재기동 전 확인 | T6. 원인을 좁히는 진단 절차 T3가 아니라 재기동에 앞선 확인 | T5와 독립; safety_flag 유지 |
| K-0303 | 컨베이어 올라가기 금지 | T5. 예외는 금기의 적용 범위이며 T2 요령으로 분리하지 않음 | 금지와 예외를 한 카드로 보존 |

P-02/P-03은 source_editor에게 전체 조항 발췌 보강을 요청했고, 전제와 예외가 포함된 최종 패킷을 사용했다. K-0302의 restart_type은 원문 비상·사고 정지 맥락을 enum으로 옮긴 분류 메타데이터다. 원문 자체의 코드가 아니므로 evidence-map의 metadata_links에 두었다.

## 보류

- P-04(SKF, dev): 단일 사건에서 특정 축 베어링 배치를 분석하고 설계대안을 제안한 서사다. 조건이 단순 적용 범위인 경우 T2로 분류하지 않는 작성 가이드 §2.1에 따라 카드화 보류. 재사용 가능한 조건별 선택 요령·분기 근거가 추가되면 유형을 다시 검토한다. T1/T3/T6 필수 사실도 이 발췌만으로 만들지 않는다.
- NSK(dev): 설비 GR/RT 의미 대응 근거 부족. 원문 편집자의 보류 유지.
- KOSHA §4.3(9): 기존 카드와 상당 중복하여 원문 편집자의 보류 유지.
- sealed 계보: 원문 열람·생성에 사용하지 않음.

## 빈 값과 관리 메타데이터

원문에 사건·실패시도·증상·인계방법·승인 기록이 없어 관련 필드는 null/빈 목록이다. 신규 사건/실패 ID, 임계값, 진단 단계는 만들지 않았다. 재기동 맥락은 know_how와 restart_type으로 보존했고 측정 신호를 창작하지 않아 conditions/exclusions는 빈 배열이다. K-0303 예외를 자동 검색 제외 조건으로 만들면 금기 자체가 사라질 수 있어 서술형으로 유지했다.

S1/S2는 docs/design/A_domain.md A4.2에 따른 독자 분류다. CV는 컨베이어의 의미 대응이며 실제 현장 설비 ID를 지정한 것이 아니다. split=kb는 source-packet의 문서 계보 해시 배정 제안이며 배정표 등록은 하지 않았다. 모델은 GPT-6 계열이며 프로젝트 Qwen/Ollama를 호출하지 않았다. prompt_version/index_version은 확인 가능한 고정 버전이 없어 null이다. 생성 시각은 실제 시스템 시간 출력이다.

confidence=0.0은 메인이 정한 미평가 sentinel로 확률·정확도 점수나 낮은 신뢰도 판정이 아니다. 이 검토용 배치는 운영 KB 및 런타임 판단에 사용하지 않는다. generalization_evidence.confidence_basis는 원문 지식이 아닌 제작 메타데이터로 근거 지도에 분리했다. safety_review=null이며 사람 검토 기록을 생성하지 않았다.
