# S-03 — OSHA 29 CFR 1910.147

대상: `29 CFR 1910.147 — The control of hazardous energy (lockout/tagout)`  
원문 확인일: 2026-09-17  
공식 원문: [eCFR §1910.147](https://www.ecfr.gov/current/title-29/subtitle-B/chapter-XVII/part-1910/subpart-J/section-1910.147)  
원문 상태: eCFR 현행 본문 확인. eCFR은 지속 갱신되는 온라인 CFR이며, 페이지는 이를 authoritative but unofficial로 표시한다.

## 확인한 적용 범위

이 조항은 예기치 않은 통전·기동 또는 저장에너지 방출이 근로자 부상을 초래할 수 있는 기계·설비의 정비·보전에 적용된다. 정상 생산작업은 원칙적으로 적용 범위 밖이지만, 방호장치를 제거·우회하거나 작업자가 위험구역에 신체 일부를 넣어야 하는 정비·보전은 적용될 수 있다. 전기·기계·유압·공압·화학·열 등 에너지원을 정의한다.

이는 미국 규정이다. 한국 사업장의 법적 의무를 직접 정하는 근거로 사용하지 않으며, L1의 에너지 격리·작업 인계 데이터 구조를 검토할 때의 보조 참고로만 쓴다.

## 핵심 항목

| 조항 | 확인 내용 요약 | L1 설계·카드와의 연결 |
| --- | --- | --- |
| (a)(1)~(3) | 위험에너지 통제의 범위·목적, 기계·설비 비가동화와 에너지 격리 | HPU 유압, GR/RT/CV의 기계·전기 에너지 위험을 하나의 보류 기준으로 다룸 |
| (c)(1)~(4) | 절차·교육·정기검사로 구성된 에너지 제어 프로그램, 잠금 가능 설비의 lockout 원칙, 문서화된 절차 | 카드가 작업절차를 대체하지 않고, 설비별 절차 참조를 요구해야 함 |
| (c)(6)~(9) | 정기검사, 교육·통지, 권한 있는 작업자만 격리 수행 | `safety_basis`만으로 작업 권한을 부여하지 않으며, 담당자 승인·통지 기록을 별도 관리 |
| (d)(1)~(6) | 정지 준비 → 정지 → 에너지원 격리 → 잠금/표지 → 잔류에너지 안전화 → 격리 확인 | T5 카드의 “잔압·저장에너지 확인 전 작업 보류” 근거 구조 |
| (e) | 재가동 전 작업구역·작업자 상태를 확인하고, 적용자가 잠금/표지를 제거 | 재가동 체크와 책임자 기록이 필요한 이유 |
| (f)(4) | 교대·인원 변경 시 잠금/표지 보호의 연속성을 위한 구체 절차 | S3 교대 인계에서 에너지 격리 상태·담당자·미완료 작업을 남기는 근거 구조 |

## 카드 인용 예시

```text
OSHA 29 CFR 1910.147(c)(1), (d)(1)~(6) [절차 참고]
OSHA 29 CFR 1910.147(f)(4) [교대 인계 절차 참고]
```

`[절차 참고]` 표기는 이 출처가 국내 법적 의무의 대체물이 아님을 카드 검수자가 알 수 있도록 하는 내부 표기다. 실제 카드에 어떤 표기 체계를 채택할지는 미결 #18 검토 후 확정한다.
