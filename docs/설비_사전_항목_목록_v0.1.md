# 설비 사전 항목 목록 v0.1

대상: 가상 냉연 코일 처리 라인 L1의 보조설비 HPU·GR·RT·CV. 이 문서는 설비군 대표 사전 입력 항목의 초안이며, 실제 운전·정비 지시서가 아니다. 계측 범위와 경보값은 모두 `[가상 값]`이고, 실제 현장 적용 전 설비 사양·작업표준·안전 담당자의 확인이 필요하다.

## 공통 입력 규칙

- 설비군 항목은 인스턴스(예: `GR-01`, `GR-02`)에 공통 적용하되, 설치 위치·개조 이력·실제 계측 태그는 인스턴스별로 분리한다.
- 부품에는 `부품 코드`, `명칭`, `기능`, `고장 모드`, `연결 계측 태그`를 기록한다.
- 계측에는 `태그`, `단위`, `정상/경보 범위`, `변화율`, `값의 출처`, `가상 여부`를 기록한다.
- 금기는 독립 T5 항목으로 관리한다. 실제 차단점·방압 순서·재가동 승인 조건은 설비별 작업표준을 참조하며 이 사전에 추정해 넣지 않는다.
- T5 항목은 `safety_flag=true`와 `safety_basis`를 필수로 하고, 채택 전 안전 담당자의 사람 검수를 받는다.

## HPU — 유압 파워 유닛

| 구분 | 사전 항목 |
| --- | --- |
| 부품 | 주 베인펌프, 리턴 필터, 축압기, 릴리프 밸브, 오일 쿨러, 주 공급 호스 |
| 고장 모드 예시 | 토출 저하·이상 소음·내부 누유, 필터 막힘·차압 상승, 축압기 질소압 저하·블래더 파손, 밸브 설정압 이탈·고착, 냉각 성능 저하, 호스 크랙·외피 손상 |
| 계측 | `hpu_pressure` (bar), `hpu_oil_temp` (degC), `hpu_filter_dp` (bar), `hpu_flow` (L_min) — 범위·경보·변화율은 기준정보의 `[가상 값]`을 사용 |
| 금기 | 가압 상태에서 유압 배관·호스·커플링을 분리하지 않는다. 정비·점검 전 운전 정지, 기동 방지, 잔압·축압기 방압 확인 전 작업하지 않는다. 고온 유압유·누유 부위에 접촉하거나 임시로 누유를 막지 않는다. |
| 안전 근거 방향 | 산업안전보건기준에 관한 규칙 제92조 제1·2·4항. OSHA 29 CFR 1910.147은 절차 참고용이다. |

## GR — 감속기 구동 설비

| 구분 | 사전 항목 |
| --- | --- |
| 부품 | 입력측 베어링, 감속 기어박스, 커플링, 구동 모터, 진동 센서, 베어링 온도 센서 |
| 고장 모드 예시 | 베어링 표면 피로·압흔·부착 마모·전식, 치면 마모·윤활 부족·이상 진동, 커플링 편심·탄성체 열화, 모터 과부하·절연 저하, 센서 오프셋 드리프트·배선 단선 |
| 계측 | `gr_vib_rms` (mm_s), `gr_brg_temp` (degC), `gr_current` (A) — `GR-01`, `GR-02` 공통의 `[가상 값]` 기준 |
| 금기 | 운전 중 감속기·커플링·모터·회전체에 접근하거나 방호물을 해체하지 않는다. 회전부 점검·윤활·조정·부품 교체는 정지 및 기동 방지 상태 확인 후에만 한다. 진동·온도 센서 이상 의심 시 계측값만으로 기계 고장을 확정하지 않는다. |
| 안전 근거 방향 | 산업안전보건기준에 관한 규칙 제92조 제1·2항. |

## RT — 롤러 테이블

| 구분 | 사전 항목 |
| --- | --- |
| 부품 | 롤러 세트, 유압 클램프, 승강 실린더, 구동부(감속기·모터는 연결 GR 사전 참조) |
| 고장 모드 예시 | 롤러 편마모·고착·표면 손상, 클램프 응답 지연·내부 누유, 승강 실린더 응답 지연·내부 누유 |
| 계측 | `rt_speed` (m_min), `rt_clamp_press` (bar), `rt_lift_delay` (min, RT-02), `rt_motor_current` (A, RT-03) — 모두 `[가상 값]` |
| 금기 | 운전 중 롤러·클램프·승강부에 손이나 공구를 넣거나 걸린 소재를 수동 제거하지 않는다. 정비·청소·점검 전 정지와 기동 방지 상태를 확인한다. 클램프·승강부의 유압 잔압이 남은 상태에서 분해·조정하지 않는다. |
| 안전 근거 방향 | 산업안전보건기준에 관한 규칙 제92조 제1·2·4항; 컨베이어 위험 맥락은 KOSHA GUIDE M-101-2012 (전문 적용 조항 확인 전) |

## CV — 컨베이어

| 구분 | 사전 항목 |
| --- | --- |
| 부품 | 벨트, 텐셔너, 사이드 가이드·스토퍼(인스턴스별 추가 등록), 구동 롤러·풀리(인스턴스별 추가 등록) |
| 고장 모드 예시 | 벨트 사행·장력 저하·손상, 텐셔너 유압 저하·고착, 가이드 편심·접촉, 롤러·풀리 마모·고착 |
| 계측 | `cv_speed` (m_min), `cv_belt_tension` (kPa), `cv_queue_len` (pct) — `CV-01` 기준은 `[가상 값]`; `CV-02`는 현재 대기율만 등록됨 |
| 금기 | 운전 중 벨트·풀리·롤러의 끼임 구역에 접근하거나 손으로 걸림을 제거하지 않는다. 벨트 사행을 운전 중 손·공구로 보정하지 않는다. 적재물 낙하·이탈 위험이 있으면 접근을 제한하고, 정비·청소 전 정지 및 기동 방지를 확인한다. |
| 안전 근거 방향 | 산업안전보건기준에 관한 규칙 제92조 제1·2항; KOSHA GUIDE M-101-2012은 컨베이어 위험 맥락으로만 사용한다. |

## v0.1 보완 목록

1. `GR-02`, `RT-01`, `RT-02`, `CV-02`의 부품 인스턴스 등록을 보완한다. 현재 기준정보의 상세 부품은 주로 `GR-01`, `RT-03`, `CV-01`에 집중돼 있다.
2. CV의 사이드 가이드·스토퍼·구동 롤러·풀리와 RT의 연결 구동부를 부품 코드, 설치 위치, 고장 모드까지 확정한다.
3. 각 금기에 실제 설비별 작업표준 ID와 승인 주체를 연결한다. LOTO 차단점·방압 순서·재가동 기준은 안전 담당 확인 전 기록하지 않는다.
4. KOSHA GUIDE M-101-2012 전문을 확보·검토한 뒤, CV·RT 금기별 적용 조항을 `safety_basis`에 매핑한다.
