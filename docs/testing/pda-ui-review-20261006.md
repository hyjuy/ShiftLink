# PDA 화면 수정 의견

2026-10-06 PDA 화면을 사용하면서 확인한 수정 의견 6건이다. M3 PDA 답변 화면 검토 작업의 수정 의견 목록으로 기록한다.

1. **설정 아이콘의 기능과 화면 배치**
   - 톱니바퀴 모양의 설정 아이콘을 눌러도 설정을 변경할 수 있는 기능이 없다.
   - 아이콘을 누르면 설비 스캔 버튼이 갑자기 아래로 내려가고, 원래 위치에 큰 공백이 생긴다.
   - 설정 변경 기능을 제공하고, 아이콘을 눌렀을 때 화면 배치가 밀리는 문제를 수정할 필요가 있다.

2. **업로드 대기 내역 확인**
   - `업로드 대기 1건`을 눌렀을 때 어떤 내용이 업로드를 기다리는지 확인할 수 있어야 한다.

3. **설비 스캔 가이드 잘림**
   - 설비 스캔을 누르면 카메라 가이드라인으로 보이는 보라색 점선이 일부 잘려 보인다.
   - 가이드라인이 화면 안에 온전히 표시되는지 확인하고 수정할 필요가 있다.

4. **직접 선택 안내 문구**
   - 경로: 설비 스캔 → 직접 선택.
   - `상자의 색 띠와 이름표를 보고 고르세요.` 문구를 수정할 필요가 있다.

5. **주입 버튼 문구**
   - 설비 스캔 화면의 가장 하단 오른쪽에 있는 `주입`이라는 표현이 어색하다.
   - 사용자가 버튼의 기능을 이해할 수 있는 표현으로 수정할 필요가 있다.

6. **개발 검증 안내 문구 삭제**
   - 사용자 의견의 `파이 없이± 화면이 받습니다.` 문구를 삭제할 필요가 있다.
   - 현재 화면 코드의 해당 안내 문구: `파이 없이 인식 경로를 검증합니다. 스캔 화면에서 주입하면 서버에 인식 1건이 기록되고 화면이 받습니다.`


## 2026년 10월 7일 문구와 표시 개선

추가 검토 의견 10건을 PDA 화면에 반영했다.

1. 홈의 스캔 안내를 `설비를 스캔하면 인식된 설비가 자동으로 선택됩니다.`로 변경한다.
2. 설비명 아래의 직접 선택·카메라 확정 표시는 제거한다. 질의에 필요한 선택 경로 정보는 내부 상태에 유지한다.
3. 직접 선택의 `상자의 색 띠와 이름표를 보고 고르세요.` 안내는 삭제한다.
4. 설비 위치는 Unity 가상 공장의 주 이송로·분기 이송로·보조 설비 위치와 좌표로 표시한다. 현재 MES 구성의 route 순서와 Unity `FactoryRig.Layout` 계산을 따른다.
5. `카메라로 돌아가기` 버튼은 `설비 스캔으로 돌아가기`로 변경한다.
6. 인계 확인의 `미종료`는 `처리 또는 재확인이 필요한 항목`으로 바꾼다. `open`은 `조치 필요`, `needs_recheck`는 `재확인 필요`로 표시하고 각각의 의미를 설명한다. 상태는 인계 기록에 등록된 값이며 MES 정상화로 자동 완료되지 않는다. 근거를 누르면 카드 내용, 조치 기록 또는 결과·측정값을 펼쳐 볼 수 있게 한다. 원문이 없으면 확인이 필요하다고 표시한다.
7. 인계 작성 항목을 한국어로 바꾸고 작업 상황을 수정할 수 있게 한다. `MES 기록 불러오기`는 선택 설비의 현재 측정값·측정 시각과 최근 이벤트 5건을 기존 입력에 추가한다. 전체 과거 로그 조회 기능은 아니다. 전송 확인이 안 된 인계는 기존 내용으로 재전송한다.
   - `REQUIRED_CONTEXT` → `작업 상황 및 측정 기록`
   - `RECIPIENT_ROLE` → `받는 사람`
   - `TIMING` → `전달 시점`
   - `CHANNEL` → `전달 방법`
   - `ACKNOWLEDGEMENT` → `인계 확인 방법`
8. 안전 카드와 상단 안내를 황색 주의 표시로 바꾸고 `작업 전 확인할 안전 수칙 N건`으로 안내한다. 안전 본문·멈춤 조건·상단 고정은 유지하며, 설비 불일치나 카드 누락은 별도 오류 색상으로 표시한다.
9. 측정값 안내를 `MES에서 가져오지 못한 측정값은 직접 입력해 주세요. 같은 항목을 입력하면 질의에는 직접 입력한 값이 사용됩니다.`로 변경한다.
10. 홈 화면의 `최근 설비`는 `최근 선택한 설비`로 변경한다. 스캔이나 직접 선택으로 선택했던 설비 목록임을 명확히 한다.
