## 학습에 쓸 때 확인할 것

- **이용약관**: API 출력으로 모델을 학습시키는 것이 벤더 약관(예: OpenAI의 "출력물로 경쟁 모델 개발" 제한)에 걸리는지 먼저 확인한다.
- **계열 분리**: 평가(judge)에 LLM을 쓴다면 생성 모델·온디바이스 후보(Qwen2.5·EXAONE-3.5)와 다른 계열을 고른다(개발계획 N-4).
- 호출 한도(RPM/TPM)는 계정마다 달라 실제 계정에서 확인한다.
