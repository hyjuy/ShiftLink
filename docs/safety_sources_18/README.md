## 사용 원칙

1. 이 폴더는 **조사 노트와 링크**만 저장한다. 카드에는 원문을 장문 복제하지 않는다.
2. `safety_basis`에는 카드 상황과 직접 관계 있는 출처의 식별자와 조문·절만 쓴다. 예: `산업안전보건기준에 관한 규칙 제92조 제1항·제2항·제4항`.
3. 법적 의무의 주체·적용 여부는 실제 사업장 설비, 작업, 관할 및 최신 원문으로 안전 담당자가 재확인한다. 합성 L1 카드가 실제 작업 지시나 작업허가가 되지 않는다.
4. 한국 법령 카드에서 OSHA는 보조 비교·절차 참고일 뿐, 국내 법령 근거의 대체물이 아니다.
5. KOSHA Guide 전문을 확보하고 적용 조항을 검토하기 전에는 M-101을 근거로 한 구체 절차를 “확정” 또는 “채택”으로 표시하지 않는다.

## 카드 작성에 바로 반영 가능한 최소 범위

| 카드 상황 | 사용할 수 있는 근거 방향 | 아직 카드에 단정하면 안 되는 내용 |
| --- | --- | --- |
| 운전 중 컨베이어·롤러 접근, 청소·정비·걸림 제거 | 제92조의 정지·기동 방지 요건 + M-101의 컨베이어 위험 맥락 | 실제 현장 LOTO 순서·담당자·잠금 지점 |
| 가압 유압 호스·배관·커플링 정비 또는 분리 | 제92조 제4항의 압축 기체·액체 방출 위험 | 압력 해제 수치, 밸브 순서, 재가동 승인 조건 |
| 잠금·표지·재가동·교대 인계 절차 설계 | 제92조 제2항 + OSHA 1910.147의 비교 참고 | OSHA 절차가 한국 법령상 필수라는 표현 |
