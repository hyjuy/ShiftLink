# 증상 선택지 표시 이름 개선 (2026-10-06)

PDA 「증상 질의」 화면의 선택지를 카드 원문 대신 짧은 표시 이름으로 보여준다. 화면에 반영했고, 문구는 현장 기준 검토(M3, 전혜민)를 거쳐 확정한다.

- 반영 위치: `shiftlink/mes/web/pda.js`의 `SYMPTOM_LABELS` (카드 ID → [표시 이름, 묶음]). 안전 표시(⚠)는 카드 `tacit_type`이 T5인지로 정한다.
- 원본 카드: `docs/data/knowledge_cards/kb/kb_cards.json` (수정하지 않음)

## 1. 무엇이 문제였나

PDP-01(배전반) 증상 질의 화면 기준:

- 선택지 24개 + 「기타」. 이 중 **12개가 공통 인계 카드(T4)** 문장이다. (예: "정비·전기 담당에게 점검을 요청하거나 접수만 해 두고 아직 회신이나 착수가 없는 상태로 다음 조에 넘겨야 한다.")
- 배전반 항목은 인계 문장 11개 뒤에 나온다.
- 원문 길이·문체가 제각각이다. 긴 서술문, 키워드 나열, "~넘겨야 한다" 같은 의무문이 섞여 있다.
- 트립 계열 5개처럼 비슷한 항목의 차이가 문장 중간에 묻혀 있다.

## 2. 무엇을 바꾸나

| | 지금 | 개선안 |
|---|---|---|
| 공통 인계 카드(T4) 12장 | 모든 설비 선택지에 노출 | **증상 선택지에서 제외** (인계 검색에는 그대로 사용) |
| 선택지 문구 | 카드 `symptom` 원문 | **짧은 표시 이름** (개조식 명사형) |
| 묶음 | 없음 | **증상 / 작업 전 확인** |

| 질의로 보내는 문장 | `symptom` 원문 | **변경 없음** (`symptom` 원문) |
| 고른 뒤 | — | 선택지 아래 원문 한 줄 표시 |

### 검색·카드 연결에 영향이 없는 이유

카드 연결은 Jetson 검색이 질의 문장으로 한다. 질의에는 지금처럼 원문 `symptom`을 보내므로 검색 결과·답 없음 판정·인용·안전 공지가 모두 같다. 바뀌는 것은 화면 글자뿐이다.

짧은 이름을 질의로 보내면 안 된다. 단어 겹침 검색(E0)이라 "리프트 안 내려감", "펌프 압력 안 읽힘"은 검색 결과가 0건이었다(2026-10-06 노트북 시험). 그래서 화면 코드는 선택지마다 표시용 `label`과 전송용 `text`(원문)를 따로 들고, 질의에는 `text`를 보낸다 (`pda.js`의 `symptomsFor`·`renderSymptoms`).

## 3. 작성 규칙

1. 증상(보이고·들리고·읽히는 것)만 남긴다. 조치·인계·판단 문구는 뺀다.
2. 답을 바꾸는 조건은 남긴다 — 상황(정비 후·재가동·비상정지 후·작업 전), 방향(초과·저하), 원문 수치(58℃, 16 A, 1.2 bar), 동반 여부(+ 트립 동시, 트립 없이).
3. 원문에 없는 내용과 카드 결론(title)을 쓰지 않는다. 답을 보기 전에 판정이 드러나면 근거 카드의 의미가 없다.
4. 같은 설비 안에서 서로 구분되게, 차이 나는 조건을 앞에 둔다.
5. 묶음: 이상 현상은 `증상`, 시험·투입 순서·작업 전 안전·재가동 전 상태는 `작업 전 확인`.
6. 개조식 명사형으로 끝낸다. 연결어미(~인데, ~해서, ~지만)와 의무 표현(~해야 한다), 주어(다음 조가)를 쓰지 않는다.
7. 구어는 업무 용어로: 짐작·확정 못 함 → 원인 미확정, 어떻게 조치할지 모름 → 조치 기준 없음, 눈대중 → 정량 측정 불가, 덜 회복 → 회복 미흡, 회신 없음 → 회신 대기, 모름 → 미확인.
8. 현장 용어(트립, 유면, 편주, 잔압, 핫스팟)는 그대로 둔다. 한자어로 바꿔 더 낯설어지면 바꾸지 않는다.
9. 18자 안팎, 한 줄.

## 6. 검토가 필요한 점

**서로 헷갈릴 수 있는 쌍** — 같은 화면에 함께 뜬다.

| 카드 | 표시 이름 | 비고 |
|---|---|---|
| K-1010 | 벨트 편주 · 아이들러 중앙 이탈 | K-1012와 혼동 가능 |
| K-1012 | 벨트 교체 후 편주 | K-1010과 혼동 가능 |
| K-1025 | 베어링부 온도 62℃ 초과 | EQ-0004에서 K-1210과 혼동 가능 |
| K-1202 | 차압 1.2 bar 초과 · 교체 판단 | K-1201과 앞부분 동일 |
| K-1210 | MES 베어링 62℃ 초과 · 실측 대조 | EQ-0004에서 K-1025와 혼동 가능 |
| K-1301 | 공기 압력 저하 · 공구 출력 저하 | K-1303과 혼동 가능 |
| K-1303 | 계통 압력 저하 · 누설 의심 | K-1301과 혼동 가능 |

**원문 자체가 약한 카드** — 표시 이름으로 해결되지 않는다. 카드 `symptom` 보강은 정책 게이트를 거쳐야 한다.

- K-1005 축압기 기능 저하 의심: 원문이 '확인 필요' 위주라 증상이 약함
- K-1015 운전 중 오작동·고장 발생: 원문 자체가 포괄적

**`symptom`이 빈 카드 13장은 지금도 선택지에 나오지 않는다.** 「기타」 직접 입력으로 검색될 때만 나온다. 선택지로 노출할지는 별도 결정.

- HPU: K-1003 (용적형 펌프 과압 보호 없이 운전 금지·릴리프 설정을 펌프 최대 정격 위로 두지 않기), K-1006 (유압 파워 유닛 운전 중 정비 금지·정비 전 해당 계통 감압), K-1007 (작동유 점도 2000 cSt 초과(저온 등) 시 운전 전 워밍업)
- CV: K-1009 (건널다리·지정 통로 밖에서 컨베이어 위·아래 횡단 금지), K-1014 (운전 중 방호덮개·점검덮개 개방 금지)
- RT: K-1018 (하중을 실은 채로 리프트를 차단하지 않는다), K-1019 (코일카 아래 작업이나 유량 조절 전에는 좌우 정비 장치를 둘 다 끼운다)
- GR: K-1024 (감속기 온도·소음·진동의 정상 기록 대비 변화가 관측되면 주 모터를 멈추고 원인을 확인한다), K-1029 (옥외·다습 환경 감속기는 오일 수분을 확인하고 300 ppm을 넘기지 않는다)
- CAU: K-1304 (공기압축기 안전밸브), K-1314 (압축기 정비 전), K-1320 (공압 회로·공기탱크 잔압), K-1321 (압축공기 분사기·호스 사용 금지 사항)

**제외한 공통 인계 카드(T4)**: K-1101, K-1102, K-1103, K-1104, K-1105, K-1106, K-1107, K-1108, K-1109, K-1110, K-1111, K-1401
