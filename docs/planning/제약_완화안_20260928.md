# 제약 완화안 (2026-09-28)

> 상태: **제안 — 팀 합의 전.** 작성 최재영. 합의되면 이 문서가 아래 표에 적힌 기존 규칙보다 우선한다.

## 1. 전제

외부에서 정한 필수 조건은 세 가지뿐이다.

1. Jetson을 쓴다.
2. 카메라를 쓴다.
3. DB를 쓴다.

그 밖의 규칙은 모두 팀 계획 문서(통합본, 개발계획, `constraint_register.md`)가 스스로 정한 것이다. 모의 MES 제약 대장 하나에만 200개(확정 122, 미결 41)가 있다. 학습용 팀 프로젝트에 필요한 수준을 넘어섰고, 규칙 때문에 생성 실적이 0건으로 잡히는 상황이 생겼다. 팀이 합의하면 이 규칙들은 바꿀 수 있다.

## 2. 필수 조건 현황

| 조건 | 현황 | 조치 |
|---|---|---|
| Jetson | 플랜 B/C 측정 진행 중, 15W 재측정 남음 | 유지 |
| 카메라 | **코드 0줄.** 설계안(`PDA_카메라_설비식별_고도화.md`)은 제안 상태에 머물러 있다. 팀 규칙 C-057 "카메라 기능을 MVP에 추가하지 않는다"가 필수 조건과 정면 충돌한다 | **C-057, C-056 폐기.** USB 웹캠을 Jetson에 연결하고, OpenCV로 화면 속 대상이 설비 4종(HPU, GR, RT, CV) 중 무엇인지 분류해 `eq_id`를 넘긴다. 기존 설계안(PDA 브라우저에서 QR 인식)은 이 방식으로 대체한다 |
| DB | 모의 MES는 SQLite를 쓴다. MySQL(Aiven)은 접속 정보가 없다 | SQLite로 필수 조건이 충족되는지 확인한다. 충족되면 MySQL 연동은 선택 작업으로 돌린다 |

## 3. 유지하는 규칙

비용이 적고 실제 피해를 막는 것만 남긴다.

- **공개 저장소 보안**: `.env`, API 키, 저작권이 확인되지 않은 PDF 원문은 커밋하지 않는다.
- **KB와 평가 데이터 분리**: 평가용 사건과 카드는 KB와 검색 인덱스에 넣지 않는다. 섞이면 평가 결과가 의미 없어진다.
- **합성 표시**: 생성물에는 `is_synthetic`과 생성 모델명을 남긴다.
- **제품 안전 규칙**: T5 카드 우선 노출, 읽기 전용, 설비 직접 제어 금지. 제품 콘셉트이고 이미 코드에 들어가 있다.

## 4. 완화하는 규칙

| 지금 규칙 | 완화안 |
|---|---|
| 생성은 API로만, 명령 한 번으로 재생성 가능해야 함 (N-7, W3) | Claude Code/Codex로 생성해도 된다. 배치마다 프롬프트, 결과, 모델명만 남긴다. 재생성은 요구하지 않는다 |
| 사건 120, 채택 카드 150, 산출물 400, 봉인셋 60 | 데모와 평가에 필요한 만큼 만든다. 제안: 사건 30, 카드 60, 산출물 100, 평가셋 30 (개발용과 분리) |
| 문헌마다 승인 범위, 원문 해시, 검토자, 검토 시각 기록 (`approved_scope`) | 출처 URL과 페이지만 적는다 |
| LLM judge, 생성기와의 계열 분리, 사람 판정 일치율 20건 게이트 (N-4) | 사람이 샘플을 검수하고 스키마·규칙 검사를 한다. judge는 시간이 되면 참고용으로 돌린다 |
| 등급 L0~L3, 탈락 상태 6종 | 상태를 draft / accepted / rejected 3개로 줄인다. 등급 표기는 L0/L1만 쓴다 |
| SFT (기준선 3) | 제외한다. 계획의 대체 규칙("미수행으로 표시")을 적용한다 |
| G1/G2 수량 게이트 | 진행 확인 용도로만 쓰고, 미달해도 다음 작업을 막지 않는다 |
| `constraint_register.md` 200개 규칙 | 참고 자료로 내린다. 새 작업은 이 문서 3절만 지키면 된다 |

## 5. 합의되면 바로 바뀌는 것

- **N-7 종결**: 생성은 Claude Code/Codex로 한다. GPT-4o mini API 설정과 호출 상한은 필요 없어진다.
- **기존 draft 카드 58건**: 스키마를 통과했으니 draft로 인정한다. 채팅 기록이 없어 정확한 모델명은 알 수 없으므로 `model_version`에 생성 도구명(예: "Codex, 모델 미기록")을 적는다. T4 50건은 `split=dev`이므로 평가용으로 분리해 둔다.
- **남는 시간**은 카메라 착수와 Jetson E2E에 쓴다.
