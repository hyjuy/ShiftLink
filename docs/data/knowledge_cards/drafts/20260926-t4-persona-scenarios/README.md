# 페르소나 기반 가상 T4 인계 시나리오 25건

사용자 요청에 따라 실제 기밀 인계자료 확보를 전제하지 않고 가상 제조업 상황을 구성했다. 기존 합성 T4 방법 25건에 가상 사실 원장, 최초 인계, 되물음, 보완 인계, 모의 수신 응답, 실패 응답 예시를 연결했다. 모든 인물·대화·문서 상태·응답은 합성이다.

문서 참조·관측범위 검사 25/25건, 연결 카드 스키마 25/25건, 독립 AI 내용 검토 25/25건. 검사 결과는 [validation.json](validation.json), 검토 의견은 [review.json](review.json)에 있다.

이는 한 작성자가 원장과 대화 양쪽을 구성한 **대본형 예시**다. 카드 없이/있이 독립 에이전트를 실행해 효과를 측정한 결과는 아니다. 이전 94.9점은 이번 시나리오 점수로 재사용하지 않았다. 기존 카드의 식별자·confidence·승인 상태를 변경하지 않았다. 가상 원장 참조는 내부 일관성을 확인하기 위한 것이며 외부 실증 근거가 아니다.

합성 데이터 방법과 후속 비교 실험 설계는 [논문 검토 노트](research.md)에 정리했다. 연결된 기존 카드 전문은 [cards.md](../20260925-t4-synthetic/cards.md)에 있다.

수신 확인과 정보 해결은 서로 다른 상태다. 미확인·충돌을 정확하게 인수했다면 수신은 확인되더라도 정보 해결은 대기로 남는다. 일부 역할만 회신한 경우 전체 수신은 대기다. 대본의 수신 확인에서 물리적 작업 승인으로 넘어가지 않는다.

**보완 인계:** [가상 대화·V-11] 서식위치-타.pdf다. 내 보관함에 있던 파일이다. 이 연습의 보완 묶음에는 같은 HAND-타로 붙어 있다. 포장목록-타.pdf와 서식위치-타.pdf, 각각 첫 화면이 열리는지 대조판에 답해 줘.

**모의 수신 응답:** [모의 수신 응답] HAND-타 보완 묶음에서 포장목록-타.pdf와 서식위치-타.pdf가 각각 보이고 두 문서의 첫 화면이 열립니다. 파일별 대조로 첨부 수신을 확인했습니다.

**대본 종료 상태:** 정보 수신=confirmed, 정보 해결=resolved, 물리적 작업 승인 없음.

**잘못된 응답 예시:** 본문을 읽었으니 첨부는 열지 않아도 전부 수신 완료입니다.

**거부해야 할 이유:** 본문 수신은 파일별 전달·열람 확인을 대신할 수 없으며 F7의 확인 항목이 빠져 있다.

| T4 필드 | 가상 원장 연결 | 연결 설명 |
|---|---|---|
| required_context | F1, F2, F3 | 보유 목록·초기 수신 목록·보완 단계의 차이를 고정한다. |
| recipient_role | F4 | 본문과 첨부를 함께 인수하는 문서 담당이다. |
| timing | F5 | 누락 대조 뒤 보완 수신을 확인한다. |
| channel | F6 | 같은 인계 항목 아래 목록을 비교한다. |
| acknowledgement | F7 | 파일별 식별과 열람 여부를 모두 회신한다. |

**실질적 차이:** M20처럼 원문이 없는 상황이 아니다. 존재하는 파일의 전송 누락을 같은 인계 식별자 아래 보완하며 누락 원인 조사와 전달 완료를 분리한다.

**독립 검토:** V-11이 보유 첨부의 누락 파일명과 같은 인계 식별자를 보완하고 고정된 후반 대본의 파일별 열람 응답으로 전달 범위만 확인한다.
