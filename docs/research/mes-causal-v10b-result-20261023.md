## 원인·개발 경로

누설6건의 직접 원인은 기존 EQ1 문턱(EWMA13.893731·TS23.240467)을 한 번도 넘지 못한 것이다. 정상 calibration의 전류 순간값을 전체 수집 hold가 복제해 설비 공통 문턱을 높였고, 압력·유량의 지속 하락까지 가렸다. 정상 통지2건은 진동 순간값의 같은 복제에 EWMA가 반복 가중된 결과다. [원인 수치와 코드 줄](mes-causal-v10-result-20261023.md)을 보존했다.

별도 v10은 전체 반복 수집을 품질 상태로 구분하고 signed median→signed EWMA→채널별 정상 보정을 추가했다. hold 후 입력 재구축을 정상 회복으로 오인하는 중복 회귀도 수정했다. 최초 개발 후보는12/12 탐지·정상19/2688초여서 기각했고 test를 만들지 않았다. 정상 부하에서 많은 센서가 개별 문턱을1.004~1.260배 초과했다.

v10b는 같은 개발 자료·모델 예측을 복사해 보존하고, 모든5방법에 같은32개 설정에서 임계 여유1/1.5/2/3을 선택했다. full/noTS는 width5, q.98, patience4, multiplier1.5로 개발12/12·누설2/2·정상0/2688초였다. 개발 탐색 증가에 따른 과적합 가능성도 남는다. 모델 checkpoint는 v9 그대로이며 재학습하지 않았다. 결과 개선을 모델 학습 효과라고 설명하지 않는다.

소스·설정·자료·모델 해시 고정 뒤 처음 새36사건을 생성하고 모든 예측 저장 뒤 장부를 열었다. 시험을 본 뒤 설정을 수정하지 않았다. [최초 명세](mes-causal-v10-prereg-20261023.md), [v10b 추가 명세](mes-causal-v10b-prereg-20261023.md), [TDD](../testing/mes-causal-v10-20261023.tdd.md).

## Timestral 추가 효과

## 확인된 미해결 결함 — 고착 중 단발 bad 뒤 중복 통지

후보 고정 후 별도 배열 검사에서 지속 고착 중 한 프레임이 bad/NaN이면 고착 이력16개를 다시 쌓는 동안5개 낮은 점수를 정상 회복으로 오인하는 결함을 확인했다. 같은 고착에서 통지시각이[19,56]으로 두 번 나왔다. `scripts/mes_causal_v10.py:146`의 회복 조건은 설비의 다른 채널이 유효하면 참이어서 경보를 만든 채널의 재구축을 구분하지 못한다.

이는 긴 결측에만 국한된 미검증이 아니라 단발 불량에서도 재현된 미해결 P1이다. output/mes-causal-v10b-20261023/check_bad_during_flat.py의 `assert ticks==[19]`는 실패한다. 기존52개 회귀가 통과한 것과 별도이며, 테스트가 모두 정확성을 보장한다고 말하지 않는다. 새 시험에 이 중복이 없더라도 결함이 해결됐다는 뜻은 아니다.

집계의 duplicate는 활성 개입 시간 안의 같은 사건 추가 통지를 센다. 고장 구간 밖 잔류 재통지는 unmatched로 분류될 수 있으므로 duplicate0은 정책상 중복 억제 완전성의 증거가 아니다.

새36건의 중복1건도 같은 원인으로 확인했다. run `f6c5ce73a701551bd37bd3bf48d734ab`(A, seed1004002)의 EQ-0006 rt_motor_current 고착 구간[376,434)에서391초 첫 통지,406초 quality=bad,422초 재통지다. 세 시점의 값은12.49776251 A로 같았다. 406초 이후407~422의16개 good 관측이 쌓이며 재통지했다. 공통 acquisition hold는[158,167)로 이 고장과 무관하다. full/noTS 모두391·422를 기록했다. 중복 건수는 기존 고정 v9도1건이므로 이번 수정에서 중복이 개선됐다고 주장하지 않는다.

고정 후 새 평가 자료를 이미 생성했기 때문에 이번 후보와 시험 결과를 수정하지 않았다. 수정은 별도 다음 후보에서 원인 채널별 유효 증거와 이력 재구축 상태를 구분해 회귀를 추가하고 새 미사용 평가로 검증해야 한다. 이번 누설·정상 통지 결과와 함께 운영 보류의 직접 근거로 남긴다.
