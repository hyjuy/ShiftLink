# 공개 사건 기반 Event 초안

작성일: 2026-09-22. `shiftlink/agent/schemas.py`의 Event v1.1에 맞춘 단일 객체 JSON이다. 실제 공개 사건의 한국어 요약이며 페르소나가 만든 합성 사건이 아니다. 프로젝트 분류는 작성자의 판단으로 별도 구분한다.

| 파일 | 사건 | 적용 범위 |
|---|---|---|
| [EV-0101.json](EV-0101.json) | 냉간압연기 정비 중 유압펌프 가동 | 냉간압연 직접 사례; 첫 검토 추천 |
| [EV-0102.json](EV-0102.json) | 철강 리코일러 말림 | 슬리팅·권취 관련 |
| [EV-0103.json](EV-0103.json) | C형 훅에서 코일 이탈 | 코일 하역 관련 |
| [EV-0104.json](EV-0104.json) | 코일카 수리 중 낙하 | 코일 이송설비 정비 관련 |
| [EV-0105.json](EV-0105.json) | 리코일러 내 코일 미끄러짐 | 구리 열간압연 유사 사례; 냉간 철강 사건으로 사용 금지 |

출처 URL, 확인한 절, 사건 날짜의 정밀도, 설비 분류 이유, 미결 사항은 [manifest.json](manifest.json)에 있다. 원문 수치를 제외한 측정값·타임스탬프·인물 발언을 생성하지 않았다. 수치는 원문 단위를 유지한다.

## 사용 전 확인

- 전체가 검토용 초안이다. `split=kb`는 출처 그룹 해시의 배정 결과이며 운영 KB 편입이나 검수 완료를 뜻하지 않는다.
- `scenario=S2`는 교육용 사용 장면이며 사고자의 실제 경력 정보가 아니다. HPU와 COMMON은 프로젝트 분류로, 현장 설비 매핑 검토가 필요하다.
- `true_cause`는 원문이 제시하는 원인 또는 직접 사고 기전으로 한정했다. 원문에 없는 근본 원인은 확정하지 않았다.
- `true_actions=[]`는 검증된 정답 조치 미확보다. 원문에서 수행한 위험 행동·구조 행동은 timeline에 남기고, 예방 권고를 성공한 복구 조치로 옮기지 않았다.
- `cards_expected=[]`는 연결 카드 미작성, `restart_attempts=[]`는 구조화할 근거 부족이다. 완성된 평가 정답지가 아니다.
- 전체 Event에는 사후 결과가 포함된다. 런타임 모델 입력이나 평가 질의에는 시점별 관측 정보만 별도로 추출해야 한다.
- 원문 계보·유사 사건 중복 검토, 출처 등록 및 카드 생성용 사용 범위 검토는 후속 작업이다. 기존 원장과 평가 데이터는 수정하지 않았다.

## 검증

각 파일을 UTF-8 JSON으로 읽어 `Event.model_validate`에 전달한다. 파일명과 event_id, manifest 연결, ID 중복, 정확한 허용 필드, split 해시도 함께 확인한다. 스키마 통과는 사건의 독립적인 사실 확인이나 안전 절차 승인과 다르다.
