# T4 카드별 내용 요약

이 표는 현재 논리 카드 45개(공통 25개 + 장비별 20개)의 `know_how` 핵심을 카드 단위로 정리합니다. COMMON M07/M08/M13/M16/M18은 정합화한 후속 버전 기준입니다. 모든 카드는 개발 초안이며, 이 요약과 카드 내용은 합성 연구 자료입니다. 현장 효과나 KB 채택을 뜻하지 않습니다.
