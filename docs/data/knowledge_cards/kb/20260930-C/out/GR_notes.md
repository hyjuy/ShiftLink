# T2 GR 생성 근거와 한계

- K-1209 / slot:S09 / GR-01 검색 후보. 실제 정상 운전 대비 변화·소음 유형·베어링부 온도 확인이 필요하다. MES 온도 normal은 운전 지속 허가가 아니다. SEW 모델 적용성은 미확인이다.
- K-1210 / slot:S10 / GR-01 베어링부 온도 확인 후보. GR 전류→토크·과부하 추론은 하지 않는다. 대상 SEW 모델·설치 자세·오일 교체 지침 적합성 미확인이다. 기존 T1 온도 증상 카드와 달리 실제 확인된 유면/이력에 따른 조치 분기를 다룬다.

## 근거 부족으로 보류한 원래 예시

- S10 / K-1210: gr_current high와 부하 조건에 따른 조치를 지지하는 GR 모터 매뉴얼이 없다. 26873427 PDF p.19는 설계용 기동/피크부하 계수이며 운전 전류 진단 절차가 아니다. 다른 RT/롤러 모터 문서를 GR에 적용하지 않는다. 대상 GR 모터·인버터의 과전류/부하 진단 매뉴얼 필요.

MES 상태는 검색 트리거이고 제조사 판정값이 아니다. 모두 draft/L0/0.0. 생성자 승인 없음. 원문 구조 적용성과 사람 검수 미완료.
