# D18 사전 등록 — 원래 경보를 보존하는 알림 묶음

2026-10-21, D16/D17 결과 확인 후 별도 실험. 사용자의 지속 개선 요청에 따라 진행한다. 예측기·학습·임계값·원래 strict 점수는 바꾸지 않는다. D16의 episode-off 시간은 짧은 경보 분절의 증거가 아니므로, **짧은 정상 간격 뒤 재시작 수**를 별도 집계한다. 개선 주장은 알림 부담에 한정한다.

## 고정 후보와 입력

설비별 incident가 닫힌 상태에서 raw EWMA 경보가 켜지면 알림 한 건을 낸다. 경보가 꺼진 **연속 3초** 동안 해당 설비의 train 관측률 95% 마스크 전체가 최신/good/유한/단위 일치일 때만 정상 종료한다. 1~2초 뒤 재경보는 같은 incident로 묶는다. quiet=3은 임의 운영 가설이며 검색하지 않는다.

run 경계, sequence 불연속, 시간 간격이 정확히 1초가 아닌 경우, 비running 모드에서는 이전 incident를 interrupted로 닫는다. 유효하지 않은 raw-negative 관측도 interrupted로 닫고 정상 복구로 부르지 않는다. 불완전 관측이지만 raw-positive이면 열린 incident는 유지하고 quiet를 0으로 만들며, 닫혀 있었다면 알림을 낸다. 연속 불완전 양성 때문에 매 프레임 재알림하지 않는다. 설비별 관측 마스크를 사용하며 다른 설비의 결측은 영향을 주지 않는다. 알림 생성에는 프레임·마스크·원래 경보만 넣고 label/twin은 전달하지 않는다.

## 개발 평가와 관문

D16 저장 경보와 같은 train/validation prefix를 사용한다. 코드·prefix 해시와 원래 raw 점수를 확인한다. 원래 경보/점수는 정확히 같아야 한다. 알림은 raw-positive 프레임에서만 발생하고 incident 열린 시각과 일치해야 한다. 설비별/run별 알림 수는 원래 rising edge 수보다 늘면 안 된다.

기존 scorer가 탐지한 **개별 사건**마다 첫 매칭 시각에 실제 새 알림이 있어야 한다. 열린 incident가 있다는 이유로 알림 손실을 허용하지 않는다. 연속 프레임의 알림이나 outage 뒤 알림을 pulse scorer로 합치지 않고 명시 시각으로 매칭한다. 후보의 미일치 알림 수가 엄격히 줄어야 한다. 제거한 진짜 중복은 동일 episode ID가 이미 알림을 받은 경우만 별도 집계한다. pulse 시간과 원래 경보 시간을 비교해 오진 감소를 주장하지 않는다.

양팔 모두 통과하면 고정 EWMA 통계(train2371..2378)·threshold3·quiet3을 유지해 새 seed3371..3394의 validation을 한 번만 확인한다. 실패하면 보류하며 quiet/임계값 탐색이나 같은 자료를 이용한 후보 추가를 하지 않는다. 원본 test는 읽지 않는다. 통과도 합성 알림 실험이며 현장 배포 근거가 아니다.

독립 설계 검토는 연속 양성 속 새 고장, 선행 오경보가 후속 고장 알림을 가리는 경우, 2초/3초 경계, 결측·gap·설비별 분리를 필수 반례로 제시했다. 테스트를 먼저 작성해 누락 구현 RED를 확인한다.
