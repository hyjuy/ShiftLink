## Environment (`shiftlink-mes.service` drop-in)
```ini
[Service]
Environment=SHIFTLINK_ANSWER_MODE=s30h
# staged copy of this branch (10/16); drop this line once main is deployed
WorkingDirectory=/home/jetson/shiftlink/app-s30h
# judge-only Ollama listens on localhost
Environment=SHIFTLINK_S30H_JUDGE_HOST=http://127.0.0.1:11436
# defaults: SHIFTLINK_S30H_ANSWER_MODEL=exaone-rag-aug-ck106, SHIFTLINK_JUDGE_MODEL=exaone-sft-judge, SHIFTLINK_S30H_JUDGE_CTX=2048
```
- On startup the MES warms, in this order, the judge (ctx 2048) on the judge server, then ck106 (ctx 4096) and embeddinggemma (CPU) on the main Ollama, all with keep_alive -1.
- systemd does not allow comments at the end of a line: keep comments on their own lines.
- lo 0.3, hi 0.9 and t 0.35277185049977805 are code constants (`shiftlink/rag2/s30h.py`).
- The judge-only Ollama service, the switch order and the rollback order (sudo) are in `ShiftLink-records/deploy/jetson_s30h_sudo_plan_20261016.md`.

## Response format (open question)
- The PDA receives the same `AgentResponse`.
- Manual pages the answer cites go on the last line of the answer as `근거: <document> p.N`. Card ids go in `cited_card_ids`.
- `safety_notices` are the KB safety cards that fit the equipment, with the same rule as the PDA's `cardFits`.
- How the PDA should show manual citations is still undecided.
