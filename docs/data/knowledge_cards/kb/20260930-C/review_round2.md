## 재검토 판정

19장 모두 **출처·관측 기록에 맞춰 수정된 draft/L0**이다. T2 10장(HPU3/CV3/RT2/GR2), T6 9장(정비4/비정상3/정상2)을 유지했다. 내용 추적은 1차 표의 각 PDF 페이지·AR/AT에 연결되어 있다. 기존 T2 점도·옥외 수분 카드와 핵심 처방이 다르다. K-1201/1202는 표시기 확인 위치와 실제 교체 표시 후 조치 판단이라는 서로 다른 단계이며 근거 절은 같다.

확인 완료:

- Python 3.10 + pydantic 2.9.2 환경에서 out 19장 KnowledgeCard 스키마 통과.
- 19개 고유 ID, T2/T6 수량, PDF/EV/AR 출처 존재, 생성 prompt SHA256 일치.
- T6 18개 실패 시도 전체가 KB 관측 투영의 같은 attempt_id 기록과 필드별 정확히 일치.
- T6마다 KB supporting_event_ids 2개 이상이며 dev 기록 인용 없음.
- RT 전류·승강지연을 서로 다른 설비에서 결합하지 않음. 속도 low는 운전 지시 확인이 전제. 온도/차압 상태로 제조사 임계값을 대체하지 않음.

## 남은 한계

MES 조건은 후보검색이고 표시기 종류·소음 형태·실제 차단기 동작 등 수동 확인 분기는 자동 검증되지 않는다. 원문 모델과 가상 설치 설비의 구조/작업표준 일치는 아직 확인되지 않았다. 합성 사건의 동일 템플릿 반복은 실제 경험 다양성이나 효과 검증을 입증하지 않는다. 승인 재가동과 현장 안전 검토는 사람 담당자가 수행해야 한다. accepted/L1 승격은 하지 않았다.

검토자의 원장/개발 사례 접근 편차는 1차 문서에 남겼다. eval/ 접근은 없지만 이 검토를 블라인드 성능평가로 사용할 수 없다. 전체 배치 병합·원장 계약 검증·프로젝트 테스트는 루트 에이전트가 최종 실행한다.
