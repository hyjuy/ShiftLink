# ShiftLink 시연 수준 결과물 및 인수 기준

작성: 2026-09-24  
목표: **PDA에서 설비를 스캔하고 Jetson 로컬 LLM의 근거 있는 답을 확인하는 재현 가능한 통합 시연**

## 목표 수준

이 결과물은 통합 시연·기술 검증 수준이다. 실제 공장의 안전 판단, MES 운영, 정비 지시, 생산성 개선을 승인하거나 입증하지 않는다. 데이터는 합성·검수 fixture를 사용하며, K-0301~K-0303 draft/L0는 운영 지식으로 승격하거나 시연 근거로 쓰지 않는다.

PDA 카메라 요구는 사용자가 추가한 프로젝트 요구로 반영한다. 기존 C-056·C-057과의 충돌은 구현 전에 제약 등록부와 관련 설계 기록에서 해소한다. 카메라 영상은 PDA 밖으로 보내지 않고, 설비 ID와 스캔 메타데이터만 전달한다.

## 시연 인수 산출물

| 산출물 | 완료 기준 |
|---|---|
| PDA 앱 | 지정한 실물 Android/PDA와 Chrome에서 카메라가 열리고, QR 스캔 결과로 화면의 설비 컨텍스트가 바뀐다. 카메라 미지원·권한 거부·인식 실패 시 수동 선택으로 이어진다. |
| 설비 표식 | 정본 카탈로그에서 인쇄용 QR 라벨을 생성하고 상자 4~6개에 부착한다. 코드에서 `equipment_id`로 변환하며 미등록 코드는 질의를 시작하지 않는다. |
| Jetson 질의 경로 | PDA의 질문과 확인된 `equipment_id`가 로컬 서비스로 전달되고, Jetson의 고정된 모델 digest가 응답한다. 외부 네트워크 없이 시작·질의·재시작을 확인한다. |
| 근거 있는 답변 | 출력 스키마, 이번 검색 결과 내 인용 ID, 안전 카드, 지식 없음·검증 실패 보류를 통과한 답만 표시한다. 검증 실패 시 자유 답변을 표시하지 않는다. |
| 실행·복구 안내 | 장비 주소·인증서 신뢰 절차·모델 설정·실행/종료·오프라인 복구·시연 초기화 절차를 재현 가능한 명령과 함께 기록한다. 비밀 값은 문서에 넣지 않는다. |
| 시연 기록 | S1 질문 1건, S2 설비 3대 연속 전환, 카메라 실패 후 수동 폴백을 녹화 또는 화면 기록과 판정표로 남긴다. 안전·지식 없음 사례도 포함한다. |

## 정확도 및 성능 증거

- 평가 입력을 고정하고 기존 모델/프롬프트 기준선과 변경 후보를 같은 조건에서 비교한다. 최소 30개 개발 질문에 답변 관련성, 근거 충실도, 인용 유효성, 부정·조건 처리, 지식 없음 보류를 기록한다.
- 안전 카드 누락 0건, 검색 결과 밖 인용 0건, 근거 없는 위험 조치 0건을 필수 안전 게이트로 둔다. 미리 고른 오류 유형(예: 부정·조건 해석, 근거 충실도) 중 최소 하나가 기준선보다 개선되고 안전 지표가 나빠지지 않아야 개선 시연을 통과한다. 표본별 판정과 전체 지표를 모두 기록한다. 최종 일반화 주장은 분리 보관된 봉인 평가셋에서만 한다.
- Jetson은 15W에서 같은 KB·프롬프트·출력 제한으로 플랜 B/C 후보를 재측정한다. 모델 digest, cold/warm 시작, 성공·형식 실패·재시도, p95, 검색 지연, RAM/통합 메모리, 온도를 원시 로그와 함께 남긴다.
- 목표는 검색 p95 2초 이하, 전체 질의 p95 15초 이하이다. 목표를 못 맞추면 실패·미달로 기록하며 시연에서 감추지 않는다.
- PDA에서는 실제 스캔 성공, 코드 불일치 차단, 미지원 BarcodeDetector, 카메라 권한 거부, 수동 폴백을 실기기에서 확인한다. 카메라 보안 컨텍스트 검증은 다른 PDA 작업의 선행 조건이다.

## 통합 시험 범위

- 실제 PDA→서비스→Jetson LLM→응답 검증→PDA 화면 경로로 질의 10건을 실행한다.
- 안전 카드, 조건 미확인, 관련 자료 없음, 검색 결과 밖 인용, 모델 형식 오류·재시도 성공·재시도 실패, 시간 초과를 포함한다.
- 시연에서 인계도 보일 경우 동일 배포 경로로 인계 10건을 별도 실행한다. 인계 저장·수정·철회·재시작 보존은 전체 통합 MVP의 별도 게이트이며, 시연하지 않았다면 완료로 표시하지 않는다.
- MES/설비 제어 호출이 없고, PDA 이미지가 서버로 전송되지 않으며, 검색·응답 근거와 결과 판정이 로그에 재현 가능해야 한다.

## 40% 진행 게이트

아래가 모두 증거로 확인되면 프로젝트 진행도를 내부 추정치 약 40%로 보고할 수 있다. 퍼센트는 산출물 개수나 테스트 통과 수가 아니라, 이 통합 사용자 경로의 완료를 기준으로 한다.

1. PDA 실기기에서 상자 3종 이상을 QR 스캔하고 설비 전환에 성공한다. 미등록·미확정 설비는 검색되지 않고 수동 폴백이 동작한다.
2. 같은 PDA에서 보낸 질의를 Jetson 로컬 모델이 처리하고, 인용·안전·보류 규칙을 만족한 답이 화면에 표시된다.
3. 기준선 비교 보고서에서 사전 지정한 답변 품질 오류가 최소 하나 개선되고 필수 안전 게이트를 지킨다. Jetson 15W 원시 측정 로그도 남기고 성능 목표의 통과·미달을 명확히 판정한다.
4. 통합 질의 시험, 재현 가능한 실행 안내, 시연 기록이 저장소에 남는다.

이는 전체 MVP 또는 현장 배포 완료를 뜻하지 않는다.

## 시연 이후 전체 MVP 게이트

다음 항목은 시연 40% 게이트에 포함하지 않고, 전체 MVP 인수에 계속 필요하다.

- 최종 목표 데이터(사건 120건, 채택 카드 150건, 채택 산출물 400건), 개발셋 30건과 봉인셋 60건
- 정식 검색·인계 도구, 인계 수락·수정·철회·감사·오프라인 복구·outbox 흐름
- 대표 질의·인계 정답지 평가와 안전 누락 0건·근거 없는 위험 조치 0건 게이트
- 장시간 Jetson 안정성, 재시작 후 운영 복구, 승인된 지식의 현장 적용성·출처 범위 검토
- 발표 환경 리허설 및 미달 항목의 담당·재검증 기록

## 현재 확인된 전제와 blocker

- 이 체크아웃에는 B의 LLM 어댑터 소스/import 경로가 없다. 실제 PDA 경로를 붙이기 전에 어댑터 전달·주입이 필요하다.
- PDA 프로토타입은 `docs/design/pda_ui/prototype/`에 있으나 `shiftlink/mes/web/` 및 실제 질의 서비스와 통합되지 않았다. 현재 프로토타입 질의는 로컬 시뮬레이션이다.
- 기존 Jetson 로그의 플랜 B 긴 입력 결과는 오염되어 폐기됐고, 플랜 C 긴 입력 p95는 21.37초로 15초 목표보다 느리다. 공정한 재측정과 최종 모델 선택이 필요하다.
- K-0301~K-0303는 draft/L0이며 현장 적용 승인·출처 사용 승인·운영 채택을 받지 않았다.
