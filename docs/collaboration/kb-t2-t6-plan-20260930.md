## 왜 T2·T6인가 — 평가셋이 가리키는 빈 곳

블라인드 평가셋 70문항 중 답할 수 있는 건 23개뿐이다. 답이 없는 문항의 상당수가 두 종류다.

- **MES 값 해석 질문** (11건 중 8건 답 없음): 필터 차압, 벨트 장력, 클램프압, 승강 지연, RT 모터 전류 등. → 신호 **상태에 따라 요령이 달라지는** T2가 맞는 형식.
- **정지 후 재가동** (인터록 해제 후 재가동, 필터 교체 후 재기동 등): 카드 0장. → T6.

## 원칙

1. **평가셋을 보지 않는다.** 생성 에이전트는 `eval/` 폴더를 읽지 않는다. 평가 질문을 보고 카드를 만들면 점수가 부풀려진다(9/29 20/20 vs 7/11 사례).
2. **조건은 MES 상태 기호로.** `hpu_filter_dp_state == "high"`처럼 [`mes-card-signals.md`](../guides/mes-card-signals.md) 계약을 따른다. 매뉴얼 수치를 가상 설비의 경계로 옮기지 않는다.
3. **요령은 원문과 기록에서.** T2는 매뉴얼 근거(로컬 PDF, 출처 페이지만 기록). T6의 실패 경험은 근무 기록에서만 — 없으면 `tried_and_failed`를 비우고 지어내지 않는다.
4. **재현 기록**: 배치 A와 같은 방식 — `plan.py`(시드) → `prompts/`(원문 + sha256) → 서브에이전트 생성 → `merge.py` → `review.md` → 사람 검수 → accepted/L1 → `kb/manifest.json`에 한 줄 추가.

## T2 — 10장 (MES 신호 상태별 요령)

현재 카드가 없는 신호 위주로 배정한다. 조건 하나당 "이 상태면 이렇게, 저 상태면 저렇게"가 갈려야 T2다(조건이 단순 적용 범위면 T1/T3로 둔다).

| 설비 | 신호 (카탈로그) | 칸 | 예시 방향 (확정 아님) |
|---|---|---|---|
| HPU | `hpu_filter_dp` | 2 | 차압 high + 유온 low(냉간 기동) → 난기 후 재확인 / 유온 normal에서 high → 필터 교체 계획 |
| HPU | `hpu_pressure` + `hpu_flow` | 1 | 압력 low·유량 normal vs 둘 다 low → 확인 방향이 다름 |
| CV | `cv_belt_tension` | 2 | 장력 low + 부하 시 미끄럼 → 장력 확인 / 장력 normal인데 미끄럼 → 풀리 표면 |
| CV | `cv_speed` | 1 | 속도 low + 대기열 증가 |
| RT | `rt_clamp_press` | 1 | 클램프압 low 상태의 반송 판단 |
| RT | `rt_motor_current` / `rt_lift_delay` | 1 | 전류 high + 지연 high 조합 |
| GR | `gr_vib_rms` + `gr_brg_temp` | 1 | 진동만 high vs 온도 동반 |
| GR | `gr_current` | 1 | 전류 high + 부하 조건 |

- **선행 조건**: 유현준의 신호 표 보강(10/2)과 RT 구조 결정(10/2). RT 2칸은 결정 전까지 반송·클램프 신호만 쓴다.
- 보강 신호 11개(`hpu_oil_level`, `gr_rpm` 등)는 신호 표에 들어오면 칸을 옮길 수 있다.

## T6 — 9장 (재가동 3종 × 설비)

| restart_type | 칸 | 예시 방향 |
|---|---|---|
| `maintenance_restart` (정비 후) | 4 | HPU 필터·오일 교체 후 공기 빼기·무부하 운전 / GR 오일 교체 후 길들이기·온도 감시 / CV 스플라이스 수리 후 사행 확인 / RT 정비 잠금 해제 후 |
| `abnormal_stop_restart` (트립·비상정지 후) | 3 | CV 당김줄 비상정지 해제 후 라인 점검 / GR 과열 트립 후 / RT 인터록 트립 후 |
| `normal_stop_restart` (정상 정지 후) | 2 | 저온 기동(HPU 점도) / 장기 정지 후 |

**실패 경험이 부족하다.** T4 근거 기록 30건 중 `restart_attempts`가 있는 건 2건뿐이다 (EV-0307, EV-0312 — 둘 다 HPU 필터 교체 후 압력 미회복).

- **1안 (권장)**: T4 배치와 같은 2단계. 재가동 근무 기록 20건(KB용 15 + 평가용 5)을 먼저 합성하고, **2건 이상 반복된** 재가동 요령·실패만 카드로 뽑는다. 평가용 기록은 카드 근거로 쓰지 않는다.
- **2안 (빠름)**: 매뉴얼의 기동 절차만으로 카드를 만들고 `tried_and_failed`는 비운다. 실패 경험이 없는 T6라 정의(지식 + 실패 경험)의 절반만 채운다.
