## Q1. 신규 범위의 절단선을 어디에 둘 것인가 ★최우선

**배경** 신규 요구는 관계 모델·운전 컨텍스트·사건 다중 연결·행동·결과·재발·매뉴얼 절·개정·승인·발행·복구·로컬 웹 UI를 한꺼번에 요구한다. 기존 4주 계획은 이미 `[승인 #5]` 규모의 데이터 생산과 봉인 채점으로 채워져 있다. 전문가C의 부하 추정(허재원 1인 15~19 작업일 vs 가용 약 17일 `[가정]`)으로는 **전부 넣으면 4주에 완료되지 않는다.** 또한 `[승인 #21]`은 `incident.create`를 MVP 제외로 명시했다.

| 선택지 | 결과 |
| --- | --- |
| **(a) MVP-core 13항목만** + 절단 1·2 즉시 적용(웹 UI 3화면, 벡터 검색 선택) | 신규 요구의 핵심(관계 범위·개정 승인·행동/결과 구분)은 전부 살아남고 측정·품질에 시간이 남는다. 데모 UI는 소박하고 의미 검색이 없을 수 있다 |
| (b) 전 범위 시도 | 3주차에 무엇이 미완일지 통제 불가. **봉인 평가·안전 게이트(신뢰 장치)가 밀릴 위험이 가장 크다** |
| (c) 관계·컨텍스트까지만 (행동·결과·개정 제외) | 4주 완주 확실. 사용자 업무 흐름 후반(W10~W18 결과 관리·매뉴얼 개선)이 데모에서 사라지고 프로젝트 정의 문장도 수정해야 한다 |

## Q2. 데이터 규모를 어떻게 확정하는가 ★최우선

**배경** `[승인 #5]`(사건 120·카드 채택 150+·산출물 400+·봉인 60·개발 30) ↔ 사용자 제안(사건 30~50·카드 20~40·봉인 15~20·개발 10~15). 사용자는 "고정 요구사항이 아니라 MVP 제안값"이라고 했다.

**전문가 3인의 추천이 갈렸다.**

| | 옵션1 `[승인 #5]` 유지 | 옵션2 사용자 제안 | 옵션3 절충 |
| --- | --- | --- | --- |
| 사건 | 120 | 45 | 72 |
| 카드 채택 | 150 | 33 | 80 |
| 산출물 | 400 | 120 | 220 |
| 봉인 문항 | 60 (안전 12) | 18 (안전 6) | 42 (안전 **15**) |
| 개발셋 | 30 | 12 | 18 |
| 검수 공수 `[제안값 단가]` | **46.7h** | 17.4h | 30.5h |
| 가용 34.5h `[가정]` 대비 | **135% 초과** | 50% | 88% |
| Recall@5 오차 | ±10pp | ±18pp | ±12pp |
| "조건 불일치 ≤5%" 주장 | 가능(0건 시 4.9%) | **불가**(0건 시 상한 15.3%) | 불가 — 0건일 때 ≤10%까지 (상한 6.9%) |
| 기준선 (1)vs(2) 유의성 | 확보 | **확보 곤란** | 확보(경계) |

- 전문가A: **옵션1 유지 + 확장 필드는 사건 일부(약 40건)에만** — 봉인셋을 줄이면 안전 서브셋 12건이 깨져 "안전 누락 0건"을 주장할 수 없다
- 전문가B: **옵션3** — 옵션1은 어떤 낙관 가정에서도 90% 이상을 검수에만 쓰는 구성이다
- 전문가C: **옵션1 유지 + 신규 데이터는 사건 30~50건에만 부착**, kb/dev/sealed 층화

**통합 담당자의 지적**: 전문가B의 46.7h 중 신규 엔티티 몫은 **3.8h뿐**이고, 나머지 42.9h는 `[승인 #5]` 자체의 검수 부담이다. B의 가정이 맞다면 **승인 #5는 신규 범위와 무관하게 이미 가용 공수를 124% 초과한다.** A·C의 "부분 부착"은 신규 몫만 줄이므로 이 초과를 해소하지 못한다. 단 단가와 가용 시간은 모두 `[가정]`·`[제안값]`이다.

**따라서 결정 순서**
1. **0주차에 검수 단가를 실측한다** — 카드 5건·사건 3건을 실제로 검수해 건당 시간을 재고, 전혜민의 실제 가용 검수 시간을 확인한다. 이것으로 논쟁이 끝난다.
2. 가정이 맞으면 → 옵션3, 또는 팀 4명 전원 검수 참여로 가용을 늘린다
3. 가정이 과했으면 → `[승인 #5]` 유지 + 부분 부착

**함께 결정할 하위 항목**
- 사용자 제안 "봉인 평가 15~20"은 **사건 수인가 문항 수인가?** (기존안은 sealed 사건 30 → 문항 60의 2단 구조). 전문가B는 사건 수 해석을 권한다
- **안전 서브셋은 어느 옵션이든 12 → 15로 늘리는 것을 추천한다** (0건 관측 시 참 누락률 상한 22% → 18%)
- 규모를 줄이면 `[미결 #6]`의 "조건 불일치 ≤5%" 문장을 **함께 고쳐야 한다**(Q12와 한 묶음)
