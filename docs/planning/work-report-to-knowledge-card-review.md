# 후속 검토: 근무일지에서 지식카드로 승격

상태: 보류. 실제 장치에서 근무일지 저장 및 후보 생성 검증을 마친 뒤 별도 작업으로 시작한다.

## 검토 범위

- 근무일지 한 건의 여러 기록에서 지식카드 후보가 각각 생성되고, 원본 기록까지 추적되는지 확인한다.
- 작업자가 작성하는 항목만으로 각 카드 유형의 필수 정보, 조치 근거, 결과, 안전 정보가 충족되는지 확인한다.
- 후보 검토, 보완, 반려, 승인 및 최종 지식카드 반영 경로를 DB와 화면 양쪽에서 검증한다.
- 중복 카드, 상충 내용, 수정 이력, 증거 부족, 중앙 DB 동기화에 대한 승격 기준을 정한다.
- 실제 작업자 입력 사례와 실패 사례를 사용해 작성 부담과 승격 가능 여부를 평가한다.

## 시작할 때 확인할 자료

- `shiftlink/mes/work_reports.py`, `shiftlink/mes/storage.py`, `shiftlink/mes/web/candidate-review.js`
- `docs/planning/현장해결기록_고도화_검토_20261013.md`
- 2026-10-20 실제 장치 검증 결과: 시험 근무일지 1건에서 T1, T2, T5 검토 대기 초안과 T3 근거 부족 후보가 생성됨. 이는 후보 생성 검증이며 지식카드 승격 검증은 아님.

완료 기준: 후보부터 승인된 지식카드까지의 데이터 연결과 화면 동작을 재현하고, 부족한 근무일지 항목과 작업자 입력 흐름의 개선안을 근거와 함께 제시한다.
