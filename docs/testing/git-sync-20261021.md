## 최종 동기화 확인 방법

```powershell
git rev-list --left-right --count 'HEAD...@{upstream}'
git rev-list --left-right --count main...origin/main
git merge-base --is-ancestor origin/main HEAD
git diff --exit-code origin/main -- shiftlink/mes/web/pda.html shiftlink/mes/web/pda.js shiftlink/pda
```

앞 두 명령이 각각 `0 0`, 뒤 두 명령의 종료 코드가 0이면 현재 커밋과 원격 기준 PDA가 일치한다.
미커밋 작업은 이 커밋 동기화와 구분하며 자동으로 원격에 게시하지 않는다. 정기 자동 동기화 설정은 추가하지 않았다.
