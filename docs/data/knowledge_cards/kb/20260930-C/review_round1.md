판정은 초안의 출처·내용 대조이며 사람 승인 또는 현장 안전 승인으로 사용하지 않는다.

## 확인 방법과 접근 편차

작업가이드, 스키마, MES 사전, 기존 A T2 두 장, T4 대조 방법, 생성 out 19장, records/kb_events.json·kb_artifacts.json을 읽었다. PDF를 직접 PyMuPDF로 열어 해당 실제 페이지를 추출·렌더링했다. 생성자가 작성한 대조문만을 원문 근거로 쓰지 않았다. 실제 표와 흐름도 확인 이미지는 tmp/pdfs/batch-c-independent/에 있다.

검토 중 events.json 전체 출력이 true_cause·cards_expected·dev 사례를 함께 노출했다. eval/는 읽지 않았다. 이 접근 편차로 검토자는 엄밀한 블라인드 평가자가 아니다. 이후 내용 판정과 수정 근거는 KB 관측 투영·PDF에 한정한다. 원장 정답과 dev 사례로 근거를 보충하지 않는다.

## 공통 수정 판정

1. T6 9장 PDF source_id는 가이드의 파일명 계약에 맞춰 basename으로 정리한다.
2. T2 공통 extraction_method는 관련 없는 HPU 흐름도 확인을 모든 설비에 붙였다. 카드별 실제 원문 확인 방식으로 정리한다.
3. T6 기록 여러 쌍은 ID만 다른 동일 템플릿 관측이다. 2건의 서로 다른 사건 ID라는 가이드 최소 형식은 충족하나 독립 현장 반복/통계 증거가 아니다. confidence_basis를 동일 템플릿 합성 반복임이 보이도록 수정한다. 관측 다양성을 지어내어 원장을 고치지 않는다.
4. T2 검색 조건은 후보선정이고 본문 일부 분기는 카탈로그에 없는 확인사항이다. 구조/표시기/소음 유형/실제 과전류 차단을 MES가 자동 검증한다고 표현하지 않는다.
5. 모든 변경은 별도 review_changes.json으로 추적하며 고정 prompt·해시는 그대로 보존한다.

최종 판정 예정: 수정 후 19장 draft/L0 유지. 사람 검토와 설치 모델·현장 작업표준 확인은 남는다.
