## K-1001 · HPU · T3 — 기어·베인 펌프 출구 압력이 없을 때 확인 순서 — Algo A.1 좌측 분기

- **부품**: 주 베인펌프
- **증상**: 펌프 운전 중 펌프 출구 압력계에 압력이 읽히지 않는다.
- **노하우**: 1) 펌프 출구 압력 유무를 확인한다. 2) 축이 도는지 본다. 3) 계통이 무부하인지 본다. 4) 동작이 일어나는지 본다. 5) 구동 회전 방향, 6) 회전 방향에 맞는 조립, 7) 프라이밍 여부를 차례로 확인한다. 8) 릴리프 밸브 탱크 라인으로 유량이 흐르면 릴리프 밸브를, 흐르지 않으면 펌프를 점검한다. 각 단계에서 이상이 나오면 해당 조치를 하고 순서를 멈춘다.
- **근거 설명**: Vickers 흐름도 Algo A.1(기어·베인 펌프 계통 시험)은 출구 압력이 없을 때 축 회전→무부하→동작→회전 방향→조립→프라이밍→릴리프 탱크 라인 유량 순으로 YES/NO 분기와 분기별 조치를 명시한다. 제조사 권고 진단 절차이며 실제 수행 기록이 아니다. 압력이 있는 경우(우측 분기)는 이 카드에 넣지 않았다.
  1. 펌프 출구 압력계에서 압력이 읽히는지 확인한다. → 압력이 없으면(NO) ST-02로 진행한다. / 중지: 압력이 읽히면(YES) 이 카드 범위가 아니다. Algo A.1 우측 분기(정상 계통압 여부 확인)로 넘어간다.
  2. 펌프 축이 회전하는지 확인한다. → 회전하면(YES) ST-03으로 진행한다. / 중지: 축이 돌지 않으면(NO) 펌프 구동부를 점검한다(Check drive to pump).
  3. 계통이 무부하(off-loaded) 상태인지 확인한다. → 무부하가 아니면(NO) ST-04로 진행한다. / 중지: 무부하이면(YES) 계통에 부하를 건다(Load system).
  4. 액추에이터 동작이 일어나고 있는지 확인한다. → 동작이 없으면(NO) ST-05로 진행한다. / 중지: 동작이 있으면(YES) 이 순서를 멈추고 원문 흐름도에서 연결 분기를 직접 확인한다(텍스트 추출로는 YES 분기 연결 대상을 확인하지 못했다).
  5. 구동 회전 방향이 맞는지 확인한다. → 맞으면(YES) ST-06으로 진행한다. / 중지: 틀리면(NO) 회전 방향을 바로잡는다(Correct rotation).
  6. 펌프가 회전 방향에 맞게 조립되었는지 확인한다. → 맞으면(YES) ST-07로 진행한다. / 중지: 아니면(NO) 펌프를 올바르게 재조립한다(Reassemble pump correctly).
  7. 펌프가 프라이밍되었는지 확인한다. → 프라이밍되어 있으면(YES) ST-08로 진행한다. / 중지: 아니면(NO) 펌프를 프라이밍한다(Prime pump).
  8. 릴리프 밸브 탱크 라인으로 유량이 흐르는지 확인한다. → 흐르면(YES) 릴리프 밸브를 점검하고, 흐르지 않으면(NO) 펌프를 점검한다.

## K-1002 · HPU · T3 — 수냉식 오일 쿨러 출구 유온 확인 순서 — Algo J.2

- **부품**: 오일 쿨러
- **증상**: 냉각기 출구 포트의 오일 온도가 높거나, 냉각기가 제 역할을 하는지 판단이 필요하다.
- **노하우**: 1) 냉각기 출구 포트에서 유온을 잰다. 너무 높지 않으면 오일 입·출구 온도차를 본다(차이 있음=냉각기 정상, 없음=작동 온도 도달 후 재확인). 너무 높으면 2) 냉각수 공급, 3) 써모스탯 조정, 4) 냉각수 출구 온도>입구 온도 여부, 5) 냉각수 입구 온도, 6) 냉각기 통과 오일 유량을 차례로 확인한다.
- **근거 설명**: Vickers 흐름도 Algo J.2(냉각기 계통 시험)는 출구 유온 확인에서 시작해 냉각수 공급→써모스탯→수온 상승→입구 수온→오일 유량 순으로 YES/NO 분기와 조치를 명시한다. '너무 높다'의 온도 기준값은 원문에 없다. 제조사 권고 진단 절차이며 실제 수행 기록이 아니다.
  1. 냉각기 출구 포트에서 오일 온도를 확인한다. → 온도가 너무 높으면(YES) ST-03으로 진행한다. 너무 높지 않으면(NO) ST-02로 진행한다.
  2. 오일 입구·출구 온도 사이에 차이가 있는지 확인한다. → 차이가 있으면(YES) 냉각기는 작동 중이다. 목록의 다음 장치를 점검한다. / 중지: 차이가 없으면(NO) 오일이 작동 온도에 도달한 뒤 다시 확인한다.
  3. 냉각수 공급이 켜져 있는지 확인한다. → 켜져 있으면(YES) ST-04로 진행한다. / 중지: 꺼져 있으면(NO) 냉각수 밸브를 연다(Open water valve).
  4. 써모스탯이 조정되어 있는지 확인한다. → 조정되어 있으면(YES) ST-05로 진행한다. / 중지: 아니면(NO) 써모스탯을 재조정한다.
  5. 냉각수 출구 온도가 냉각수 입구 온도보다 높은지 확인한다. → 높으면(YES) ST-06으로 진행한다. / 중지: 높지 않으면(NO) 냉각기를 점검한다.
  6. 냉각수 입구 온도가 너무 높은지 확인한다. → 너무 높지 않으면(NO) ST-07로 진행한다. / 중지: 너무 높으면(YES) 냉각수 공급을 점검한다.
  7. 냉각기를 통과하는 오일 유량이 맞는지 확인한다. → 유량이 맞으면(YES) 냉각기를 점검한다. 맞지 않으면(NO) 계통의 손실을 확인한다.
- **출처**: 100980172-Logical-Troubleshooting-in-Hydraulic-Systems.pdf PDF p.29 / 인쇄 p.29 / Algo J.2 System test for coolers
- **작성 노트**: | S02 | K-1002 | T3 | 수냉식 오일 쿨러 출구 유온 확인 순서 — Algo J.2 | 100980172-Logical-Troubleshooting p.29 | HPU-C43 | ok | 온도 기준값은 원문에 없음. 대상 쿨러의 냉각 방식 미확인 |

## K-1003 · HPU · T5 · ⚠ 안전 — 용적형 펌프 과압 보호 없이 운전 금지·릴리프 설정을 펌프 최대 정격 위로 두지 않기

- **부품**: 릴리프 밸브
- **노하우**: 용적형 펌프는 배압과 관계없이 유량을 내보내려 하므로 과압 보호(릴리프 밸브) 없이 운전하지 않는다. 릴리프 밸브는 펌프 토출 라인에 가능한 가깝게, 사이에 다른 밸브 없이 연결한다. 설정은 실무상 가능한 낮게 하고, 100% 바이패스 시 압력 누적을 포함해 펌프 최대 정격 압력보다 높게 두지 않는다. 릴리프 리턴 라인을 펌프 흡입 라인으로 배관하지 않는다. 설정 변경이 필요하면 담당자 확인 후 진행한다.
- **근거 설명**: Parker 스크류 펌프 매뉴얼 §3.7.2가 DANGER 문구로 과압 보호 미비 시 펌프·구동기 고장과 펌프·배관 파열 위험을 명시하고, 설정 상한과 리턴 라인 배관 금지를 규정한다. 스크류 펌프 문서 기준이며 대상 HPU(베인펌프)의 정격 압력값은 원문에 없다.
- **안전 근거**: HY13-PMDSPS1M-M1/US §3.7.2 DANGER: 용적형 펌프에 과압 보호를 제공하지 않으면 펌프·구동기 고장 또는 펌프·배관 파열이 생길 수 있다. 같은 절: 릴리프 밸브를 펌프 최대 정격 압력(100% 바이패스 시 압력 누적 포함)보다 높게 설정하지 말 것, 릴리프 리턴 라인을 펌프 흡입 라인에 배관하지 말 것(루프로 펌프 과열).

## K-1004 · HPU · T1 — 베인펌프 소음 증가와 유면 우유빛 거품 — 에어레이션 징후

- **부품**: 주 베인펌프
- **증상**: 펌프 소음이 평소보다 크고, 요구 유량이나 압력이 나오지 않으며, 탱크 유면이 거품으로 우유빛(milky)을 띤다.
- **노하우**: 이 세 가지가 함께 보이면 작동유에 공기가 섞였을(에어레이션) 가능성을 먼저 의심한다. 추가로 흡입 배관 밀봉 상태, 축 씰 상태, 리턴 라인 끝이 유면 아래에 있는지, 흡입구가 리턴 라인 정면에 있지 않은지, 탱크 유면이 흡입 위치보다 충분히 높은지를 확인해 기록한다. 우유빛 외관은 수분 오염으로 생긴 거품에서도 나타나므로 이것만으로 원인을 단정하지 않는다.
- **근거 설명**: Denison 베인펌프 고장 가이드 §2.4 2)는 공기 혼입 시 베인이 불균형해져 가장 먼저 드러나는 것이 비정상 소음이며, 심한 마모 전에 유량·압력 미달과 유면의 우유빛 거품이 나타난다고 설명하고, 흡입관 누설·축 씰 열화·리턴 라인 위치·낮은 유면 등을 원인으로 든다. 같은 가이드 §6은 수분 오염 거품도 우유빛이라고 적는다. 정상/이상 외관의 정량 경계는 원문에 없다.

## K-1005 · HPU · T3 — 축압기 프리차지·충전 압력 확인 순서 — Algo J.1

- **부품**: 축압기
- **증상**: 축압기가 계통에서 제 역할을 하는지 의심되어 가스 프리차지와 충전 압력 확인이 필요하다.
- **노하우**: 1) 제조사 지침대로 가스측에 시험 게이지를 단다. 2) 축압기의 유체를 배출하고 가스압(프리차지)을 확인한다. 틀리면 질소로 정상 압력까지 충전한다. 3) 펌프를 정지하고 축압기를 배출한다. 4) 유체 라인에 압력계를 단다. 5) 축압기를 유체 계통 압력까지 충전한다. 6) 압력 읽음이 맞는지 본다. 틀리면 7) 압력 스위치 설정, 8) 릴리프 밸브·보상기 조정을 차례로 확인한다.
- **근거 설명**: Vickers 흐름도 Algo J.1(축압기 계통 시험)은 가스측 게이지 설치→프리차지 확인→펌프 정지·배출→유체측 게이지→충전→압력 확인→압력 스위치→릴리프/보상기 순으로 분기와 조치를 명시한다. 프리차지·계통 압력의 정상값은 원문에 없고 제조사 지침을 따르게 되어 있다. 제조사 권고 진단 절차이며 실제 수행 기록이 아니다.
  1. 제조사 지침에 따라 축압기 가스측에 시험 게이지를 설치한다. → 가스측 압력을 읽을 수 있게 된다.
  2. 축압기에서 유체를 배출하고 가스 압력을 확인한다. → 프리차지 압력이 맞으면(YES) ST-03으로 진행한다. 틀리면(NO) 질소로 정상 압력까지 충전한다.
  3. 펌프를 정지하고 축압기를 배출한다. → 축압기가 배출된 상태가 된다.
  4. 유체 라인에 압력계를 설치한다. → 유체측 압력을 읽을 수 있게 된다.
