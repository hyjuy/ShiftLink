## 감점 내역

### D1-1 (-4 / 6) — K-0301 카드 존재 확인 불가
**근거**: 프레임 10 / 정본 미발견

화면 프레임 10의 조치 카드 영역에서 K-0301(T3 "다수 장비 동시 응답 지연 시 공급원 확인 순서")이 표시되나, 정본 데이터에서 발견되지 않음:
- 01_kb_cards_shared.json: K-0108, K-0109, K-0110만 포함
- EV-0031: K-0101~K-0107 (K-0301 미포함)
- EV-0032: K-0201 (K-0301 미포함)
- EV-0033: 파일 시작 부분에서 cards_expected가 K-0105, K-0110만 지정 → K-0301 미포함 확인

**이 카드가 정본에 없으면** D1(실값 사용)의 정의상 감점 필수.

### D1-2 (-0.5 / 6) — K-0201 검색 미반영 상태의 화면 표시
**근거**: EV-0032 / split="dev" / searchable_after_publish=false (암묵적)

프레임 10에서 K-0201이 조치 2번으로 표시되나, 정본의 K-0201은 EV-0032(dev 분할, 미발행)에 속함. 루브릭에서는 "검색 결과를 생성보다 먼저 올린다"고 명기하였는데, 실제 앱의 검색 결과에는 미반영되어야 함. 목업 표시가 실제 검색 결과를 대표하지 않을 가능성 있음 (검색 실행 결과와 목업의 불일치 가능성).
→ 확신 부족으로 감점 0.5

### D3-1 (-2 / 4) — 원천 없는 K-0301의 표기 불충분
**근거**: 프레임 10 / "예시" 명시 부재

AT-0001, AT-0002는 "예시"로 명시되어 D3 기준을 충족하나, K-0301은:
- 카드 ID로만 표기 (K-0301 · T3 형식)
- "원천 없음" 또는 "예시" 등 명확한 구분 표기 부재
- 정본에 존재하지 않음이 화면에서 인지되지 않음

D3의 요구사항 "원천 없는 것은 제외하거나 '원천 없음' 표기" 미충족.
