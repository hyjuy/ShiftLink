# 작업 완료 확인·인수 근거 — HSE, 2026-10-01 확인

## 직접 확인한 원문

- HSE, [Shift handover](https://www.hse.gov.uk/humanfactors/topics/shift-handover.htm), “Why is handover important?”: 인수자가 책임을 이어받을 때 작업 관련 정보를 교차 확인하는 단계가 필요하다. 일반 인계 원칙이며 특정 커플링 점검 항목을 제공하지 않는다.
- HSE, [Guidance on permit-to-work systems, HSG250](https://books.hse.gov.uk/gempdf/hsg250.pdf), 2005, PDF/인쇄 p.13 §23–24: 다음 조에 미완료 작업과 설비 상태를 전달한다. 작업 완료는 수행 책임자가 확인하고, 설비 상태는 허가 종료 책임자가 확인하며, 운전 담당자는 설비 인수를 기록한다.
- 같은 원문 PDF/인쇄 p.14 §25: 허가 발급 책임자는 작업 시작·완료 시 현장 확인을 포함하며 서류 확인만으로 끝내지 않는다.
- 같은 원문 PDF/인쇄 p.24 Figure 1 항목 12–13: 작업 완료 반환 확인과 시험·운전 복귀 확인은 별도 단계다.

## 적용 및 해석

일반 교차 확인 원칙에서 진행 기록과 책임자의 확인을 대조하는 인수 절차를 구성했다. 현장 작업 오더/체크리스트의 식별자, 확인 항목, 결과, 완료 시각과 수행자, 미결 항목을 확인·요청하도록 정리한 것은 프로젝트의 적용 해석이다. HSE가 국내 모든 현장에 동일한 서식이나 승인 체계를 요구한다고 해석하지 않는다.

HSG250의 수행자·허가 종료자·운전 담당자 구분은 작업허가제가 적용되는 경우에 한정한다. 적용 여부를 모르면 현장 절차와 지정 책임자를 먼저 확인한다. 담당자 퇴근이나 ‘진행 중’ 기록으로 완료·미완료를 확정하지 않고, 완료 확인 근거가 없으면 미확인으로 기록하여 인수 책임자에게 확인을 요청한다. 작업 완료 확인과 재가동 허가는 구분한다. 확인을 위해 임의 기동·분해·잠금 해제를 지시하지 않는다.

## 카드 및 평가 연결

문헌 기반 T4 절차 K-1401을 별도 배치에 둔다. 기존 T4 사건 배치의 ‘KB 사건 2건 이상’ 규칙을 문헌으로 대체하지 않는다. 합성 사건을 추가하지 않으며 dev/sealed 사건을 근거로 사용하지 않는다. H-019 원문을 유지하고 ‘실제 작업이 완료됐다’가 아니라 ‘완료 확인 방법을 안내할 수 있다’를 answerable 판정 대상으로 삼는다. 현장의 GR-02 완료 여부 자체는 미확인이다.
