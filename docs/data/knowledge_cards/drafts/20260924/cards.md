# 원문 기반 지식카드 3건

**AI가 생성한 검토용 초안(draft/L0)이다.** 출처 SD-005는 pending_review이며 사람 승인·현장 안전 검토 전이다. 아래 내용은 **M-101-2012(2012.6.20) 문헌 요약**으로, 현행 법적 적합성이나 현장 작업 허가를 뜻하지 않는다. 운영 KB에 적재하지 않았다.

공통 버전은 `1.1-draft-20260924-001`, 설비 분류는 CV다. `split=kb`는 문서 계보 해시로 산출한 미등록 배정 제안이다. `confidence=0.0`은 미평가 sentinel이며 확률·정확도 점수가 아니다. 이 값을 런타임 판단에 사용하지 않는다.

## K-0301 · 정지스위치 주변 장애물 금지

- 유형: T5(독립 안전 금기) / 독자 분류: S1(신입)
- 지식: M-101-2012 §4.3(3)은 컨베이어 정지스위치 주위에 장애물을 놓아두지 않도록 정한다.
- 판단 근거: 원문의 사용 항목에 정지스위치 주변 장애물 금지가 직접 제시된다.
- 출처: SD-005, PDF p.7 / 인쇄 p.5 / 4.3 사용 (3), 근거 P-01.
- 적용 한계: 장애물 제거를 위한 운전 중 접근 허가, 에너지 격리 절차, 점검 주기·거리 기준은 이 조항에서 도출하지 않았다.

## K-0302 · 비상·사고 정지 후 재기동 전 원인·보수상황 확인

- 유형: T6(재기동 전 확인) / 독자 분류: S2(저년차)
- 지식: 비상정지 중 또는 사고로 정지 중인 컨베이어를 재기동하기 전에 정지의 원인 및 고장 장소의 보수상황 등을 먼저 확인하도록 정한다.
- 판단 근거: M-101-2012 §4.3(7)이 재기동에 앞선 확인 대상을 제시한다. 비상·사고 정지 맥락을 `abnormal_stop_restart`로 분류했다.
- 출처: SD-005, PDF p.7 / 인쇄 p.5 / 4.3 사용 (7), 근거 P-02.
- 적용 한계: 이 확인만으로 재기동이 승인되거나 안전이 보장된다는 의미가 아니다. 스위치 조작 순서·인터록 해제·수리 방법·재가동 성공 및 실패 경험을 만들지 않았다.

## K-0303 · 컨베이어 올라가기 금지와 원문 예외

- 유형: T5(독립 안전 금기) / 독자 분류: S1(신입)
- 지식: 근로자가 컨베이어에 올라가지 않도록 정한다. 작업상 부득이한 경우로서 사업주가 안전상 필요한 조치를 강구한 경우에는 원문의 예외가 있다.
- 판단 근거: M-101-2012 §4.3(11)의 금지와 예외를 함께 보존했다.
- 출처: SD-005, PDF p.8 / 인쇄 p.6 / 4.3 사용 (11), 근거 P-03.
- 적용 한계: 정지만 하면 올라가도 된다는 허가가 아니다. 필요한 안전조치의 구체 종류·충분조건·승인자·연락 채널은 제시하지 않았다. 예외를 자동 판정하는 검색 제외 조건으로 변환하지 않았다.

## 생성하지 않은 후보

SKF P-04는 단일 사례의 설계개선 제안이다. 조건에 따라 달라지는 재사용 요령이 확인되지 않아 T2로 강제 분류하지 않고 보류했다. NSK 사례는 프로젝트 설비 대응 근거가 부족해 보류했다. 상세 판단과 후속 질문은 [author-notes.md](author-notes.md)에 있다.

기계 판독본은 [cards.json](cards.json), 필드별 근거와 관리 메타데이터 구분은 [evidence-map.json](evidence-map.json), 원문 발췌는 [source-packet.json](source-packet.json)에서 확인한다.
