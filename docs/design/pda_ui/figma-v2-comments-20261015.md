## 후속 반영 때 확인할 사항

- #48은 1차의 “테두리 대신 볼드” 방향에서 변경된 요구다. 테두리 버튼을 유지하고 선택 시 배경색·글자색을 바꾸도록 한다.
- #50은 독립된 전체 선택 버튼을 표 헤더 체크박스로 바꾸는 요구다.
- #56은 선택한 단일 설비의 정비이력 화면을 요구한다. 전체 인계사항 목록의 흐름(#63)과 구분해 반영한다.
- #60은 MES 센서 데이터가 없다는 지적이다. 데이터 표시가 필요한 범위와 기존 센서 불러오기 삭제 요구의 관계는 구현 전에 확인한다.
- #45·#46·#59의 “공백”은 위치만 확인했다. 삭제·축소·재배치 등 구체적인 처리는 원문에 없어 확정하지 않았다.
- #44의 이동 대상 요소와 #62의 정확한 대상 프레임은 후속 반영 시 핀을 재확인한다.
