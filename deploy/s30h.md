- The judge-only Ollama service, the switch order and the rollback order (sudo) are in `ShiftLink-records/deploy/jetson_s30h_sudo_plan_20261016.md`.

## Response format (open question)
- The PDA receives the same `AgentResponse`.
- Manual pages the answer cites go on the last line of the answer as `근거: <document> p.N`. Card ids go in `cited_card_ids`.
- `safety_notices` are the KB safety cards that fit the equipment, with the same rule as the PDA's `cardFits`.
- How the PDA should show manual citations is still undecided.

## Experimental R5 source conditions (default off)

- `SHIFTLINK_S30H_SOURCE_CONDITIONS=1` enables the two-card R5 postprocessor. Omit it or set `0` for the existing answer rendering. Do not enable it on the demo service without separate approval.
- Only actually cited K-1012/K-1027 cards at revision `1.1-safety-20261020` qualify. Their condition excerpt must also occur verbatim in the cited index chunk; an old or mismatched index causes that card to be skipped. The unchanged answer must not be interpreted as a safety-validated answer.
- No additional model calls, prompt changes, threshold changes or authorization checks are performed. An abstained answer stays empty. `s30h_trace.source_condition_cards` lists applied cards when the option is on.
- This is an experimental condition renderer, not a safety validator. It preserves existing factual/branch errors, can expose conditional procedures despite unknown applicability, and adds roughly 255 characters in the saved pilot. It is not evidence that the current machine is ready for work.
- Before adoption, separately approve a Jetson check using an isolated app copy: check card/index revision consistency, condition retention in the actual MES response and PDA, no truncation, unchanged abstention/routing, and end-to-end latency. Keep the running demo service and its configuration unchanged. No Jetson measurement or deployment was done for this PR.
- Research scope and AI grading limitations: [R5 exploratory result](../docs/experiments/source-conditions-r5-20261020.md).
