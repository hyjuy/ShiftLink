# 카드 작성 가이드 초안 — 유형 경계 판정 규칙

> 대응 항목: 전문가1 검토 3-1
>
> 작성일: 2026-09-17
>
> 상태: 검토 요청용 잠정안
>
> 적용 대상: K-01 `KnowledgeCard.tacit_type` (`T1`~`T5`)

## 1. 목적과 전제

이 문서는 하나의 지식이 여러 유형에 걸쳐 보일 때 카드의 **주 유형을 일관되게 판정**하기 위한 작성·검수 기준이다. 유형은 소재에 포함된 단어가 아니라, 카드가 작업자에게 제공하는 **주된 효용**으로 정한다.

현재 T1~T5의 전문가1 원 정의문과 최종 포함·제외 기준은 확인되지 않았다. 따라서 아래 규칙은 [`docs/A_domain.md`](../docs/A_domain.md)의 잠정 정의와 [`shiftlink/agent/schemas.py`](../shiftlink/agent/schemas.py)의 스키마 v0.9를 기준으로 만든 **잠정안**이다. 원 정의가 확인되면 차이를 기록하고 이 문서를 개정한다.

## 2. 유형별 판정 기준

| 유형 | 주된 질문 | 포함 | 제외 또는 다른 유형으로 보내는 기준 |
| --- | --- | --- | --- |
| `T1` 감각 기반 이상 징후 판단 | “무엇이 평소와 다르게 느껴지고, 그것을 어떻게 해석하는가?” | 소리·진동·냄새·열감·리듬 등 감각 단서와 정상 대비 차이, 추가 확인점 | 여러 단계의 진단 절차가 중심이면 T3. 조건별 작업 요령이 중심이면 T2. 감각 표현 없이 계측 임계값만 제시하면 원칙적으로 T1 아님 |
| `T2` 조건부 요령 | “어떤 조건에서 어떤 요령을 적용하거나 제외하는가?” | 운전 모드·속도·품목·설비 상태 등에 따른 행동 선택, 적용·제외 조건 | 순서대로 원인을 좁히는 절차가 중심이면 T3. 금지·중지·격리가 핵심이면 T5. 단순히 조건이 언급됐다는 이유만으로 T2로 정하지 않음 |
| `T3` 트러블슈팅 순서 | “증상 발생 후 무엇부터 확인하고 어디서 분기·종료하는가?” | 2단계 이상의 확인 순서, 분기, 종료·보류 기준, 원인 후보 축소 | 독립된 한 가지 요령이면 T2. 감각 단서의 의미 해석만 있으면 T1. 순서 없는 점검 항목 나열은 보완 전까지 T3로 채택하지 않음 |
| `T4` 인수인계 맥락 | “다음 작업자가 무엇을 이어서 판단해야 하는가?” | 현재 상태, 이미 확인한 것, 미해결 사항, 임시 조치, 다음 확인점과 관찰 시점 | 다른 유형의 내용을 단순히 전달 문장으로 바꾼 것은 T4가 아님. 재사용 가능한 판단·요령·절차·금기는 각각 T1·T2·T3·T5로 작성하고 인계 기록에서 참조 |
| `T5` 안전 금기 | “어떤 행동을 하면 안 되며 언제 멈추거나 격리해야 하는가?” | 금지 행동, 작업 중지, 에너지 격리, 접근 제한, 보호조치와 안전 근거 | 안전 주의가 부수적으로 붙은 카드 전체를 T5로 바꾸지 않음. 다만 안전 금기 자체가 독립적으로 재사용되어야 하면 T5 카드로 분리 |

현재 코드가 강제하는 최소 조건은 다음과 같다.

- T1·T3: `symptom` 필수
- T2: `conditions` 1개 이상 필수
- T5: `safety_flag: true` 및 `safety_basis` 필수
- T1~T4도 안전 관련 내용이 있으면 `safety_flag: true`와 `safety_basis`를 작성

## 3. 경계 판정 절차

원문에서 서로 독립적인 지식을 먼저 분리한 뒤, 각 카드 후보에 다음 순서로 질문한다.

1. **금지·중지·격리 자체가 핵심인가?** 그렇다면 T5다.
2. **증상에서 시작하는 둘 이상의 확인 단계와 분기가 핵심인가?** 그렇다면 T3다.
3. **적용 조건에 따라 달라지는 한 가지 요령이 핵심인가?** 그렇다면 T2다.
4. **감각 단서를 정상 상태와 비교해 알아차리거나 해석하는 것이 핵심인가?** 그렇다면 T1이다.
5. **현재 상태와 미해결 사항을 다음 작업자에게 이어 주는 것이 핵심인가?** 그렇다면 T4다.
6. 어느 질문에도 명확히 답하지 못하면 유형을 억지로 지정하지 말고 `판정 보류`로 검수에 올린다.

한 카드로 유지해야 하는데 둘 이상의 유형이 남으면 잠정 우선순위 **T5 > T3 > T2 > T1 > T4**를 적용한다. 이 우선순위는 카드 분리를 대신하지 않는다. 독립적으로 검색·재사용할 수 있는 내용은 먼저 나누고, 분리할 수 없는 경우에만 사용한다.

## 4. 자주 혼동하는 경계

### T1과 T2

- “고주파 금속음이 평소보다 촘촘해지면 회전부 마찰 가능성을 의심한다”처럼 **감각 차이의 인지·해석**이 중심이면 T1이다.
- “라인 속도가 특정 조건일 때만 청음 위치를 바꾼다”처럼 **조건에 따른 요령 선택**이 중심이면 T2다.
- T1에도 관측 조건은 있을 수 있고, T2에도 감각 표현은 있을 수 있다. `conditions`의 존재만으로 결정하지 않는다.

### T2와 T3

- “A 조건이면 B를 한다”라는 한 번의 조건부 행동은 T2다.
- “증상 확인 → 공통 원인 배제 → 상류 확인 → 당해 장비 확인”처럼 **순서와 분기**가 판단 가치를 만들면 T3다.
- T3의 한 단계가 별도로도 반복 사용되는 조건부 요령이면 T2 카드로 분리하고 T3에서 참조할 수 있다.

### T3와 T5

- 점검 순서 중 안전 단계가 포함되어도 주 효용이 원인 축소라면 주 카드는 T3이며 `safety_flag`를 켠다.
- “운전 중 커버를 열지 말 것”, “에너지 격리 전 접근 금지”처럼 **금지 자체를 먼저 노출해야 하는 지식**은 T5로 분리한다.
- 안전 조치를 진단 단계 중 하나로만 묻어 두지 않는다.

### T4와 나머지 유형

- “현재 속도 하향 상태, 원인 미확정, 다음 조에서 30분 간격 확인”은 사건에 묶인 인계 맥락이므로 T4다.
- “속도 하향 시 증상 변화로 원인 후보를 구분한다”는 재사용 가능한 요령이므로 T2다.
- “다음 조에 전달한다”는 문장만 추가됐다는 이유로 T1·T2·T3·T5 지식을 T4로 바꾸지 않는다.

## 5. 카드 분리와 병합 규칙

다음 중 하나라도 해당하면 카드를 분리한다.

- 금지 행동과 진단 절차가 한 카드에 함께 있어 안전 금기가 뒤로 밀린다.
- 서로 다른 조건에서 행동 또는 제외 기준이 달라진다.
- 순서 전체 없이도 독립적으로 검색할 가치가 있는 감각 판단이나 조건부 요령이 있다.
- 인계 시점의 사건 상태와 장기간 재사용할 지식이 섞여 있다.
- 한 문장으로 카드의 주된 질문을 설명할 수 없다.

반대로 같은 증상, 같은 적용 조건, 같은 판단 목적을 설명하기 위해 감각 단서와 확인 행동이 붙어 있는 정도라면 한 카드로 유지한다. 유형별 카드 수를 맞추기 위해 같은 지식을 표현만 바꿔 중복 생성하지 않는다.

## 6. 판정 예시

| 원문 후보 | 판정 | 이유 / 처리 |
| --- | --- | --- |
| “평소보다 굵고 불규칙한 진동이 손에 느껴지면 회전체 상태를 추가 확인한다.” | T1 | 감각의 정상 대비 차이와 해석이 핵심 |
| “저속 운전 중에만 접촉음이 사라지면 속도 조건을 기록하고 즉시 정상으로 단정하지 않는다.” | T2 | 운전 조건에 따른 판단 요령이 핵심 |
| “인터록 확인 → 공통 유틸리티 확인 → 상류 구동부 확인 → 해당 장비 내부 확인.” | T3 | 확인 순서가 핵심. 각 단계의 분기·종료 조건을 보완해야 채택 가능 |
| “임시 속도 하향 중이며 원인은 미확정이다. 다음 조는 30분 간격으로 재발 여부를 확인한다.” | T4 | 특정 사건의 현재 상태와 다음 확인점을 전달 |
| “운전 중 커플링 접근 금지. 정지 및 에너지 격리 후 점검한다.” | T5 | 금지·격리가 독립적인 핵심. 유효한 `safety_basis` 확인 필요 |
| “이상음을 확인한 뒤 커버를 열어 내부를 본다.” | 판정 보류 | 안전 조건이 빠져 있으며 위험 행동으로 읽힐 수 있음. 안전 검수 전 카드화 금지 |

## 7. 작성·검수 기록

각 카드의 검수 메모에는 아래 형식을 남긴다. 이 메모는 현재 K-01 필드가 아니므로 카드 JSON에 임의 필드로 넣지 않고 별도 검수 기록에 둔다.

```text
주 유형: T_
주된 질문:
경합 유형:
경합 유형을 제외한 이유:
분리 카드 필요 여부 및 연결 대상:
적용한 우선순위(해당 시):
판정 근거가 된 원문 위치:
미결 또는 전문가 확인 질문:
```

## 8. 전문가1 검토 요청 사항

1. T1~T5의 원 정의문과 필수 포함·제외 기준이 위 잠정 정의와 일치하는가?
2. 동일 지식이 겹칠 때 `T5 > T3 > T2 > T1 > T4` 우선순위를 써도 되는가?
3. 안전 금기는 항상 별도 T5 카드로 분리해야 하는가, 아니면 `safety_flag`만으로 충분한 예외가 있는가?
4. T4는 사건별 인계 기록인가, 재사용 가능한 인계 작성 요령인가, 또는 둘 다인가?
5. 순서가 없는 점검 목록을 T3로 허용할 것인가?
6. 정지·재가동 지식을 기존 T2·T3·T5로 분류할지, 별도 T6으로 둘지?

검토 답변을 받을 때는 각 항목을 `유지 / 수정 / 폐기`로 표시하고, 수정된 정의의 적용 시작 버전과 기존 카드 재분류 필요 여부를 함께 기록한다.
