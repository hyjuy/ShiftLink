# R5: 출처 조건 결합 탐색 결과

## 범위

R5는 모델에 안전조건을 다시 쓰게 하는 대신, 최종 답에서 실제 인용한 카드의 조건 단락을 코드가 먼저 연결하는 실험이다. K-1012/K-1027의 `1.1-safety-20261020` 버전에만 적용한다. 카드와 해당 인용 조각에 조건 문구가 일치해야 한다. 카드 보강은 별도 PR #309에서 반영됐다. 이번 변경에는 카드·색인 수정이 없다.

기존 KB3 C 저장 결과31문항×두 반복(62행)을 인스턴스 CPU에서 재생했다. 새 모델·판정기 호출0. 반복 둘을 독립 표본으로 세지 않았다. 검색·원문 답·확률·임계값·거절·인용은 고정하고 최종 조건 연결만 바꿨다. 봉인60·보류셋·test30과 Jetson은 사용하지 않았다.

## 결과와 해석 제한

최종 답이 바뀐7문항을 같은 Codex가 사용자 정의5종 중대 오류 기준으로 예비 채점했다. **독립·블라인드·최종 사용자 채점이 아니다.** 이전 다른 출력에 대한 사용자 판정은 변경하지 않았다.

| 문항 | 기준선 → 후보(AI 예비) | 남은 문제 |
|---|---|---|
| B3-015 | 충분 → 충분 | 조건 반복·길이 비용 |
| B3-018 | 오류① → 보완 | 미확인 모델의 조건부 절차 자체를 보여주는 문제 |
| BC-002 | 오류① → 보완 | 이번 기준선의 재기동 방지 누락은 연결했으나 누유 원인 분기는 부족 |
| Q-056 | 보완 → 충분 | 표현·길이 개선 여지 |
| Q-060 | 오류① → 보완 | 압력/유면 구분의 직접 답·원인 분기 부족 |
| S-18 | 보완 → 보완 | 가스켓 뒤집힘 등 기존 사실 오류 유지 |
| T6-14 | 오류① → 보완 | 미확인 모델의 조건부 절차 자체를 보여주는 문제 |

중대 오류는4→0, 충분은1→2로 예비 집계했다. **CV 두 문항의 절차 노출을 더 엄격하게 오류로 유지하면 중대 오류는4→2다.** 따라서 안전성을 입증했다거나 전체 모델 품질이 개선됐다고 결론 내리지 않는다. 적어도 감속기 두 문항의 누락 조건을 실제 작업과 연결하는 좁은 개선 후보로 해석한다.

나머지24문항은 최종 답 객체가 동일했다. 거절·인용·기존 숫자 검사 상태는62행 모두 불변이며 변경14행은 기존 `G.check` 재검사도 통과했다. 기존201문항 저장 결과에도 적용 범위·거절 불변성을 검사했으나 품질 채점/독립 검증으로 세지 않았다.

변경 답변은 중앙값255자 길어졌다. 이는 생성400토큰 상한 이후의 표시 문자열 증가다. 최초 R4는 공통 머리말이 길고 CV 출처에 없는 별도 승인까지 일괄 요구해 버렸으며, R5에서 이를 제거했다. 추론 시간이나 메모리 개선을 주장하지 않는다. 실제 PDA 표시·현장 작업 허용·Jetson 지연은 미검증이다.

## PR 적용 원칙

- 기본값 off. 명시적 `SHIFTLINK_S30H_SOURCE_CONDITIONS=1`만 실험 기능을 활성화한다.
- source kind, card ID, revision, chunk ID, 해당 조각의 조건 문구를 검사한다. 미인용·다른 종류·오래된 색인·다른 revision·거절에는 적용하지 않는다.
- 실제 조건 충족이나 작업 승인을 확인하지 않는다. 별도 안전 검증기를 대신하지 않는다. 기존 사실 오류와 잘못된 인용/검색은 그대로 남을 수 있다.
- 운영 배포·Jetson 접근·서비스 재시작은 하지 않았다. 채택 전에는 별도 승인 아래 실제 MES 응답과 PDA 표시를 소규모 확인해야 한다.
