ShiftLink 계획 공정에 따른 Unity 연결·동작 구현

근거 및 전문가 검토
  공장 생산설비 배치 전문가 역할의 서브 에이전트가 계획표와 기준정보를 검토했다.
  계획 범위: docs/planning/최종 통합본(고도화 v1.1)(codex).md:86
  공정 본체 추가 제외: docs/planning/03_결정질문.md:121,127
  공정 관계: docs/data/reference/00_plant_and_relations.json:839~1202
  실제 현장 도면이 아닌 합성 MES 공정에 맞춘 동작이다.

현재 구현
  제작한 EquipmentTypes/Connections FBX로 Resources/Factory Prefab을 생성한다.
  FactoryAssetBuilder.Prepare 또는 Editor 자동 준비로 생성 가능.
  RT-01/RT-02/RT-03은 12/16/12롤러. RT-02의 롤러·베어링 위치를 재배치한 변형이다.
  RT-02 승강 피벗은 분리되어 있으나 위치 이벤트가 없어 임의 승강 사이클을 돌리지 않는다.
  정상 경로 RT-01→RT-02→RT-03→CV-01을 이송 연결 롤러로 이어준다.
  Unity에서 Input/OutputAnchor 간 거리 4.8m와 상부 Y=1.22m를 검사했다.
  장비 중심 간격 5.4m, 연결 간격 0.6m는 시연용 치수 가정이다.
  CV-02는 옆으로 분기하며 RT-03의 별도 ScrapOutputAnchor를 사용한다.
  CV-01의 CAU 디버터와 RT-03 스크랩 분기는 동일 장치로 취급하지 않는다.
  GR 출력 축 실제 모델 접점에서 커플링·보호 커버·지지축·베어링·직각 분배부·체인 커버로 연결한다.
  직각 분배 기어와 체인 전달은 도면이 없어 가정 형상이다. 실제 기어비는 없다.
  HPU 압력/회수 배관, PDP 전력 케이블/트레이, CAU 공압 수직 배관을 해당 공급 대상에만 연결한다.
  CAU는 기준정보의 2층 위치를 플랫폼으로 표현한다. 높이 3.2m는 가정이다.

운동과 소재
  rt_speed/cv_speed의 good 품질 m_min 값만 사용, m/s=v/60으로 변환.
  롤러 반경 0.12m, 풀리 반경 0.175m를 이용해 omega=v/r로 회전한다.
  위 반경은 모델 가정이며 계산된 회전수는 실측 RPM이 아니다.
  GR·연결 축 회전은 종동 이송 장비 속도에 동기화하는 시연 표현이다.
  CV 벨트 표식은 같은 속도로 이동한다. 전체 벨트 메시를 공간 이동시키지 않는다.
  CV-02는 MES 스냅샷에 명시적인 good cv_speed가 있을 때만 회전한다. 없는 값은 임의로 만들지 않는다.
  MES coil_id를 유지한 객체가 equipment_id/position 목표로 연속 이동한다.
  스냅샷 사이의 이동은 보간 표시이며 물리 기반 코일 적재/운반 시뮬레이션이 아니다.
  경계 전환 시 Output/다음 Input 지점을 거치며, 스크랩 전환은 ScrapOutput 지점을 사용한다.
  감긴 코일은 V형 운반 받침 위에 둔다. 받침·코일 운반 가능성은 합성 시연용 가정이다.
  코일 자체 자유 굴림과 압연/권취/절단 공정은 구현하지 않는다.
  CV-02에서는 별도 절단재를 표시한다. 통코일이 절단되는 물리 동작을 뜻하지 않는다.
  rt_clamp_press/rt_lift_delay는 위치가 아니므로 승강/클램프 임의 반복 동작을 만들지 않는다.
  HPU/PDP/CAU는 공급 상태를 표시한다. 모든 설비가 기계적으로 이동하는 것은 아니다.
  가동+running line에서 회전·운반, 대기/심각 고장/일시정지/단절에서는 정지한다.
  단절 시 상태등 회색, 소재 숨김. 상태·인터록 판정은 MES가 담당한다.
  동일 run의 이전 sequence는 무시한다. run이 바뀌면 기존 소재를 제거한다.

검증
  FactoryMotionChecks.Run: 원시 도형에서 롤러 피벗 없음으로 RED 재현.
  Unity 6000.3.12f1에서 FBX 기반 구성·미터/위쪽/방향·12/16/12롤러·회전·객체 유지·
  소재 이동·대기/심각 고장/단절 정지·스크랩 절단재 검사.
  FactoryMotionLiveChecks.Run: 임시 MES/PDA HTTP 서비스와 실제 Unity Play Mode에서
  advancing sequence, 롤러 회전, 소재 이동, PDA 선택을 확인.
  검사 프로젝트/로그/이미지는 artifacts/unity-motion-test 아래이며 기존 장면 검사를 격리했다.
  코드 커버리지 비율은 측정하지 않았다. 물리적 간섭·하중·실제 공장 적합성은 검증 범위 밖이다.
  실제 Pi/Jetson 하드웨어 연결, 실측 배관 경로, 기계 전달 설계는 별도 검증이 필요하다.
