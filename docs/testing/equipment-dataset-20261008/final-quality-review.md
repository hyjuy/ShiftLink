# 최종 CNN 사진 품질 검토

검토일: 2026-10-08. 검토자는 요청에 따라 최종 큐레이션 manifest·summary·필터 코드와 실제 PNG 표본을 읽기 전용으로 확인했다. 이 문서 외 데이터셋·코드 수정, 사진 삭제, 업로드는 수행하지 않았다.

## 검토 범위와 한계

초기 최종 큐레이션은 후보 9,600장 중 8,944장 유지, 656장 제외였다. 유지 ID 8,944개와 제외 ID 656개는 각자 중복이 없으며 두 집합의 교집합은 0이었다. 모든 train/val/test에 HPU/PDP/CAU/GR/RT/CV 6클래스가 있고, 장비 10대 각각에 0~11의 12방향이 전체 split 합산 기준으로 남았다. 근접사진 2,853장, dim 사진 1,785장(train 1,431, val 177, test 177)이 유지되어 어두운 사진이나 근접사진을 일괄 제외한 것은 아니다. 일부 split의 일부 방향 표본은 없으므로 각 split 전체 방향 보장을 의미하지 않는다.

실제 PNG는 아래 13개 표본을 원본 해상도로 확인했다. low_contrast 단독 제외 8장 전부, 가장 어두운 유지 표본 1장, small_target 단독 제외의 클래스별 대표 4장이다. 이는 데이터셋 전체 육안 전수검사가 아니다. 모델 훈련, 정확도 측정, 실제 카메라 사진 평가를 수행하지 않았으며 성능 향상 수치를 주장할 근거는 없다. bbox 크기와 명암 표준편차는 휴리스틱이며 실제 식별 가능성과 일치하지 않을 수 있다.

## 삭제 스크립트 읽기 전용 검토

검토 대상: `.worktrees/equipment-handheld-cnn-20261008/scripts/retire_excluded_photos.py`.

PNG 삭제 후보는 제외 capture_id 일치, SHA256 일치, 링크 우회 거부(`resolve() == absolute()`), root 내부 경로 확인을 거친다. 모든 발견 PNG 검증이 끝난 뒤 첫 unlink가 실행되어 한 복사본의 해시 불일치로 검증 단계에서 중단할 수 있다. 제외 ID 중복과 발견되지 않은 제외 ID도 검사한다.

읽은 버전에는 manifest·summary 수정 경로의 링크/내부경로 검사가 없고 JSON parsing은 PNG 삭제 이후 수행된다. 실행 전 해당 쓰기 대상의 `resolve() == absolute()` 및 root 내부 여부, manifest·summary JSON 파싱 가능 여부와 summary가 필요한 cnn manifest 존재 여부를 모두 사전 확인해야 한다. 그렇지 않으면 삭제 후 파싱 오류로 중단하거나 링크 경유 외부 파일을 수정할 수 있다. 보호 검증이 assert 기반이므로 `python -O` 및 `PYTHONOPTIMIZE` 설정을 사용하면 안 된다. 이 검토에서는 삭제 스크립트를 실행하지 않았다.
