## 새 평가 실행

원본과 새 후보를 같은68조건·모델별30,464프레임·64개 이상 사건으로 비교한다. 직전 미배포 episode 후보도 같은 고정 입력으로 별도 설명용 비교를 수행한다. 추가 대조군을 위해 사전 통과 기준을 바꾸거나 후보를 선택하지 않는다. 공통 시뮬레이터 안의 새로운 정상 궤적/고장 개입 평가이며 현장 일반화와 다르다. 평가의 단일 고장 강도는1·3이며 가장 약한0은 포함하지 않는다. 간헐형 최초 증상은32프레임, 이후 출현18~32·휴지4~20프레임 범위다. 수리 후 같은 센서 재고장은64프레임 정상 간격을 검사했고 더 짧은 같은 센서 재발을 모두 구분한다는 보장은 없다.
## 보존 확인과 남은 운영 검증

Pi 최종 검증에서 운영 코드·설정 pin22개 모두 이전 해시와 일치했고 기존 분석 worker는 PID7066·active/running·NRestarts0을 유지했다. 마지막 운영 상태는 running·기존 경보0·AI ready였다. 마지막 온도46.7°C·throttled=0x0, 검사 중 기록된 온도 최대55.0°C다. 이는 간헐적으로 기록한 샘플이며 연속 열/얼굴/CNN 부하 시험의 최댓값으로 해석하지 않는다. 기존 두 평가의 archive·계획·생성기 및 이전/신규 전체 사례 해시도 확인했다. 새 시험 manifest의 seal과 생성 이후 mtime이 유지됐고, 모든 검증 자식 프로세스가 종료됐음을 확인했다.

운영 r5·기존 경보·PDA 파일/서비스·모델/profile/settings는 교체하지 않았다. 이번 후보는 별도 Git branch codex/pi-fault-lifecycle-candidate 및 Pi validation 경로에만 있다. 운영 factory 선택도 그대로다. 실제 사용자 알림·확인·재진동 조작을 하지 않았다. 가장 약한 고장 강도0, 초기64프레임 예열 중 고장,20프레임보다 긴 간헐 휴지, 짧은 같은 센서 수리/재발, 다른 설비/공장/실측 센서의 성능은 이번 통과로 입증하지 않았다. 이후 운영 연결에는 장기 활성 표시와 수리/회복 정책 검증이 필요하다.
