# 지식카드 생성 배치 분석

2026-09-24 · Codex sub-agent card_analyst(AI). 분석 대상은 이 폴더의 생성·근거·독립 검토·검증 산출물이며 신규 원문 조사나 사람의 승인은 수행하지 않았다.

이번 배치는 **역사적 문헌의 명시지 요약 카드 3건**을 만들고 독립 검토까지 마쳤다. 3건 모두 `content_decision=pass`, `operational_gate=hold`다. 원문에서 확인 가능한 주장과 제작자가 부여한 분류를 분리해 추적하는 작업은 충족했다. 현장 숙련자의 암묵지 확보, 안전한 현장 적용, 운영 KB 확충 완료 또는 RAG 성능향상을 입증한 결과는 아니다.

## 생성과 독립 검토에서 얻은 것

원문 선별 → 카드 작성 → 별도 에이전트 검토 과정에서 P-02/P-03 발췌를 전체 조항으로 보강했다. 그 결과 비상·사고 정지라는 전제와 사업주 안전조치라는 예외가 카드에 함께 남았다. 독립 검토자는 K-0302의 일본어 `generalization_scope`를 발견했고, 작성자가 한국어로 수정한 최종본을 재검사했다. SKF P-04는 초기 T2 후보였으나 특정 설계개선 사례의 적용 범위만으로 조건별 재사용 요령을 입증하지 못해 보류했다. 유형 수를 채우기 위한 강제 분류를 막은 결정이다.

카드에는 원문에 없는 진단 단계·수치·재기동 승인·성공 결과를 추가하지 않았다. 특히 K-0302는 재기동 전 확인 요구만 담고 실행 가능한 복구 절차를 갖추지는 못했다. K-0303은 금지와 예외를 한 카드에 보존했으나 예외를 판단할 현장 기준은 확보하지 못했다. `conditions/exclusions`의 빈 배열은 적용 조건이 전혀 없다는 뜻이 아니다. 해당 문맥은 본문에 남아 있으므로 향후 구조화 검색에서 조건을 누락하지 않는지도 확인해야 한다.

프로젝트의 원문 추적·유형 분류·안전 검토 분리 요구에는 검토용 예시를 제공한다. 반면 `event_ids`, 일반화 지지/반박 사건, 실패시도 및 인계 방법은 비어 있어 현장 경험에서 도출한 판단 근거, 예외, 시행착오를 검증할 수 없다. `tacit_type`을 부여했다고 명시지가 암묵지로 바뀌지는 않는다. 프로젝트 Qwen/Ollama 및 공식 생성 파이프라인을 실행하지 않았으므로 이번 결과로 해당 모델의 생성 품질이나 지연시간도 평가할 수 없다.

## 편중·순환생성·계보의 한계

3건은 같은 2012년 문서의 안전 금기·재기동 확인에 집중된다. 문헌 충실성이 같더라도 다른 설비, 운전조건, 실제 사고·복구 결과로 일반화할 근거가 없다. SKF는 유형 근거 부족, NSK는 GR/RT 설비 대응 부족으로 각각 dev 상태에서 카드화를 보류했다. KOSHA 정비 조항 §4.3(9)은 기존 카드와 상당 중복하여 제외했다. 유압 계보는 sealed 메타데이터만 확인하고 원문 열람·생성에서 제외했다. 이를 모두 같은 이유의 탈락으로 집계하면 다음 수집 과제를 잘못 정하게 된다.

기존 카드는 중복 대조에만 사용하고 생성 근거로 재활용하지 않았다. 원문 해시와 조항, 근거 지도가 있어 이번 배치 내부의 순환생성 위험을 줄였다. 그러나 원문→번역·발췌→과거 카드의 전체 계보와 전역 의미 중복은 확인되지 않았다. ID 충돌 검사도 공유 KB와 20260923 배치 범위에 한정된다. 같은 원문에서 파생된 3건은 하나의 그룹으로 다뤄야 하며 개별 카드를 서로 다른 평가 분할로 나누어 독립 표본처럼 쓰면 안 된다. `split=kb`는 bucket 4의 **미등록 배정 제안**이지 운영 적재 승인이 아니다.

## 다음 원문 보완과 운영 반영 조건

1. **현재 3건의 적용성부터 확인:** SD-005 판본·이용 범위의 출처 승인, 최신 적용 문서와 현장 절차 대조, 정지스위치 접근 관리·재기동 권한과 확인 항목·올라가기 예외 판단 기준을 담당자에게 확인한다. 이 분석은 현행 법령이나 현장 안전성을 판정하지 않는다.
2. **실제 사건 원문 확보:** 우선 CV의 비상정지·복구 기록에서 관측 사실, 원인 판단 근거, 시도와 실패, 인계 내용, 결과 및 반례를 확보한다. 문헌 카드와 별도 사건 계보로 연결해야 암묵지 일반화 가능성을 평가할 수 있다.
3. **설비·유형 범위 확장:** SKF에는 조건별 설계 선택을 뒷받침할 원문, NSK에는 실제 설비·부품 대응 자료를 보완한다. 기존 dev 그룹을 유지하며 자료가 지지하는 유형만 판정한다. 중복 정비 조항은 신규 카드 수를 늘리기보다 기존 카드와 통합·근거 보강 여부를 검토한다.

운영 반영 전에는 출처 승인 범위와 이용권한, 그룹 배정표 등록 및 전체 계보·중복 점검, 사람의 내용·안전 검토와 현장 적합성 확인이 남아 있다. `confidence=0.0`은 미평가 sentinel이므로 신뢰 확률로 소비하기 전에 평가·필드 정책을 정해야 한다. 이후 공식 파이프라인과 런타임 검사를 거치고, 계보가 분리된 평가 자료로 검색·응답 품질을 측정해야 성능 영향을 말할 수 있다. 그때까지 draft/L0와 운영 hold를 유지한다.

분석 시점에 cards.json, source-packet.json, evidence-map.json의 SHA-256을 직접 계산했으며 review.json 및 validation.json의 기록과 모두 일치했다. 검증 결과의 형식 통과는 의미 정확성이나 사람 승인을 대신하지 않는다. 수치와 해시는 analysis.json에 기록했다.
