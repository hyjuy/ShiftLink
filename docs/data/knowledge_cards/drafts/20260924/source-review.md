# 원문 선별·근거 편집 검토

2026-09-24. source_editor 서브에이전트(AI)가 원문을 확인했다. 사람의 승인이나 전문 검수를 대신하지 않는다. 구체 모델 버전은 확인할 수 없어 기록하지 않았다.

## 생성 담당에게 전달

`source-packet.json`의 P-01~P-03은 SD-005의 2012년 지침을 문헌 요약한 CV 카드 후보다. 정지스위치 주변 장애물 금지(T5), 비상/사고 정지 후 재기동 전 원인·보수상황 확인(T6), 컨베이어 올라가기 금지와 원문 예외(T5)는 독립 목적이다. 원문 범위를 넘어 현행 법적 요구나 충분한 재가동 승인 절차라고 쓰지 않는다. §4.3(11)의 사업주 안전조치 예외는 보존하되, 예외를 충족하는 구체 조치를 창작하지 않는다.

P-04는 SKF의 특정 축 베어링 배치 부적합이 확인된 감속기 사례에 한정한 T2 설계대안 후보다. 조건부 참고 지식으로 쓸 수 있는지 유형 검토가 필요하다. 단순 고장만으로 그 조건이 확인된 것으로 취급하지 않는다. 원문에 없는 진단 순서나 재가동 절차로 만들지 않는다. 다른 설비에 대한 교체 지시나 효과 보장을 금지한다.

## 원문 확인과 분할

PDF 스킬을 읽고 기존 `.test-deps`의 PyMuPDF로 텍스트를 추출했다. KOSHA PDF의 관련 전체 페이지 7·8(인쇄 5·6), NSK/SKF 각각 전체 1·2쪽을 PNG로 렌더링하고 육안으로 대조했다. KOSHA는 전체 텍스트를 확인했으나 시각 검토 범위는 해당 2쪽이다. 추출문에서 페이지 번호와 문단 경계를 확인했다.

원문 제목·문서번호로 그룹 ID를 확정한 뒤 SHA-256 big-endian 정수 mod 12 규칙을 적용했다. KOSHA `SRC-KOSHA-M101-2012-CONVEYOR-SAFETY`는 4/kb, SKF `SRC-SKF-10404-EN-DRIVELINE-FOR-METALS`와 NSK `SRC-NSK-COLD-ROLLING-MILL-STEELSTRIP`는 각각 7/dev다. 해시 결과 후 ID 변경은 없다. 이 값은 미등록 제안이며 확정 배정표는 변경하지 않았다. SKF/NSK의 dev는 생성금지가 아니므로 원문 검토했으며 파생 카드도 dev를 유지한다.

기존 유압 계보 `SRC-VICKERS-LOGICAL-TROUBLESHOOTING-OBSERVATION-GAP`의 10/sealed 메타데이터를 이전 보고서에서 확인하고 이번 원문은 읽지 않았다. 평가용 정답·봉인 사건을 생성에 사용하지 않았다.

## 설비와 시나리오

CV는 원문의 conveyor와 합성 기준정보 ET-0004의 의미 대응이다. SKF gearbox는 ET-0002 GR/CP-0008 감속 기어박스와 의미 대응하지만 실제 제품이나 공정 일치를 뜻하지 않는다. 부품명은 원문 용어를 사용하며 특정 equipment_id는 배정하지 않는다. NSK의 4열 원추롤러베어링을 프로젝트 GR/RT에 대응할 근거는 없어 보류했다.

S1=신입, S2=저년차는 `docs/design/A_domain.md` A4.2에서 확인한 제작 메타데이터다. 원문이 대상자를 그 시나리오로 지정한 것은 아니다.

## 중복·보류와 미확정 사항

기존 공유 카드 K-0108~K-0110은 생성 재료가 아닌 중복 대조용으로만 읽었다. KOSHA §4.3(9)의 위험 정비 시 정지/작동방지는 K-0108과 상당 부분 겹쳐 보류했다. §4.3(11) 올라가기 금지는 가까운 안전 주제이지만 독립 행위와 예외를 다뤄 후보로 남겼다. 기존 보고서의 K-0201/0202는 Xu-Zhang와 합성 인계 계보로 SKF 설계대안과 구분했다. 전역 의미 누출 없음은 주장하지 않는다.

출처 등록부의 SD-005는 pending_review이고 approved_scope는 비어 있다. 이를 변경하지 않았다. SKF/NSK의 LOCAL 식별자는 이번 패킷 문서 식별자일 뿐 등록부 승인 ID가 아니다. 생성은 운영 파이프라인의 승인된 출처 생성과 구별되는 검토용 draft/L0 후보로 제한한다. 전문 이용권한, 현장 적용성, 출처 승인, 인간 안전 검토, 전역 의미 계보 검토는 남아 있다.

## 근거 보강 이력

2026-09-24 생성 담당의 요청으로 P-02/P-03 발췌를 각각 §4.3(7), §4.3(11)의 전체 조항으로 보강했다. 비상/사고 정지라는 전제와 사업주의 안전조치라는 예외를 발췌 자체에서 확인할 수 있게 했다. 앞서 확인한 PDF p.7·8과 재대조하며 띄어쓰기·줄바꿈만 읽기 편하게 정리했다. 원문 파일과 SHA256 및 그룹/분할은 변경하지 않았다. P-04는 생성 담당이 조건에 따라 달라지는 요령을 입증하지 못하는 단일 설계개선 사례로 보아 T2 생성 보류를 제안했으며, 최종 결정은 별도 독립 검토에 따른다.
