## 1. 준비 상태 (10/23 확인)

| 항목 | 상태 |

| 로컬 MES `127.0.0.1:8000` | 실행 중 (`pda.html` 200) |
| Jetson `jetson-06.tail0a6af3.ts.net:8000` | HTTP 200 |

| Unity 빌드 `output/ShiftLink.exe` | 실행 확인(창 제목 `ShiftLinkFactory`). 새 치비 남성 캐릭터 포함, 두 PC 멀티플레이 변경은 미포함 |

## 2. 3인칭 Unity 컷 (추가 제안)

스토리보드는 Unity를 설비 스캔 컷(시트3·2)에서 1인칭 시점으로만 쓴다. 새 캐릭터는 1인칭에선 보이지 않고 촬영 이미지에서도 제외된다. 그래서 **3인칭 컷을 4개 추가**하는 것을 권장한다. 모두 GEN 컷의 대체가 아니라 보강이다.

| 추가 컷 | 넣을 자리 | 내용 | 길이 |
|---|---|---|---|
| U1 | 시트2·4 → 5 사이 또는 시트2 도입 | 공장 외부 보기(`공장 외부 보기` 버튼)로 시연 공장 전경. "시연은 Unity 가상 공장" 설명 | 4초 |
| U2 | 시트3·1 | `V`로 3인칭. 작업자 캐릭터가 HPU 앞으로 걸어가 PDA를 든다 (`F`→이동, `P`→PDA) | 5초 |
| U3 | 시트3·2 직전 | 같은 장면에서 1인칭 전환(`V`) → 매치 컷으로 PDA 스캔 화면 | 2초 |
| U4 | 시트4·5 또는 시트5·1 | 3인칭으로 필터 교체 장면 대신 라인 가동·코일 이송 (`시작`) | 5초 |

운영 규칙: 캐릭터는 **남성만** 연결돼 있다(여성은 Blender 원본만). 신입 역이 남성이므로 맞다. 조장(여성)은 Unity에 쓰지 않는다. 화면 구석에 "Unity 가상 공장" 표기.

## 3. 촬영 순서

이야기 순서대로 이어서 찍어야 화면 상태가 이어진다(R2의 인계 사항이 R7의 근무일지로, R7의 후보가 R8·R9로).

1. **서버 상태 확정** — MES를 HPU-01 압력 저하 상태로 둔다(같은 상태를 R3~R6 전부에 유지).
2. **REC 녹화 R1 → R9** (4절).
3. **Unity 컷 U1~U4 + R3의 가상 카메라 영상**.
4. **MG 컷 제작**.
5. **GEN·CAM 컷 확보**(병행 가능).
6. **조립**: 컷 순서대로 이어 붙이고 자막·표기·콜아웃 합성.
7. **내레이션 얹기, 색·소리 통일, 검수**.

녹화 설정: 키오스크 해상도 그대로 1080p 이상, 커서 숨김·터치 표시, 알림 끔. 실제 응답 시간을 그대로 녹화하고 줄이는 건 편집에서 배속(표기). 컷 앞뒤 2초 여유.

주의: **Jetson·파이를 상대로 하는 질의는 기록을 남긴다.** 녹화 전 예행은 로컬 MES에서 하고, 본 녹화만 Jetson에서 한다. 파이·Jetson 설정 변경은 사람이 요청할 때만 한다.

## 5. 합성·편집 규칙

- 실제 화면은 다시 그리거나 글자를 고치지 않는다. 콜아웃은 원·밑줄·번호만.
- 대기 시간을 숨기지 않는다. 배속은 구석에 "2배속 · 실제 약 10초". "N초 경과" 표시는 자르지 않는다.
- 구석 표기 "모의 시연 · 합성 MES" 상시. 설비 스캔 컷에 "시연은 Unity 가상 공장". 크레딧에 "일부 장면 AI 생성".
- 초록 화면 합성은 3컷(시트1·8, 시트2·7, 시트4·9)만, 카메라 고정이므로 모서리 4점 한 번 배치.
- 색: 시트1은 차갑게, 시트2부터 조금 밝게. 포인트색은 PDA 앱 청록 하나.
- 자막: 왼쪽 아래 카드 하나, 폰트 하나. "STEP N · 단계명"은 매 장 첫 컷에만.
- 소리: GEN은 현장음, REC는 터치음을 작게 + 내레이션. 음악은 시트1 낮은 피아노 → 문제 구간 현장음만 → 로고부터 가벼운 신스 패드.
- 수치는 시트5의 세 카드를 포함해 발표 자료와 대조한 뒤 확정한다.

## 6. GEN 컷 제작 요령 (사람)

1. 시트별 이미지 프롬프트로 스토리보드 시트를 만들고, 컷 이미지를 잘라 **시작 프레임**으로 쓴다.
2. 영상 프롬프트로 컷마다 따로 생성(한 번에 5~10초). 컷 이미지를 시작 프레임으로 넣는다.
3. 얼굴이 달라지면 이름표·수첩·안전모 색 같은 고유 소품을 강조해 재생성.
4. 생성 영상 속 글자는 영어만(한글 깨짐). 한국어는 편집에서.
5. 시트1·8·시트2·7·시트4·9는 **"camera locked off, screen is a plain solid green"** 로 생성.
6. 완성 클립은 `docs/demo/video/clips/` 아래 `시트-컷번호_소스.mp4`(예: `s1-04_GEN.mp4`)로 넣으면 Claude가 조립한다.

**막힌 것**
- **Jetson 쓰기 거부**: 인계 기록 저장 요청이 자동 승인 검사에서 거부되어 Jetson·파이에는 쓰지 않았다. REC는 노트북의 녹화용 MES 복사본(:8011, hydraulic_fault)과 노트북 PDA(:8081)로 녹화했다. R5·R6은 질문이 Jetson 질의 기록·업로드에 남으므로 사용자 허락이 있어야 한다. 로컬에는 판정·답변 모델이 없다.
- **R7 후보 0건**: 질문 없이 쓴 일지는 후보가 생기지 않는다. R6(해당 지식 없음) 직후 같은 화면에서 써야 후보 1건이 생긴다.
- **내레이션**: 임시 합성 음성(Windows 한국어)이다. 최종은 녹음 또는 자막만으로 정한다. s2-2, s5-3은 내레이션이 컷보다 길다(문구 축약 필요).
- REC 화면은 1280x800으로 녹화돼 1080p로 확대된다. 해상도가 필요하면 키오스크 해상도에 맞춰 다시 녹화한다.

**다시 만드는 법**: `tools/build_rough_cut.py`(조립), `tools/mg_scenes.py`(MG), `tools/rec_r2_r4.py`(R2~R4), `tools/rec_r7.py`(R7), `tools/unity_keys.ps1`(Unity 조작). 서버 준비: `python -m shiftlink.mes --port 8011 --db output/video/rec/db/mock-mes.sqlite3`, `python -m shiftlink.pda --no-window --port 8081 --jetson http://127.0.0.1:8011 --unity http://127.0.0.1:8090 --cnn output/video/rec/cnn`.
