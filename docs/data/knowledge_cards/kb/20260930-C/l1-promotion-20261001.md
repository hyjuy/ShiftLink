# C 카드 L1 승격 기록

2026-10-01 사용자 요청: “human-review-checklist-20260930에 맞춰서 l1으로 승격”.

[지정 검수표](../human-review-checklist-20260930.md)의 C 카드 K-1201~K-1219 모두 `accepted` 판정이므로, 19장을 `draft/L0`에서 `accepted/L1`로 변경했다. 원본 카드와 out JSON을 동기화하고 통합 KB에 편입했다. 통합 카드 수는 62장에서 81장으로 변경된다. 검수자의 이름·판정 근거는 검수표에 있는 기록을 그대로 보존한다. 비어 있거나 `-`인 근거를 새 검토 기록으로 채우지 않는다.

승격 범위는 프로젝트 KB 편입이다. K-1201의 기존 수치 표현 승인 범위도 보존하며, 이번 사용자 요청을 별도의 편입 근거로 기록한다. 제조사 모델 적용성·현장 작업 안전 승인·실제 경험 검증을 추가로 확정하지 않는다. confidence=0.0은 미평가 값으로 유지한다.

출처 approved_scope, 합성 사건 계보 배정 및 T6 독립 반복 근거의 미충족 항목은 [카드별 승격 데이터](l1-promotion-20261001.json)에 남겼다. 원래 정책 검사와 `verify.py --kb-ready`는 이 보류 상태를 계속 보고한다. 배치 병합·검증에서는 이번 요청에 고정한 카드 본문과 해당 C 카드의 검수 구간 해시가 일치할 때만 기록된 편입 예외를 인정한다. 새 정책 문제나 이후 본문 변경은 자동 승인하지 않는다. 다른 배치의 검수 내용 변경은 C 승격에 영향을 주지 않는다. 최초 검수표 전체 파일 해시는 감사 기록으로 보존한다.

검증: C 병합·배치 검증 통과, C 양식·판정·통합·승격 예외 회귀 검사 9개 통과. 라우팅은 dev 20/30, T4 7/20, sanity 29/30으로 승격 전과 같다. 전체 회귀 검사에서는 별도로 작업 중인 MES 추가 신호와 기존 A 신호 매핑의 불일치로 2개가 실패했다. `verify.py --kb-ready`는 기존 정책 보류 19장을 보고하며 종료 코드 1을 유지한다.
