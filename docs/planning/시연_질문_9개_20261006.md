- 기대 카드 ID는 각각 하나씩 존재하며 모두 `accepted / L1 / kb`이다. HPU·GR·CV 각 3개다.

- 원인 관련 답은 확정 진단이 아니라 의심 대상과 확인 방법이다. 카드의 현장 제조사·모델 적용성은 미확인으로 남아 있다.
- 실제 시연 검색에서 기대 카드가 반환되는지, 생성 답변이 올바른 분기를 유지하는지는 추가 검증이 필요하다.
