## 기존 H2와 PDA 확인

- `20260930-C/policy_gate.py`에 기존 H2 보강이 반영돼 있다. T6 예외는 명시적 승인·승인자·요청·날짜·사유·근거·검토 카드 SHA가 일치해야 인정한다.
- 비합성 사건은 승인된 case scope·문서 버전·해당 카드 연결·group_id를 확인하고 사건 그룹으로 중복 제거한다. 승인 없거나 내용이 바뀐 예외, scope 누락, 다른 카드 및 같은 사건 출처 중복 등의 회귀 검사가 통과했다.
- 실제 C 배치에 게이트를 실행한 결과 `kb_ready=true`, `blocked_cards=0`, `reasons={}`였다. 이번 작업에서 정책 기준이나 승인 기록은 변경하지 않았다.
- PDA `renderResult`는 안전 스택을 답변 앞에 붙이며 `safetyEl`과 `actionEl`은 카드 ID를 표시한다. 실제 브라우저 연결이 없어 화면 자동 확인은 수행하지 않았다.

## G2 실제 질의

2026-10-07 10:30 KST에 기존 Jetson `http://jetson-06:8000`의 `/api/kb/cards`에서 K-1001 제목을 읽고 아래 질의를 `/api/query`로 전송했다. 로컬 결정적 모델을 사용하거나 운영 MES에 제어 명령·시나리오·인식 결과를 주입하지 않았다. 수동 설비 선택 경로이므로 물리 카메라나 G1 검증은 아니다.

```json
{"question":"기어·베인 펌프 출구 압력이 없을 때 확인 순서 — Algo A.1 좌측 분기","equipment_id":"EQ-0001"}
```

- HTTP 200, 지연 `4.629651199999898`초. 단일 질의 시간이며 p95가 아니다.
- 근거 카드: `K-1001`.
- 안전 카드: `K-1003`, `K-1006`, `K-1211`, `K-1218`.
- `review_queue=false`, `no_knowledge=false`.
- 실제 응답을 로컬의 생산 `render_response`로 렌더한 로그의 순서는 `안전 공지 → 답변 → 조치 단계 → 재가동 실패 이력 → 참고 카드: K-1001`이다. 모든 안전 ID와 인용 ID가 로그에 있음을 assertion으로 확인했다.
- [실제 응답 요약](assets/h1-g2-20261007.json), [안전 우선 렌더 로그](assets/h1-g2-20261007.log). 원본 전체 HTTP 응답은 Git 제외 `artifacts/h1-g2-20261007/jetson-response.json`에 보관했다.

**G2의 화면 또는 로그 기준은 로그 경로로 PASS.** 보강한 질의 저장 코드는 로컬 회귀 검사로 확인했으며 기존 Jetson에 배포하지 않았다. Jetson 서버가 새 로그 필드를 이미 저장한다거나 물리 PDA 화면을 확인했다는 주장은 하지 않는다.
