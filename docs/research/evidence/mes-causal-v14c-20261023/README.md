# v14c 고정 평가 요약 사본

이 폴더는 `output/mes-causal-v14c-20261023`의 설정과 최종 요약을 다시 계산하지 않고 복사한 검토 자료다. `provenance.json`은 복사 원본의 SHA256·크기 및 로컬 candidate-lock SHA256을 기록한다. 파일 안의 `v14` 결과 키는 최종 v14c 설정으로 실행한 결과다.

- 설정: `settings.json` (기존 정상 통계·채널 순서·보조 온도 한계).
- 새 미사용 평가: `evaluation/result.json`, `evaluation/event-delays.json`.
- 기존 통지 행 비교: `post-evaluation-comparison.json`.
- 이미 소비한 냉각 사례 재생: `known-cases.json`. 새 평가와 분리한다.
- 최종 로컬 무결성 감사: `final-audit.json`.

합성 입력 전체·고장 정답 장부·절대 경로 기반 lock·준비 캐시·모델 가중치·기기 재생 ZIP은 이 PR에 포함하지 않는다. 따라서 이 사본만으로 803개 파일의 고정을 재감사하거나 전체 42건 평가를 재실행할 수는 없다. 전체 재실행에는 보존된 로컬 output 및 이전 단계 산출물이 필요하다. 새 체크아웃에서는 회귀 테스트로 코드 경계를 검증한다. 이 PR 과정에서 미사용 평가를 다시 생성하거나 후보를 조정하지 않았다.

지연은 탐지 성공 사건의 합성 개입 시작 기준이며 실제 추론·전송·화면 지연이 아니다. 정상 13440초에서 오통지 0건은 현장 오통지율 0을 뜻하지 않는다. 비매칭 11건은 개별 원인이 이번에 재판정되지 않았다. 고장 종류별 탐지율은 장부 기준이며 원인 분류 정확도가 아니다.
