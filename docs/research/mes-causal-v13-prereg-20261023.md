# v13 파급 관측과 열 잔류 재통지 — 새 시험 전 명세

v12c와 이전 소스·모델·결과·기존 개발 시도를 SHA로 보존한다. 별도 v13 소스/출력만 쓰며 Pi·운영 MES/PDA·실사용자 경보는 변경하지 않는다. 현재 v12c test는 소비된 진단 자료이며 새로운 최종 평가에 합치지 않는다.

## 13건의 실제 재현

원본 v12c의 비매칭13건은 유압 누설 중 EQ-0006/0007/0008의12건과 B seed1202106 EQ-0005의283초1건이다. 동일 시드의 고장/무고장 동역학을 다시 실행하고 기록된 원 센서값과 정확히 일치하는지 확인했다. 파급12건은 rt_clamp_press만 통지 점수를 넘었고, 무고장 대비 압력 상태 차이는 -0.73~-1.44, 원 클램프 압력 차이는 약-1.90~-3.73이었다. EQ-0005는 냉각 개입[111,166) 뒤283초에도 열 상태 차이+0.4384, 베어링/표면 온도 차이+1.82376/+1.13985가 남았다.124초 통지 뒤283초 재통지다.

정답 장부는 주입 구간/원인 장비만 채점하므로 파급·잔류를 비매칭으로 센다. 이를 오통지13건으로 단정하거나13건 모두 없애는 것을 목표로 하지 않는다. 진단에만 생성기의 숨은 상태/반사실 비교를 쓰고 검출기와 통지기는 장부·고장 종류·실제 파급 상태를 입력받지 않는다.

## 최소 변경

1. 입력63채널·v12c의 중심/척도/한계·median5·EWMA.4·공정 지속4·고착16·불량/반복 게이트를 고정한다. Timestral 재도입·신경망 재학습·한계 재선택은 하지 않는다.
2. 온도 근거로 시작된 에피소드의 회복은 기존 한계의2/3 이하에서 유효5샘플을 확인한다. 기존 한계1.5의 경우 회복1.0이다.1.0~1.5의 열 잔류를 정상 회복으로 세지 않는다. 비온도 근거와 새 고착에 대해 기존 통지기가 보낸 첫 통지는 보존해 열 잔류가 독립 근거를 가리지 않게 한다. 삭제된 온도 통지도 continuation 근거로 별도 저장한다. 고정 시간 쿨다운을 사용하지 않는다.
3. 기준정보의 hydraulic_supply 관계만 snapshot한다. 하류 rt_clamp_press 감소와 현재 상류 압력 저하·앞선 상류 통지가 함께 보일 때 ‘관련 압력 관측/상류 후보’를 기록한다. 인과 확정=False, 통지 보존=True다. 하류 전류·진동·고착 등 다른 근거도 함께 공개한다. 관계만으로 알람을 삭제하거나 원인 장비를 확정하지 않는다. 관계가 없거나 상류 선행/방향 증거가 없으면 부가 해석하지 않는다.

이 hysteresis는 정상 복귀를 더 엄격하게 정한다. 회복 밴드에 들어오지 않은 같은 장비의 순수 온도 재상승은 계속된 에피소드로 본다. 독립 열원 재발과 열 잔류를 온도만으로 항상 구분할 수는 없으며 이 한계를 숨기지 않는다. 실제 회복 뒤 가까운 새 열 이상, 잔류 중 독립 전류 이상·고착·bad/hold/reset을 회귀로 검사한다.

## 개발과 새 시험

새 development seed1301000/1301100, 아직 생성하지 않은 test seed1302000/1302100을 쓴다. 두 역할 모두 A/B 각7그룹·1024초·26실행이다. 기존 core36건을 유지하고 각 가족의 index5에 누설과 동시인 EQ-0006 마찰(누설 시작+8초,40초)을 추가한다. index6에는 열 잔류 중 별도 EQ-0006 진동 센서 고착[270,330)과 충분한 시간 뒤 EQ-0005 냉각 재발[650,698)을 추가한다. 총42건=core36+보호 확인6이다. 양 후보는 같은 입력을 받는다. 정상/control14실행의 노출은13440 합성 초다.

기존 고장 세기.5~2.5·고착48~64초·공통 hold·자연 bad를 유지한다. 새 동시 마찰 세기는.7~2.5, 새 진동 고착60초, 냉각 재발48초다. 모든 고착의 시작+25초 bad는 paired control에도 적용한다. 생성기는 기존 A/B 동역학을 수정하지 않으며, 격리된 localhost HTTP에서 연결만 재사용한다. 운영 서버는 건드리지 않는다. HTTP 최초 프레임을 직접 Session 재현값과 대조한다.

개발에서 미탐/배경 제외 탐지 악화 없음·중복0·정상 오통지 증가 없음·p95 및 개별 첫 통지 악화 없음을 확인한다. 이미 소비된 v12c 재생은 기준 전체 통지 행 일치,36건 첫 통지 유지·관련12건 보존·열 재통지1건 continuation 전환을 확인한다. 실패하면 고정하지 않는다. 개발 뒤 소스·설정·개발·명세·테스트를 잠근 뒤에만 새 시험을 처음 생성한다. 예측·관련 근거를 저장한 다음 장부를 읽어 동일한 기존 채점으로 비교한다. 시험 결과에 따라 재조정하지 않는다.

원래 비매칭 지표의 정의를 바꾸거나 장부 구간을 늘려 수치를 좋아 보이게 하지 않는다. 전체/종류별/추가 보호 사건 탐지, 정상 노출과 통지율, 중복, p95,10초 내, 개별 첫 통지 차이, 비매칭, 관련 관측, continuation을 모두 공개한다. 새42건에서 파급 수가12건이어야 한다고 강제하지 않는다. 생성기 기반 반사실 분석은 별도 진단이며 모델의 현장 인과 추론 능력을 뜻하지 않는다.

기존 A/B·작성 가정·고장 계열을 공유하므로 시드 분리는 실행 누수 방지다. 실측·다른 설비/현장 일반화·Pi·실제 추론/대기/통신/PDA 표시를 포함한 지연은 미검증으로 남긴다.

동시 주입 사건의 구간 내 통지 매칭은 어떤 개입 때문에 통지가 발생했는지까지 증명하지 않는다. 추가6건은 기존 통지 보존의 보호 시험이며 독립 원인 분리 정확도를 주장하지 않는다. 새 시험 뒤의 비매칭도 별도 동일 시드 반사실 재현으로 조사하되, 이것으로 채점 장부를 확장하거나 후보를 조정하지 않는다. 관측 차이가 작거나 혼합된 경우 미확인으로 남긴다.
