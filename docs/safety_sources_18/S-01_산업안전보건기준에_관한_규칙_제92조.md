# S-01 — 산업안전보건기준에 관한 규칙 제92조

원문 확인일: 2026-09-17  
원문 상태: 국가법령정보센터 현행 조문 확인  
공식 원문: [국가법령정보센터 — 제92조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0092&lsiSeq=273603&urlMode=lsScJoRltInfoR)

## 확인한 조문 범위

`산업안전보건기준에 관한 규칙`은 검색 시점에 2025-09-01 시행본으로 표시됐다. 제92조 제목은 “정비 등의 작업 시의 운전정지 등”이다.

| 항 | 확인 내용 요약 | L1 카드에 연결 가능한 상황 |
| --- | --- | --- |
| 제1항 | 동력 기계의 정비·청소·급유·검사·수리·교체·조정 등에서 근로자 위험 우려가 있으면 운전을 정지해야 한다. 구조상 위험 우려가 없는 경우의 단서가 있다. | CV·RT·GR·HPU의 정비, 점검, 걸림 제거 전 정지 여부 |
| 제2항 | 정지 후 타인의 운전을 방지하도록 기동장치 잠금과 열쇠 별도 관리 또는 표지판 등 방호조치가 필요하다. | 무단·오조작 기동 방지, 잠금/표지 상태 확인 |
| 제3항 | 부적절한 작업방법 때문에 기계가 갑자기 가동될 우려가 있으면 작업지휘자 배치 등 필요한 조치가 필요하다. | 여러 작업자 또는 작업 순서가 얽힌 정비·청소 작업 |
| 제4항 | 설비 내부의 압축 기체·액체 방출로 위험 우려가 있으면 앞 항의 조치 외에 미리 방출하는 등 필요한 위험방지 조치가 필요하다. | HPU 유압 호스·배관·커플링·축압기 등 잔압 위험이 있는 작업 |

## 카드 인용 예시

```text
산업안전보건기준에 관한 규칙 제92조 제1항·제2항
산업안전보건기준에 관한 규칙 제92조 제1항·제2항·제4항
```

카드 본문은 “정지·기동 방지·압력 방출을 확인해야 한다”는 근거 범위까지만 표현한다. 특정 설비의 차단점, 방압 순서, 잠금 장치 종류, 승인권자는 이 조문만으로 결정하지 않는다.

## L1 적용 메모

- CV·RT에서 사람의 신체가 끼임 위험 구역에 접근하거나 걸린 소재를 제거하는 상황은 제1항·제2항 검토 대상으로 기록한다.
- HPU의 가압 배관·호스·커플링을 다루는 상황은 제4항까지 함께 검토 대상으로 기록한다.
- 이 문서는 카드의 법적 근거 확인 메모이며, 실제 작업 전 위험성평가·설비별 작업표준·안전 담당 승인 절차를 대체하지 않는다.
