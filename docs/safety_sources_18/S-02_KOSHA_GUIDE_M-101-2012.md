- [KOSHA Guide와 법령 간 연계성 표](https://www.kosha.or.kr/cms/resFileDownload.do?fileName=KOSHA_Guide_%EB%B0%8F_%EB%B2%95%EB%A0%B9_%EA%B0%84_%EC%97%B0%EA%B3%84%EC%84%B1%28Guide_%EA%B8%B0%EC%A4%80%29.pdf&siteId=kosha&type=etc)는 M-101-2012를 안전보건규칙 제2편 제1장 제11절과 연결한다.

## L1 카드에 연결하는 범위

| L1 대상 | 확인된 위험 맥락 | 카드 작성 시 표현 |
| --- | --- | --- |
| CV 벨트·풀리·롤러 | 끼임·말림, 걸린 소재 제거 중 접근 | “운전 중 접근·수동 제거를 보류하고, 설비별 안전 절차 확인 후 진행” |
| RT 롤러·동력전달부 | 회전부 끼임·말림, 불시기동 | “점검·정비 전 운전 정지와 기동 방지 상태를 확인” |
| 적재·이송 구간 | 적재물 낙하·이탈, 점검통로 위험 | “낙하·이탈 위험과 접근 제한을 확인” |

## 미확인 범위와 보류 사항

M-101-2012 전문의 조·항·세부 작업절차는 이번 조사에서 공식 원문 파일로 확보하지 못했다. 따라서 다음은 이 파일만으로 확정하지 않는다.

- 지침의 정확한 조항 번호와 원문 문구
- L1 CV·RT에 필요한 방호물·비상정지장치의 구체적 사양
- 걸림 제거, 청소, 점검, 재가동의 설비별 순서

T5 카드의 `safety_basis`에는 현재 `KOSHA GUIDE M-101-2012 「컨베이어의 안전에 관한 기술지침」`까지만 식별자로 기록할 수 있다. 전문을 확보하면 적용 조항을 추가하고 카드별 매핑을 다시 검토한다.
