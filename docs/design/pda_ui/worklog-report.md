# PDA 근무일지 보고서 양식

[HTML 양식](worklog-report.html)을 브라우저에서 열어 확인한다. 1280×800 가로 PDA의 기존 밝은 테마와 상단·본문 구성을 참고한 독립 시안이다.

## 작성 원칙

- 정상근무일은 근무정보와 MES 자동 기록만 표시하며, 특이사항을 입력하거나 ‘없음’을 체크하지 않는다.
- 정비·이상증상·고장이 발생했을 때만 보고서에 기록을 추가한다. 필수 입력은 대상 설비(복수 선택)와 상황·수행한 조치 두 항목이다.
- 기록 유형은 선택 사항이다. 확인한 원인·조치, 결과·후속 인계, PMS 계획 연결은 필요한 경우에만 행을 추가한다.
- 한 기록에 설비 여러 대를 연결할 수 있고, 원인별로 관련 설비와 추정·확인·배제 상태를 남길 수 있다. 원인 미확인을 기록 누락으로 처리하지 않는다.
- 지식카드 후보는 체크 하나로 제안한다. 적용 조건·재사용 절차·승인 여부는 별도 검토에서 보완한다.

‘기본 양식’은 특이사항이 없는 상태, ‘정비·이상 작성 예시’는 다중 설비·원인 사례를 보여준다. 작성 중 내용을 예시로 바꾸거나 비울 때는 확인을 받는다. 인쇄 시 주변 도구를 숨기고 보고서 본문을 출력한다.

## 자동 기입·선택 기록의 경계

| 자동 기입·연결 대상 | 발생 시 작성 | 선택 추가 |
|---|---|---|
| 근무일·조·작성자·소속·라인, 설비 마스터 | 대상 설비, 상황·수행한 조치 | 원인·확인 근거, 결과·인계, PMS 계획, 지식카드 후보 |
| MES 값·단위·기준·관측시각·품질, 근무 중 경보·이벤트 |  | 사진·증빙 연결은 후속 연동 대상 |

MES는 근무시간 범위의 관측·경보 이력을 연결해야 한다. 현재값만으로 근무 전체가 정상이라고 판정하지 않으며, 미수신 값은 정상으로 간주하지 않는다. 일반근무 구분과 센서 정상 판정도 구분한다.

## 구현 범위와 제한

이 파일은 양식 검토용 시안이다. 근무정보·설비명과 작성 예시는 가상 데이터이며, 실제 MES 요청·DB 저장·중앙 업로드·PMS 연결·지식카드 승격을 수행하지 않는다. ‘일지 마감 확인 (시연)’은 필수 입력 검증 결과만 표시한다. 입력 내용은 메모리에만 유지되어 새로고침하면 사라진다.

실제 연결에서는 일지, 추가 기록, 기록별 복수 설비, MES 근거를 저장하고 후보를 원본 기록에 연결해야 한다. 이 PR에는 해당 DB/API 구현이나 기존 PDA·MES 동작 변경을 포함하지 않는다.

## 검증

Playwright 모듈과 Google Chrome이 설치된 환경에서 저장소 루트에서 실행한다. Playwright가 외부 런타임에 설치되어 있다면 해당 node_modules를 NODE_PATH로 지정한다.

```sh
node tests/pda_worklog_report.cjs
git diff --check
```

자동 검증 범위: 1280×800에서 문서 전체의 가로 넘침 없음, 정상일 무입력 마감, 추가 기록 필수 항목, 다중 설비·원인, 선택 PMS·인계·후보 기록 유지, 내용 교체 확인, 가상 예시 표시, 인쇄 PDF 렌더링, 브라우저 오류 없음. 실제 서버 저장과 중앙 DB 업로드는 이 테스트의 대상이 아니다.
