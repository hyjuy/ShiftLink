# 증상 매핑 검수 문서 (kg-demo-v1)

모든 연결은 **사람 검수 전 후보**이며 `status: accepted` 같은 원본 상태와 무관하다. 안전성이 확인되었다는 뜻이 아니다.

## 1. 집계

- 카드 86장 모두 card_map·needs_review에 1회씩 기록
- safety_flag=true 56장 → 연결 0 (후보는 4절에만)
- symptom=null 13장 → 연결 0 (안전 11장 + 비안전 2장)
- 두 집합의 합집합 58장 → 연결 0
- 나머지 28장 → 연결 후보 18장, 보류 10장
- 증상 개념 18개 (모두 연결된 카드가 있는 개념만)

## 2. 증상 개념과 연결 카드

- `sym:hpu-outlet-pressure-absent` 펌프 출구 압력 없음 — K-1001
  - 펌프가 운전 중인데 출구 압력계에 압력이 읽히지 않는 상태. 압력이 읽히지만 작업에 부족한 상태와 구별한다.
- `sym:hpu-outlet-pressure-low-present` 펌프 출구 압력은 읽히나 작업 압력·유량 부족 — K-1203
  - 펌프 출구 압력은 읽히지만 작업에 필요한 압력 또는 유량이 부족한 상태. 압력이 전혀 읽히지 않는 상태와 구별한다.
- `sym:hpu-cooler-outlet-oil-temp-over-limit` 냉각기 출구 유온 상한 초과 — K-1002
  - 냉각기 출구 포트의 오일 온도 측정값이 카드가 밝힌 프로젝트 설정 상한 58 degC를 초과하는 관측. 이 수치는 원문 제조사 임계값이 아니며 '냉각 성능 확인 필요'는 포함하지 않는다.
- `sym:hpu-pump-noise-low-output-milky-foam` 펌프 소음 증가·유량 또는 압력 저하·탱크 우유빛 거품 — K-1004
  - 펌프 운전 중 동일 조건의 정상 기록 대비 소음이 증가하고, 유량 38 L_min 미만 또는 압력 145 bar 미만이며 탱크 유면에 우유빛 거품이 함께 관찰되는 상태. 유량 정상 38–46 L_min·압력 정상 145–165 bar는 MES 기준이며 제조사 임계값이 아니다. 소음 증가는 정성 관측이다. 작동유 변색·젤라틴 덩어리와는 구별한다.
- `sym:hpu-fluid-cream-color-gel-rust` 작동유 크림색 변색·젤라틴 덩어리·녹 — K-1008
  - 작동유 색이 투명에서 크림색(우유빛)으로 바뀌고, 탱크나 부품에 젤라틴 같은 덩어리가 보이거나 금속면에 녹이 생기는 외관 변화. 펌프 소음·유량 저하와 유면 거품이 함께 나타나는 상태와 구별하며, 수분 오염이라는 원인 판단은 포함하지 않는다.
- `sym:cv-idler-roll-slow-or-stopped-squeal` 부착물 없는 아이들러 롤 회전 지연·정지와 끽끽 소리 — K-1011
  - 운전 중 부착물 없는 아이들러 롤의 회전수가 동일 조건 정상 기록의 80% 미만이거나 0 rpm이고, 정상 주행 때 없던 고음의 끽끽 소리가 관찰되는 상태. 80%는 프로젝트 기준이며 원문 임계값이 아니다.
- `sym:cv-belt-section-drift-at-all-points` 벨트 특정 구간만 모든 지점에서 한쪽으로 이탈 — K-1013
  - 벨트의 같은 구간이 지나갈 때마다 컨베이어 모든 지점에서 한쪽으로 벗어나고 나머지 구간은 똑바로 도는 상태. 벨트 전체가 중앙을 벗어나 치우치는 상태와 구별한다.
- `sym:cv-belt-cover-spot-stripe-swelling` 벨트 커버 점·줄무늬 부풂 — K-1016
  - 벨트 커버 표면이 군데군데 점이나 줄무늬 모양으로 부풀어 있는 외관 상태. 기름·그리스 오염은 원인 후보이며 정의에 포함하지 않는다.
- `sym:gr-reducer-regular-abnormal-noise` 감속기 규칙적 이상음 — K-1026
  - 감속기에서 평소와 다른 규칙적인 운전음이 나는 상태. 불규칙한 운전음이나 장착부 주변의 소리와 구별한다.
- `sym:common-signal-out-of-range-without-alarm` 알람 없이 계측값이 정상 범위 이탈 — K-1105
  - 알람은 표시되지 않았지만 순회 중 읽은 계측값이 정상 범위를 벗어난 관측. 알람 부재와 계측 신호 부재는 다르며, 정상 범위 경계는 실제 알람 설정값이 아니다.
- `sym:hpu-filter-dp-above-1-2-bar` HPU 필터 차압 1.2 bar 초과 — K-1201, K-1202
  - hpu_filter_dp 측정값이 1.2 bar를 초과하는 관측(MES 정상 범위 0–1.2 bar, 1.2 bar는 정상에 포함). 이 경계는 제조사 고장 기준이 아니며 막힘·교체 필요 판정은 포함하지 않는다.
- `sym:cau-air-pressure-drop` 압축공기 계통 압력 저하 — K-1301, K-1303
  - 압축공기 계통 압력이 떨어진 관측. 압력 상승, 공급량 부족, 누설음과 구별하며 누설은 원인 후보로서 정의에 포함하지 않는다.
- `sym:pdp-bus-voltage-dip-at-motor-start` 대형 모터 기동·부하 피크 시점 버스 전압 순간 강하 — K-1307
  - 대형 모터 기동이나 부하 피크와 시각이 겹쳐 배전 버스 전압이 잠깐 떨어지는 상태. 기동·피크와 겹치는 시점 조건을 가진 관측으로 분류한다. 차단기 트립은 별도 관측이며 동반될 수 있다. 이 개념은 트립이 없음을 뜻하지 않는다.
- `sym:cau-compressor-stop-during-load-run` 압축기 부하 운전 중 정지 — K-1311
  - 압축기가 부하 운전 중 정지하며 과열 정지, 과부하 트립, 토출 고온 경보가 동반될 수 있는 상태. 정전·복전 후 기동 불가와 구별한다.
- `sym:cau-compressor-no-start-after-power-restore` 복전 후 압축기 기동 불가 — K-1322
  - 정전 뒤 전원이 복구되었는데 압축기가 기동하지 않는 상태. 재기동 확인 순서 자체와 자동 재기동 설정은 포함하지 않는다.
- `sym:cau-compressor-discharge-temp-high` 압축기 토출 고온 — K-1323
  - 압축기 토출 온도가 높은 상태. 부하 운전 중 정지는 별도 관측이며 동반될 수 있다. 이 개념은 정지가 없음을 뜻하지 않는다. 지정 외 윤활유 사용은 원인 후보로서 포함하지 않는다.
- `sym:cau-compressor-oil-consumption-increase` 압축기 윤활유 소비 증가 — K-1323
  - 압축기 윤활유 소비량이 늘어난 관측. 지정 외 윤활유 사용은 원인 후보로서 포함하지 않는다.
- `sym:cau-compressor-oil-foaming` 압축기 윤활유 거품 — K-1323
  - 압축기 윤활유에 거품이 생긴 관측. 작동유 탱크의 우유빛 거품과는 설비·매체가 달라 구별한다.

## 3. 비안전·증상 있는 28장

### K-1001 HPU/주 베인펌프
- 원문 증상: 펌프 운전 중 펌프 출구 압력계에 압력이 읽히지 않는다.
- 후보: `sym:hpu-outlet-pressure-absent`
- 메모: 압력 '없음'. K-1203의 '읽히나 부족'과 병합하지 않음.

### K-1002 HPU/오일 쿨러
- 원문 증상: 냉각기 출구 포트의 오일 온도 측정값이 MES 연계 기준 상한 58 degC를 초과하거나, 냉각 성능 확인이 필요하다. 58 degC는 hpu_oil_temp의 MES 정상 상한에 맞춘 설정값이다.
- 후보: `sym:hpu-cooler-outlet-oil-temp-over-limit`
- 메모: 원문 증상의 '냉각 성능 확인이 필요하다'는 확인 요구라서 증상 개념에 넣지 않음. 58 degC는 프로젝트 설정값.

### K-1004 HPU/주 베인펌프
- 원문 증상: 펌프 운전 중 동일 조건의 정상 기록 대비 소음이 증가하고, hpu_flow < 38 L_min 또는 hpu_pressure < 145 bar이며 탱크 유면에 우유빛 거품이 관찰된다. 유량 정상 38–46 L_min·압력 정상 145–165 bar는 MES 기준이다. 소음 증가는 정성 관측으로 남긴다.
- 후보: `sym:hpu-pump-noise-low-output-milky-foam`
- 메모: 소음·유량/압력 미달·거품이 한 증상으로 함께 서술되어 복합 개념으로 둠. K-1008과 병합하지 않음.

### K-1008 HPU/작동유
- 원문 증상: 작동유 색이 투명에서 크림색(우유빛)으로 바뀌고, 탱크나 부품에 젤라틴 같은 덩어리가 보이거나 금속면에 녹이 생긴다.
- 후보: `sym:hpu-fluid-cream-color-gel-rust`
- 메모: 작동유 외관 변화. 원문이 에어레이션 거품과 혼동 가능하다고 명시하여 K-1004와 분리.

### K-1011 CV/아이들러 롤(베어링)
- 원문 증상: 운전 중 부착물 없는 아이들러 롤의 회전수가 동일 조건 정상 기록의 80% 미만이거나 0 rpm이고, 정상 주행 시 없던 고음의 끽끽 소리가 관찰된다. 80%는 프로젝트 회전 지연 기준이며 원문 임계값이 아니다.
- 후보: `sym:cv-idler-roll-slow-or-stopped-squeal`
- 메모: 회전수(정지/지연)와 소리가 함께 서술됨. 80%는 프로젝트 기준.

### K-1013 CV/벨트(스플라이스)
- 원문 증상: 벨트의 같은 구간이 지나갈 때마다 컨베이어 모든 지점에서 한쪽으로 벗어나고, 나머지 구간은 똑바로 돈다.
- 후보: `sym:cv-belt-section-drift-at-all-points`
- 메모: 특정 구간·모든 지점이라는 조건이 증상의 일부. 일반적 벨트 사행과 분리.

### K-1016 CV/벨트 커버
- 원문 증상: 벨트 커버 표면이 군데군데 점이나 줄무늬 모양으로 부풀어 있다.
- 후보: `sym:cv-belt-cover-spot-stripe-swelling`
- 메모: 외관 증상만 연결. 기름·그리스 오염은 원인 후보.

### K-1026 GR/감속 기어박스
- 원문 증상: 감속기에서 평소와 다른 규칙적인 운전음이 난다.
- 후보: `sym:gr-reducer-regular-abnormal-noise`
- 메모: 원문 증상은 '규칙적인 운전음'. 갈리는/두드리는 구분은 know_how의 원인 후보 분기라 개념으로 나누지 않음.

### K-1101 COMMON/교대 인계 기록
- 원문 증상: 원인 미해결·여러 단계 확인 진행, 확인 완료 범위·정상 결과의 다음 조 인계
- 보류
- 사유: 증상이 아니라 인계 상황(확인 완료 범위·정상 결과의 다음 조 인계)을 서술. 증상 개념으로 만들지 않음.

### K-1102 COMMON/교대 인계 기록
- 원문 증상: 필터를 갈거나 볼트를 조이거나 유면을 보충했는데 계측값이 덜 회복돼서, 조치 효과를 다음 조가 재확인하도록 넘겨야 한다.
- 보류
- 사유: 조치 후 계측값 회복 부족을 다음 조에 넘기는 인계 기록 절차. 특정 설비 증상이 없음.

### K-1104 COMMON/감각 관측 기록
- 원문 증상: 계측값에 남지 않는 갈리는 소리·끽끽 소리·외관 변화를 현장에서 듣거나 봤는데, 들은 소리와 본 모습을 다음 조에 넘겨야 한다.
- 보류
- 사유: 감각 관측을 기록하는 방법에 관한 카드. 소리·외관은 예시이며 특정 증상 개념으로 확정할 수 없음.

### K-1105 COMMON/알람 없는 신호 이상
- 원문 증상: 알람은 안 떴는데 순회하며 읽은 값이 정상 범위를 벗어나 있어, 몇 시에 얼마였는지, 다음 조가 무엇을 다시 읽을지 넘겨야 한다.
- 후보: `sym:common-signal-out-of-range-without-alarm`
- 메모: 인계 카드지만 증상 문장에 '알람 없이 정상 범위 이탈'이 관측으로 서술됨. 인계 방법 자체는 증상이 아니므로 제외.

### K-1106 COMMON/조치 절차 미정 영역
- 원문 증상: 따를 조치 절차가 정해지지 않은 신호 이상이라 현장에서 어떻게 조치할지 모르는데, 다음 조에 넘겨야 한다.
- 보류
- 사유: 조치 절차가 없는 상태의 인계 방법. 증상이 특정되지 않음.

### K-1107 COMMON/공급원 설비 확인
- 원문 증상: 공급받는 설비의 유지압·장력이 떨어졌는데, 공급원 설비도 이상인지 함께 봐서 다음 조에 넘겨야 한다.
- 보류
- 사유: 공급받는 설비의 유지압·장력 저하는 명시된 관측이다. RT 압력 81→79 bar, CV 장력 342→338 kPa, 공급원 HPU 압력 152 bar 등 설비·단위·확인 시각과 공급원 확인 여부가 달라 단일 개념의 범위를 확정하기 어려워 연결 보류. 공급원 전체 정상이나 고장 원인 배제를 뜻하지 않음.

### K-1108 COMMON/추정·관측 구분
- 원문 증상: 원인이 짐작되지만 관측만으로는 확정하지 못했고 다른 원인 가능성도 남아 있어, 추정과 실제 관측을 나눠 다음 조에 넘겨야 한다.
- 보류
- 사유: 추정과 관측을 구분해 적는 방법. 증상이 아님.

### K-1109 COMMON/요청 접수 상태
- 원문 증상: 정비·전기 담당에게 점검을 요청하거나 접수만 해 두고 아직 회신이나 착수가 없는 상태로 다음 조에 넘겨야 한다.
- 보류
- 사유: 요청만 접수된 상태의 인계 방법. 증상이 아님.

### K-1111 COMMON/수치 없는 관측
- 원문 증상: 누유량이 줄었는지 동작이 느려졌는지 눈대중으로만 봤고 잴 수단이 없어서, 다음 조가 수치로 비교하도록 넘겨야 한다.
- 보류

## 6. 병합·비병합 판단

- 병합: K-1201+K-1202(같은 관측 1.2 bar 초과), K-1301+K-1303(압력 저하, '누설 의심'은 제외).
- 비병합: K-1001(압력 없음) / K-1203(읽히나 부족) — 없음/낮음 구별.
- 비병합: K-1004(펌프 소음·유량/압력 저하·유면 거품) / K-1008(작동유 외관 변화) — 원문이 거품과 변색을 혼동하지 말라고 함.
- 비병합: K-1311(부하 운전 중 정지) / K-1322(복전 후 기동 불가) / K-1323(토출 고온·소비 증가·거품) — 운전·재가동 맥락과 관측 종류를 구별하며 정지·고온 등의 동시 발생을 배제하지 않음.
- 비병합: K-1011(CV 아이들러, 회전 지연·정지) / 안전 카드 K-1017(RT 롤러 소음) — 설비와 회전수 조건 차이.
- 비병합: K-1026(규칙적) / K-1028(불규칙) / K-1030(장착부 주변) — 소리 성질과 위치 차이.
- 비병합: K-1301(압력 저하) / K-1305(압력 상승) / K-1312(공급량 부족) / K-1302(누설음).
- 비병합: K-1307(기동·피크 시 순간 강하) / K-1310(전압 저하+차단기 트립).
- 병합 후보(안전 카드라 보류): K-1010+K-1012, K-1025+K-1210.

## 7. 사람이 확인할 사항

1. 18개 개념의 정의 단위(복합 개념 K-1004·K-1011 및 K-1323 복수 관측 카드의 독립 후보 3개 분리)가 현장 표현과 맞는지.
2. K-1301의 '공압 설비 출력 저하'를 별도 증상 개념으로 둘지.
3. K-1201/K-1202 병합, K-1301/K-1303 병합의 적절성.
4. K-1105의 기존 연결 유지 여부와 보류 10장 중 K-1107의 보류 유지 여부.
5. 안전 카드 45장의 후보를 안전 검수 뒤에 연결할지(자동 연결 금지).
6. 프로젝트 설정 임계값(58 degC, 80%, 1.2 bar 등)이 개념 정의에 들어간 것이 적절한지. 정의 문장은 제조사 기준이 아님.
